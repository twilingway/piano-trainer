# Параметры локального атласа правой кисти

Здесь сохраняется авторская работа над 51 позой: назначения нот и пальцев, сгибание MCP/PIP/DIP,
разведение, положение и поворот запястья, размеры клавиатуры и снимок статусов проверки. Эти
параметры можно перенести на собственный rig. Изображения для чтения параметров не нужны.

`poses.json` содержит разрешённые поля поз. `metadata.json` описывает единицы, систему координат,
MIDI-центры клавиш, ссылки и SHA исходных файлов. `export-manifest.json` подтверждает точное
сохранение разрешённых полей всех 51 позы и содержит хеши результатов. Статус относится к
сохранённой локальной модели; он не подтверждает качество переноса на другой rig или визуальную
приёмку.

```powershell
python export_poses.py --source "путь/к/локальному/smplh-black-key-atlas.json" --status "путь/к/локальному/frame-status.json" --output "путь/к/публичному/экспорту"
```

Экспорт использует стандартную библиотеку Python. Он проверяет число и порядок кадров, MIDI и
битовые маски, соответствие подписей назначенным нотам, конечность чисел, размеры векторов и
правильность матриц поворота. Все разрешённые авторские поля сравниваются с исходными данными после
отбора; записанный JSON читается обратно. Входные файлы не изменяются.

Полные `full_pose156`, `right_hand_pose45`, `left_hand_pose45`, параметры формы, анатомические оси,
индексы вершин, топология руки, регрессоры, веса и blend shapes не экспортируются. В исходном
`full_pose156` присутствует масштабированное обученное среднее левой кисти MANO; этот вектор
намеренно исключён. Не включены Blender/FBX-файлы руки, NPZ, массивы контактных деформаций,
модельные изображения и сторонний код адаптера MANO.

Сохранены только собственные рецепты визуальных коррекций: подушечки кадров4/5 по Z до1 мм и боковой
контакт кадров45/48 по X до2 мм. Самих смещений вершин здесь нет. Это статические визуальные приёмы,
не модель давления, сил или физиологии.

Точная рабочая сцена, источники и промежуточные доказательства остаются в отдельной **локальной
полной резервной копии**. Публичный экспорт не заменяет эту копию и не обещает побитово восстановить
Blender-модель. MANO/SMPL+H не входит в архив; его условия:
[лицензия MANO](https://mano.is.tue.mpg.de/license.html). Эта копия собственных параметров и
инструментов не предоставляет прав на стороннюю модель.

В `source/` находятся отдельные авторские инструменты: таблица случаев `black_cases.py` и решатель
`wrist_solver.py`. Это не готовый автономный пакет: для старого процесса необходимы исключённые
локальные зависимости и отдельно полученная модель с подходящей лицензией. Подробности — в
`source/NOTICE.md`. Сторонние зависимости не следует копировать в публичный архив автоматически.

`keyboard-layout.blend` — отдельный собственный макет из 61 клавиши без руки, скелета и внешних
библиотек. Кадр 1 показывает клавиши в покое, кадр 2 — ход вниз на 8 мм. Геометрия и координаты
клавиш также сохранены в `keyboard-layout.json`. Пересоздать макет можно в Blender командой
`blender --background --python build_keyboard_layout.py -- "папка этого пакета"`.

Продолжение работы описано в `PROMPT-NEXT-SESSION-RU.md`. Точная локальная сцена находится в
`blender/labs/mano-reference-20261018/black-key-atlas-20261018/working-refinement/smplh-black-key-atlas.blend`;
полный архив хранится отдельно в `blender/backups/`. Внешняя модель не загружается этим пакетом
автоматически. Для переноса на собственную руку нужно заново проверить калибровку суставов, контакт
с клавишами и форму поз.

Состояние r12: 45-й кадр исправлен сгибанием среднего без бокового сжатия, 48-й — расслаблением
безымянного и перепривязанным SIDE. Пользователь разрешил касание без проникновения: `ДОПУСТИМО` не
означает ошибку позы. Численный отказ строгого профиля с запасом 0.5 мм остаётся в технических
полях; его не подменяют на PASS. Общий frozen-индекс/replay и визуальная приёмка остаются открытыми.
