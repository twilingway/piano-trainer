# Область этих исходников

`black_cases.py` задаёт авторские назначения MIDI, пальцев и масок для 19 дополнительных случаев. Он
не содержит данных модели.

`wrist_solver.py` сохраняет авторскую реализацию поиска положения кисти, IK и дифференцируемой
подгонки. Обученные массивы модели в этот файл не встроены. Его импорты `black_solve`,
`solve_smplh_pilot`, `smplh_data` и `pilot_body` относятся к отдельному локальному процессу; их
дерево зависимостей сюда не перенесено. Файл сам по себе не запускает и не восстанавливает атлас.

В частности, локальный `smplh_data.py` помечен как адаптация MANO v1.2 и содержит уведомление об
авторских правах исходных авторов. Он исключён из публичной копии собственных инструментов. Не
следует распространять этот адаптер или данные модели на основании наличия данных файлов в
репозитории.

MANO/SMPL+H использовался в локальном эксперименте для анимации персонажа; авторство модели
принадлежит Max Planck Institute for Intelligent Systems. Условия отдельно получаемой модели:
