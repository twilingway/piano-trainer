# Импорт уроков из PDF

Утилиты, которыми ноты и табы курса переводятся из PDF в MusicXML для `local-lessons/`. В
репозитории лежат только инструменты: сами ноты защищены авторским правом, поэтому и готовые
MusicXML, и текстовые исходники транскрипций живут только в git-ignored `local-lessons/`.

## Шаги

1. **Рендер страниц.** OMR-программ (Audiveris, oemer) нет, PDF читается глазами по картинкам.
   Python без сторонних пакетов PDF не рисует, поэтому рисует pdf.js в браузере:

   ```bash
   python tools/course-import/serve.py <папка-с-pdf> <папка-для-png>
   ```

   Затем открыть `http://127.0.0.1:5392/render.html?f=n05,t05` (имена PDF без `.pdf`). Каждая
   страница сохраняется как `<имя>_p<N>.png` в масштабе 3×. Имена с кириллицей и пробелами удобнее
   заранее скопировать в короткие ASCII (`n05.pdf` — ноты, `t05.pdf` — табы).

2. **Крупный план.** Строку нот вырезать и увеличить, чтобы считать добавочные линейки:

   ```bash
   python tools/course-import/crop.py n05_p1.png sys1.png 0.1 0.19 0.92 0.31 2
   ```

3. **Транскрипция в текст.** Каждый такт — одна строка в формате `dsl2musicxml.py` (описание в
   начале файла): `R:` правая рука, `L:` левая, ноты вида `E5:q./3` (высота, длительность, палец),
   аккорды `[C4 E4 G4]:h/531`, лиги `~`, атрибуты такта `@bar=double`, `@mark=Припев`. Сумма
   длительностей такта сверяется с размером, лиги должны закрыться, иначе конвертер падает с номером
   такта. Исходники хранить в `local-lessons/.sources/`.

4. **MusicXML.**

   ```bash
   python tools/course-import/dsl2musicxml.py local-lessons/.sources/05n.txt "local-lessons/05 Song (урок 5)/1 Ноты.musicxml"
   ```

   Папка урока — `NN Песня (урок N)`, уровень — `1 Ноты…`, `2 Табы…`: загрузчик
   (`src/song/localLessons.ts`) упорядочивает уроки и уровни по имени и срезает ведущий номер. Если
   табы — та же музыка, что и ноты, уровень один.

5. **Проверка.** Все уровни парсятся читалкой проекта, а аппликатура солвера сравнивается с
   напечатанной:

   ```bash
   pnpm exec vitest run src/fingering/courseFingering.test.ts --silent=false
   ```

   С переменной окружения `COURSE_REPORT=1` тест печатает расхождения по тактам. На чистом клоне без
   `local-lessons/` тест пропускается.

## Табы курса

Таблица: строки «пальцы правой руки», «правая рука», «левая рука», «гармония»; клетка — шестнадцатая
(16 клеток на такт 4/4) или восьмая, по нотам видно, какая. Буквы без октав: октаву и длительность
берём из нот, из табов — начала нот и пальцы. Палец 1 на нижней ноте и сразу 5 на ноте выше растяжки
означают прыжок рукой, а не растяжку.
