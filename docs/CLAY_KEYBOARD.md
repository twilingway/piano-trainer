# Пластилиновая клавиатура

В настройках вида добавлен «Пластилин». Это объёмная клавиатура с кремовыми округлёнными клавишами,
тёмными матовыми чёрными клавишами и мягким тёмно-бирюзовым корпусом. Визуальный ориентир —
существующие `src/ui/lesson-art/left-hand.webp` и `two-hands.webp`.

Новый игрок получает этот вид. Явно сохранённые «Классика», «Аркада» и «3D» сохраняются. Камера и
проекция нот хранятся в прежних профилях, отдельно для каждого вида. В уроке пластилиновый вид
остаётся; учебный профиль не записывает временные настройки поверх настроек игрока.

## Модель и материал

| Элемент        | Реализация                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| Белые клавиши  | Процедурный контур с плечами около чёрных клавиш; скругления в плане и объёмный край 3,2 мм                  |
| Чёрные клавиши | Отдельная округлённая экструзия с краем 2,1 мм                                                               |
| Размеры        | Прежние метрики 88 клавиш A0–C8: шаг 23,5 мм, ширина белой 22,5 мм, чёрной 13,31152 мм; глубина белой 150 мм |
| Контакты       | Верхние габариты 22/34 мм, прежний ход 8 мм; центры и часы сессии не меняются                                |
| Материалы      | MeshStandardMaterial, roughness 0,91–0,94, metalness 0; без лака и отражающего металла                       |
| Рельеф         | Детерминированная карта 64×64 RGBA, 16 КиБ, запекается один раз и разделяется материалами                    |
| Корпус         | RoundedBoxGeometry на собственных клонах прежних частей; исходный GLB не меняется                            |
| Подписи        | Прежняя общая текстура с именами нот, номерами октав, подсказками и цветами пальцев                          |

Совпадающие вершины скругления имеют усреднённые нормали: на мягком крае нет полигональных полос.
Плоская контактная поверхность, UV подписей и группы материалов сохраняются.

Геометрия создаётся при раскладке. Кадровый цикл использует прежние hinge-группы и оболочку
подсветки без лепки геометрии или генерации текстур. На клавиши действует существующий мягкий свет и
контактный AO, без дополнительных проходов теней.

Исходники модели — `src/render/three/clayKeyGeometry.ts`, материал — `ClayKeyMaterials.ts`. Модель
написана процедурно для проекта; сторонних растровых материалов, импортированных моделей и новых
зависимостей в этой задаче нет.

## Ввод и владение ресурсами

Пластилиновые визуальные скругления не меняют hitregions: native picking использует нерендеримые
proxy с оригинальной GLB-геометрией и текущей мировой матрицей каждой показанной клавиши. Proxy не
добавляют draw calls и не владеют геометрией/материалами. Области нажатия сохраняются и при ходе
клавиши.

Процедурными клавишами владеет раскладка. Материалами индивидуальной подсветки владеет
ThreeKeyEmission, общими clay-шаблонами и картой — StageKeyMaterials. Корпус освобождает только
собственные скруглённые геометрии. Оригинальные GLB и компьютерная клавиатура сохраняют прежний
путь.

Если native-модель не загрузится, остаются плоские клавиши и управление. На узком экране диапазон
можно уменьшить существующим выбором клавиш; полный физический инструмент остаётся 88-клавишным.

## Проверки

Автотесты проверяют 88 габаритов и высот, группы 2+3, плечи вокруг чёрных клавиш, ограничение числа
вершин, детерминированность карты, освобождение ресурсов, проекции краёв и плеч при picking, ход и
видимость proxy. Настройки проверяются для нового и сохранённых видов, входа/выхода из урока и
сериализации профиля.

Браузерная проверка и полный gate фиксируются в итоговом PR отдельно от тестов. Реальный MIDI и звук
не подтверждаются статическим снимком.
