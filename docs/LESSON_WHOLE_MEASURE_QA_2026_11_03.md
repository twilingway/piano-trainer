# Учебная комната: целый такт на широком экране

Ветка `fix/lesson-whole-measure`, основа `origin/dev` 1d2d0669 (релиз 0.0.290). Это точечное
исправление ширины по замечанию игрока; новый OpenSpec change не требуется.

Причина: учебная комната ограничивалась 1080 px даже на широком мониторе. После симметричных боковых
колонок для стана оставалось 744 px. В исходном XML уже были четыре ноты текущего такта, но
четвёртая оказывалась за краем. Убран только предел ширины комнаты; генерация, учебные подсказки,
оценка, сохранённый масштаб и музыкальное время не менялись.

## Видимый Chrome

Стенд ветки: 5191, PID 54540, управляемая сессия 23558. Аудиовывод приглушён; MIDI заменён пустым
списком. Физические устройства и Safari не проверялись.

- 2376×1308, 150%: до правки staff 744 px, SVG 1092 px, видны три из четырёх головок; после — staff
  2040 px, SVG 1102 px, все четыре внутри области, scrollLeft=0.
- 11 настоящих keyboard-ответов: на нотах 1–11, включая третий такт (9–11), каждый раз четыре
  головки видны целиком, SVG остаётся на x=637, scrollLeft=0.
- 200%, 2376×1308 и 1920×1080: SVG 1462 px, все четыре головки видны.
- 200%, 667×375 и 320×568: сохраняется горизонтальное следование; последняя головка текущего такта
  доступна. Overflow страницы отсутствует.
- Масштаб уроков сохранён как 2, обычный масштаб — 1; изменение размера и настроек не продвинуло
  позицию с ноты 12. Высота клавиш — прежние 177 px desktop, 122/116 px mobile.
- Ошибок JavaScript нет. Снимки остаются локально в основной папке `.browser-artifacts/`:
