# Весёлая пластилиновая нотация

Учебный стан использует матовый SVG-материал без зеркального блика. Заполненные обычные головки
получают одинаковую улыбку: она не сообщает ступень, руку, октаву или правильность ответа. Именная
палитра по-прежнему разрешена только действующей подсказкой. Цвета принятой ноты и отметок разбора
имеют прежний приоритет; линии, флажки, аккорды и полые головки сохраняют форму.

`staffClayFaces` использует точный chord index OSMD и написанный тип. В установленном OSMD 2.1.x
массив типов содержит опечатку `eigth`: для настоящего MusicXML `eighth` тип остаётся UNDEFINED. В
этом узком случае лицо разрешается только по явному обычному solid-глифу `vb`; половинные, целые,
специальные и пользовательские формы не подменяются. Исходные музыкальные пути неизменны.
SVG-примитивы лица имеют свои цвета и не входят в path-перекраску глифа.

Сгенерированные G2/F4 ключи и происхождение находятся в `src/staff/art/manifest.json`. Растровая
декорация вписана пропорционально внутрь исходного bbox. Центр завитка G закреплён на второй линии,
промежуток между музыкальными точками F — на четвёртой. Сохраняемые исходные пути дают прежние
размеры и восстанавливаются при отключении материала или ошибке загрузки изображения. Необычные и
октавные ключи остаются исходными. Поздняя ошибка удалённого изображения не влияет на его замену
после relayout.

Проходы выполняются после engraving, не в кадровом цикле. Генерация песни, MusicXML и часы
PracticeSession не меняются. Для визуальной приёмки нужен настоящий браузер: unit-тесты SVG не
подтверждают внешний вид, звук, Web MIDI или кадровую анимацию.

Для нотного постера в 3D оба ключа встроены как data URL из статических импортов. Экспорт SVG
допускает только точное совпадение байтов одного из этих двух ассетов с правильным маркером. Иные
изображения, внешние URL, неверная пара маркер/ассет и ассет без маркера удаляются. Поэтому постер
самодостаточен и сохраняет ключи, а общий запрет произвольных изображений остаётся в силе.
