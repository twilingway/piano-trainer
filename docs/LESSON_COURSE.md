# Первые десять уроков

Карточки курса отделены от прежних партитур. Пока содержание урока не проверено, его карточка
показывает «Скоро». Этапы рук не заменяют уровни сложности прежних упражнений.

## Подключение проверенного урока

Музыка, кадры, видео и рабочие расшифровки остаются в игнорируемой папке `local-lessons/`. Не
добавлять их в git. После сверки нот, октав, ритма, повторов и пальцев с видео добавить урок в
`local-lessons/course.json`:

```json
{
  "lessons": [
    {
      "id": "lesson-01",
      "number": 1,
      "title": "Название проверенного урока",
      "goal": "Краткая цель упражнения",
      "reviewed": true,
      "stages": ["right", "left", "both"],
      "phrases": [
        {
          "id": "phrase-01",
          "version": "1",
          "musicXml": "lesson-01/phrase-01.musicxml"
        }
      ]
    }
  ]
}
```

`number` — номер от 1 до 10. `musicXml` — относительный путь внутри `local-lessons/`. Каталог
подключает только локально найденные XML, а не произвольные внешние пути. Для урока с двумя этапами
перечислить только фактические этапы, например `right`, `both`. Порядок фраз в массиве — порядок
обучения; одна и та же партитура используется на каждом этапе. Каждый этап сначала проходит все
фразы. Названия и цели — текст локальных материалов; общие подписи интерфейса переводятся каталогами
RU/EN.

Идентификаторы урока и фразы остаются постоянными при переименовании. Изменение XML автоматически
меняет эффективную версию фразы. При намеренном пересмотре задания также увеличить `version`.
Прежний зачёт сохраняется в хранилище, но не относится к новой версии.

## Зачёт и сохранение

Фраза засчитывается после естественного окончания полного прохода от начала в режиме ожидания или
темпа с хотя бы одним попаданием игрока. Порог точности отсутствует. Пауза допустима. Перемотка,
неполный диапазон, прерванный проход, прослушивание и воспроизведение дубля не дают зачёт. Не
использовать закрытие записи `onTake` как завершение задания.

Зачёт связан с неизменным контекстом урока, этапа, фразы и её эффективной версии, а также с
идентификатором загруженной песни. Поздний результат другого задания не принимается. Этап завершён
после всех фраз, урок — после всех предусмотренных этапов. Повтор пройденной фразы не удаляет
прогресс. Полностью пройденный урок можно начать снова.

Redux хранит прогресс, последнюю учебную позицию, вид «Табы / Ноты» и сопровождение курса.
Сохранение выполняет отдельный listener по ключу `lesson-course-v1`; загрузка не записывает
defaults. Последняя позиция восстанавливается только при доступной локальной фразе, а прежние зачёты
сохраняются и при временном отсутствии материалов. Ошибки чтения и записи видны через общий механизм
ошибок хранилища; при сбое записи текущий прогресс остаётся в памяти.

Табы показывают исходные ноты песни, время берут из `PracticeSession` и не запускают свои часы.
Сопровождение курса по умолчанию выключено. Оно сохраняется отдельно от глобальных настроек рук и
сопровождения обычных песен.
