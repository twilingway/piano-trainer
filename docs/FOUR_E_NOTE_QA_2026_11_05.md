# Четыре ми в знакомстве — 5 ноября 2026

Новый третий этап `hot-cross-buns/notes-e-repeat-v1` повторяет исходную ми4 четырьмя отдельными
событиями. Каждая остаётся половинной нотой с третьим пальцем и исходным темпом 72 BPM. Это два
такта 4/4, начала 0/2/4/6 долей. Исходный XML полной песни, hash, revision и финал не изменены.

Повторы являются явно производным учебным материалом: четыре уникальных ID вида
`practice-hot-cross-buns-notes-e-repeat-v1-n1` … `n4`. Они не выдаются за четыре исходные ноты.
`expectedNodeRawIds` используется одинаково построителем и проверкой точного набора доказательств.
Обычный loader сохраняет явные роли, уникальность и 1:1 runtime/canonical mapping.

Прежний `notes-e-intro` доступен через legacyNodes для старой истории и материала. При
восстановлении старого выбора открывается новый четырёхнотный этап остановленным. Следующий этап
остаётся `notes-e` той же песни. Старое однократное выполнение не завершает новый узел; разные node
ID также сохраняют независимые ключи удержания доказанных результатов.

Для этого производного знакомства используется повтор всего этапа, а source-only review недоступен.
Идентификаторы производных нот не передаются в анализатор исходных фраз. Показ и видимый стан берут
те же четыре события. Прежняя палитра, изображения и звук не менялись.

Фокусная проверка: 21 файл / 162 теста, включая построение материала, истинные четыре down/up, одно
долгое удержание (только один ответ), длительности/пальцы, source identity, старый proof,
восстановление выбора и миниатюры. Полный pnpm check прошёл: 5218 тестов + 30 compiler tests, pnpm
spec:validate — 99/99. Браузерный стенд и аппаратный MIDI этим исполнителем не запускались;
визуальную приёмку выполняет интегратор.
