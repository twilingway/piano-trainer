## Ответы на вопросы дополнения

- Подробные попытки P1 уже сохраняются, а не только агрегаты. История подсказок пока существует
  внутри текущего `ReadingSession` и теряется после завершения; сохраняется только достигнутый
  уровень.
- Отдельных курсов слуха, интервалов, ритма и аккордов нет. `src/song/exercises.ts` содержит
  статические упражнения, `src/song/harmony.ts` — анализ аккордов/тональности партитуры, не оценку
  ответа ученика.
- `src/audio/pianoSound.ts`: soundNoteOn/off и scheduleSound не продвигают PracticeSession; нужны
  жест пользователя и готовые семплы. `scheduledVoices.ts` поддерживает идентификаторы голосов, но
  глобальная отмена выключает общие голоса. Для P3 потребуется отмена звуков владельца упражнения.
- `src/song/song.ts` представляет аккорд отдельными нотами с общим стартом. `practice/session.ts`
  группирует ожидаемые начала до 30 мс и в wait ждёт все клавиши; это не готовое окно оценки
  фактического аккордового нажатия. `recording/take.ts` сохраняет отпускания и педаль.
- `src/recording/compare.ts` уже считает onset, длительность, пропуски и лишние ноты в tempo;
  `src/practice/calibration.ts` предоставляет калибровку. Не выдавать wait за измерение ритма.
- Seed API есть только для пятинотного чтения. Он исключает повтор предыдущей серии, но не всей
  истории.
- P1 доступен через MIDI, компьютерную клавиатуру и мышь. `src/render/KeyboardLayer.ts` хранит один
  mouseKey: мышь пока не решает будущее требование одновременного аккорда P6.
- Обязательные и факультативные будущие упражнения пока не выбираются: P2 ничего не блокирует,
  существующие задания доступны сразу, адаптация и отложенная проверка добровольны.

## Хранение и локальность

Сейчас файлы библиотеки хранятся в IndexedDB `piano-trainer` (`src/library/myLibrary.ts`), а
предпочтения, исполнения и прогресс курсов — в localStorage. P2 расширяет прежний локальный
`reading-course-v1`, без второго сервиса/базы и без серверной отправки событий. История помощи и
накопленные показатели доступны после reload в том же браузерном профиле и origin. Между
устройствами синхронизации нет; очистка данных сайта удаляет сохранения.

## Риски

1. Баланс P1 несовместим с увеличением доли трудных нот. Решение: отдельное адаптивное действие,
   стандартные серии и проверки сохраняют баланс.
2. Seed без фиксированного профиля не воспроизводит адаптацию. Решение: сохранять план/версию
   политики и использовать их как явные входы генерации.
3. У P1 неизвестны начало, полная история помощи и новизна. Решение: помечать неполноту, не
   синтезировать доказательства. Отпечатки старых последовательностей можно восстановить только для
   известной версии генератора.
4. Подробная история ограничена 20 результатами на вид задания. Расписание и журнал показов имеют
   отдельный жизненный цикл в том же сохранении; гарантия новизны ограничена последними 256 сериями.
5. Пороговые значения — гипотезы политики. P2 не объявляет научно подтверждённое освоение и не
   закрывает задания на основании этих порогов.
