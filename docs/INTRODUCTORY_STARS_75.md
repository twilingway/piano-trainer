# Две звезды во вводном уроке

Для новых попыток знакомства с нотами (тип notes) достаточно 75% правильных удержаний и не менее 80%
правильных нот, чтобы получить вторую звезду. Три удержания из четырёх дают ровно 75%. Например,
результат 100% ноты / 100% начало / 75% удержание получает две звезды.

Одна звезда по-прежнему требует 60% правильных нот. Для трёх нужны 95% нот, 90% удержаний и 90%
точных начал; режим ожидания не оценивает начало. Остальные типы этапов сохраняют второй порог
удержания 80%. Оценки и ошибки отдельных нот, источник музыки и время сессии не меняются.

Новые результаты сохраняют политику song-course-v3 и вводный контекст. Этот контекст передаётся из
типа исходного этапа при начале попытки и подтверждается при зачёте по исходному узлу. Нельзя
получить вводный порог для финального исполнения, подменив флаг в сохранении.

Старые результаты song-course-v1 и song-course-v2 остаются с исходными звёздами. Перезагрузка не
переоценивает их и не стирает историю. Новую оценку получает новая завершённая попытка.

## Проверки

Узкая проверка — 76 тестов в 6 файлах. Полный pnpm check — 5308 тестов и 30 React Compiler, успешно;
pnpm spec:validate — 103/103. Отдельно проверены поток четырёх физических событий down/up,
сохранённые v1/v2, поддельные звёзды и невозможность получить вводный зачёт в обычном узле. Браузер,
аппаратный MIDI, слияние и публичный релиз этим исполнителем не проверялись.
