## Результат

видимом Chrome стан показывал русские названия одновременно с буквенными названиями falling. Через
UI выбраны falling ru, стан en, выключены обе отдельные группы пальцев. Reload сохранил именно эти
значения, время осталось 00:00. Миграция старых имён, повреждённые новые значения, сохранение и
приоритет учебного профиля защищены тестами.

RU/EN проверены на 320×568, 390×844, 667×375 и 1440×900. Горизонтального переполнения документа или
диалога нет. Прокрутка остаётся внутри settings-content (401/677/196/685 px по высоте), последний
параметр стана достижим. Двуязычные наклейки клавиш сохранены.

В реальной 3D-игре выбор левой руки, затем «Слушать» оставлял меню открытым на обоих шагах. Escape
закрывает. Controlled-тесты проверяют также MIDI-партию → слушать с очисткой партии, закрытие
кнопкой и нажатие снаружи.

Переключения сохраняли 00:01. Ближние C/5, G/2, A/3 и B/4 видны целиком, буквы вертикальные. Free
показывает подписи на поднятом поле; performance дополнительно проверен после перемотки к 00:14.
После полного reload ошибок JS/GLSL нет. Дальние подписи уменьшаются вместе с нотами.

Текст запечён один раз в атлас, обновляются instanced-атрибуты. Exact top-fan decal повторяет
реальную верхнюю геометрию и NOTE_SLAB_VERTEX тела; polygonOffset устраняет самоперекрытие без
отключения depthTest. Экранные UV сохраняют пропорции, центры строк идут вдоль проекции оси.
Математическое ревью и reviewer общего b5543be — без блокеров.

Custom look.badge печатной игры остаётся буквой в старом overlay; native не получает числовую замену
или дубль. Без пальца название использует свободное место. Карточка сохраняет нотацию и выключает
только badge. ViewHintSettings сохраняет выбор до асинхронного mount без загрузки песни заново.
Повреждённая Canvas2D-подготовка оставляет доступный прежний fallback.

При сохранённом 3D задержан реальный GLB-запрос: HTML-лоадер остаётся, root скрыт, runtime-модалок
нет. После отпускания запросов сцена готова. Этот сценарий проверяет совместимость отсроченного
native запуска с начальной готовностью приложения.
