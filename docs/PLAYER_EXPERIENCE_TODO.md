# Ближайшие улучшения игры

## Отсчёт перед воспроизведением

Запрос игрока от 24.10.2026. Статус: запланировано, ещё не реализовано.

- [ ] После нажатия «Играть» показывать заметный отсчёт 3–2–1, чтобы успеть поставить руки.
- [ ] Добавить в «Игра / Режим и темп» сохраняемую длительность отсчёта; по умолчанию 3 секунды, 0 —
      сразу.
- [ ] До завершения отсчёта не продвигать музыкальное время, не запускать мелодию, MIDI, метроном и
      оценку.
- [ ] Повторное нажатие, остановка или смена песни отменяет отсчёт без запоздалого старта.
- [ ] Перед реализацией описать в OpenSpec поведение старта и возобновления, локализовать RU/EN и
      добавить ссылку из помощи на параметр.
- [ ] Проверить мышь, Ctrl+Пробел, начало и продолжение песни, отмену, сохранение настройки и
      отсутствие двойного запуска.

## Единые новые 3D-руки

Запрос игрока от 24.10.2026. Статус: аудит агентом, ещё не реализовано.

- [ ] Во всех видах заменить старые рисованные руки новыми принятыми 3D-руками.
- [ ] В 3D-виде оставить один вариант рук — 3D; убрать устаревший выбор «Рисованные».
- [ ] Перенести сохранённые настройки старых рук без сброса ракурса, видимости и позиции песни.
- [ ] Сохранить принятые форму и анимацию новых рук, проверить их контакт с белыми и чёрными
      клавишами в классике, аркаде и 3D.
