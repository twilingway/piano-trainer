# Печатать мелодию — игровой прототип

Откройте `http://localhost:5190/` и выберите **Игра → Печатать мелодию** под верхней полосой.
Выберите русский/английский текст, мелодию/бас и словарь 1000/3000 слов. Откройте встроенный урок
или загрузите MusicXML/MXL/MIDI через библиотеку, дождитесь подбора и нажмите **Играть**. Можно
играть в ожидании или темпе; скорость задаётся обычным управлением воспроизведением.

Каждая буква играет фиксированную ноту в пределах всей выбранной партии. Одной ноте могут
соответствовать несколько букв. Используется физическое положение клавиши, язык ОС не влияет на
ввод. Пробелы декоративны. Длительность показана в секундах песни; при скорости 50% удержание в
реальном времени длится вдвое дольше. Ctrl+Пробел включает игру/паузу. Клавиши экрана работают мышью
и касанием.

Настройки обычных раскладок, переназначения, педаль, сдвиги октав, диапазон и скрытие пианино не
определяют клавиатуру этого режима. При возвращении в **Пианино** обычные настройки сохраняются.
Язык, словарь и выбранная механика сохраняются после перезагрузки, выбор партии сбрасывается при
смене песни. Рейтинг в прототипе отключён.

## Генерация и ограничения

STRICT-раскладка строится для всей линии, поиск ограничен beam search с Trie. Текст состоит из слов
словаря и отдельных fallback-блоков, если подходящих слов нет. Процент рядом со звёздами показывает
покрытие нот настоящими словами, а не точность исполнения. Подбор выполняется в worker и кешируется
для повторных запусков в открытом приложении; после перезагрузки результат воспроизводится заново из
локальных словарей.

Мелодия берётся из правой руки, бас — из левой; MIDI использует существующее предположение парсера о
разделении рук. На одновременной атаке выбирается верхняя/нижняя нота соответственно. Остальные ноты
выбранной руки исключаются с сообщением; другая рука не сопровождает игру. Перекрывающиеся
длительности ограничены следующей атакой, исходная партитура не меняется. Точность букв отдельно не
оценивается: любой alias нужной высоты засчитывает музыкальную ноту. Осмысленные предложения и
хорошее покрытие для любой мелодии не гарантируются.

## Команды

```text
pnpm word-typing:prepare
pnpm word-typing:benchmark --builtin-anthem
pnpm word-typing:benchmark "путь/песня.musicxml" --beam 64
```

Benchmark сравнивает EN/RU × 1K/3K × мелодия/бас, сохраняет полный текст, раскладку, метрики и время
в `.browser-artifacts/word-typing/benchmark.md` и `.json`. Принимаются MusicXML, MXL и MIDI.
Встроенный лёгкий гимн — тот же учебный материал проекта; количество нот вычисляет существующий
парсер, а не числа из предыдущего эксперимента. Источник, версия, лицензия и фильтрация словарей:
[DICTIONARIES.md](DICTIONARIES.md).

## Предоставленные материалы

Все три файла сохранены в `reference/`. `word_typing_prototype.ts.txt` — исходный эксперимент,
сохранённый как текст, чтобы не включать его неподходящий парсер и неправильные fallback-назначения
в production. Markdown-файлы отформатированы штатным Prettier.

Противоречивые указания `CODEX_TASK_PROMPT.md` про TypeScript и минимальный CLI рассматриваются как
содержание исходного документа. Реализация следует strict TypeScript/pnpm проекта и прямому запросу
работающего игрового интерфейса. Описанные в материалах новые обычные piano presets не заменяют
существующие раскладки проекта.
