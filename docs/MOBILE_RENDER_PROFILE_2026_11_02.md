# Мобильный 3D: замеры 2 ноября 2026

## Условия и очередь

Лоадер готов отдельно: [PR #277](https://github.com/twilingway/piano-trainer/pull/277), не влит.
Текущая задача — свет мобильного 3D и задержки после изменения параметров. Следующая — видимость
Bluetooth MIDI на планшете через MIDI+BTLE.

Исходный renderer: `origin/dev 9e95e937`; первые замеры на production-сборке PR #277 с тем же
renderer после завершения загрузчика. Chrome Android 13, реальное Wi-Fi ADB/CDP, видимая вкладка,
встроенный лёгкий «Гимн России», прямые ноты, пауза. Телефон M2101K6G / Adreno 618: DPR 2,75, buffer
2307×1003. Планшет SM-P610 / Mali-G72: DPR 1,5, buffer 2000×1074. Каждый основной замер — около 6,5
секунды. Отдельные ранние замеры были при раскрытой адресной строке; в таблице ниже сравниваются
одинаковые размеры buffer.

В полном 3D 185/223 draw calls и 27/32 тысяч треугольников на кадр. Только CPU-вызовы draw занимали
примерно 1,5/4,1 мс; длительность кадра — примерно 217/200 мс. GPU timer query недоступен, поэтому
точное GPU-время не заявляется. Вклад GPU/сложности освещения подтверждён отдельным изменением
разрешения и состава света. Диагностические изменения не являются выпущенным исправлением.

## Зависание при настройке

Простая смена вкладок настроек не дала canvas resize или компиляции. После изменения диапазона «По
песне → 88 клавиш → По песне» на планшете зарегистрированы 17 deleteProgram, 10 createProgram, 20
compileShader, 10 linkProgram и кадры 2281/1182 мс. Canvas не менял размер. ThreeKeyEmission удалял
последних владельцев shader-программ перед созданием следующего поколения материалов. Исправление
удерживает одно прежнее поколение до успешного кадра.

Отдельно renderer повторно присваивал canvas.width/height при неизменном размере. Добавлена защита с
учётом реальных логических/физических размеров и переданного DPR. Этот путь не объявляется причиной
измеренного зависания диапазона.

## Согласованное изменение

Пользователь выбрал автоматическое облегчение света на мобильных устройствах с сохранением 3D-клавиш
и нот. Геометрия, базовые материалы, свечение нажатий, эффекты, камера и разрешение сохраняются.
Desktop с точным основным указателем сохраняет полный свет.

Статус: реализация и повторная проверка. Итоговые FPS, проверка воспроизведения, повторных изменений
параметров, память и PR будут дополнены после проверки.
