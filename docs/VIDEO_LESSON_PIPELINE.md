# Разбор локального видеоурока

Этот порядок одинаков для Codex, Claude Code и локального Qwen. Он готовит данные для проверенного
урока: речь преподавателя, её тайминг и кадры с табами. Все исходники и результаты остаются на
компьютере. Сервер, ComfyUI и LM Studio для этого процесса не требуются.

## Среда и команды

Нужны Node.js из проекта, Python 3.10+, FFmpeg/FFprobe в `PATH`, драйвер NVIDIA и CUDA PyTorch. На
этом компьютере выбран `faster-whisper` с моделью `turbo`, CUDA и `float16` для RTX 4090. CLI не
переключается незаметно на CPU. Обычная текстовая модель Qwen не является распознавателем речи.

В основной папке репозитория:

```powershell
pnpm lesson-video:setup --no-download
pnpm lesson-video:setup --model turbo
```

Первый вариант готовит и проверяет GPU без загрузки модели; второй также получает модель. Повторный
запуск использует локальный кэш. Для другой базовой Python-среды передать
`--python "C:\путь\python.exe"` только команде `setup`.

Скрипт создаёт `.browser-artifacts/lesson-analysis/.venv` с `--system-site-packages`, чтобы
использовать уже установленный CUDA PyTorch. Он ставит `faster-whisper==1.2.1` и
`ctranslate2==4.8.2` в локальную среду. Если CUDA PyTorch недоступен, устанавливает туда
`torch==2.7.0` из официального индекса `cu126`. Глобальная среда Python не меняется. Модели и
Hugging Face cache также находятся в `.browser-artifacts/lesson-analysis/`.

Python helper генерируется из tracked TypeScript в той же игнорируемой папке. Для Windows он
добавляет DLL из `torch/lib` в `PATH` только своего процесса. Загрузка модели использует проверяемый
HTTPS; `HF_HUB_DISABLE_XET=1` обходит зависающий Xet transport. Таймаут получения метаданных/данных
— 60 секунд. Если модель не загрузилась, проверить сеть и повторить `setup`; не отключать проверку
TLS и не загружать видео в сторонний сервис. Загрузка весов обращается к сети, распознавание самого
урока выполняется локально.

## От видео к расшифровке

Выбрать конкретный файл и согласованный с пользователем диапазон. Время можно задавать секундами,
`мм:сс` или `чч:мм:сс`, с дробной частью секунд. `--start` по умолчанию 0, без `--end` команда
обрабатывает оставшуюся часть видео. Для первого прохода лучше короткий фрагмент.

```powershell
$video = "G:\папка курса\Урок 01.mp4"
pnpm lesson-video:prepare --video "$video" --id lesson-01-60-120 --start 01:00 --end 02:00
```

CLI определяет длительность через FFprobe, извлекает выбранное аудио в mono PCM16 16 kHz, затем
распознаёт русскую речь с временными отметками слов. Пример выходной папки:

```text
local-lessons/.analysis/lesson-01-60-120/
  source.json                 исходный путь, размер и mtime
  metadata.json               источник, начало, конец, длительность и формат
  audio.wav                   только выбранный фрагмент
  audio-receipt.json          SHA256 успешно извлечённого аудио
  transcript.json             сегменты, слова и вероятность слова
  transcript.txt              текст для чтения агентом
  transcript.srt              субтитры для сопоставления с видео
  timeline-draft.json         кандидаты этапов по словам преподавателя
```

Все отметки в JSON/TXT/SRT — **абсолютное время исходного видео**, а не время от начала вырезанного
аудио. Например, первое слово фрагмента `01:00–02:00` имеет отметку около 60 секунд. `--id` содержит
только латинские буквы, цифры, дефисы и подчёркивания; пути через него запрещены.

Подготовленные файлы используются повторно только при совпадении пути, размера и времени изменения
исходника, точного диапазона, формата и контрольной суммы аудио. Проверяется также длительность WAV,
чтобы не принять незавершённое извлечение. Другой файл, изменённое видео, другой диапазон или другая
ASR-модель требуют нового `--id`. FFmpeg запускается с `-n`: оригинал и существующие аудио/кадры не
перезаписываются. После аварийного неполного вывода выбрать новый ID; не удалять исходное видео.
Выходные пути с перенаправлением за пределы репозитория через junction/symlink отклоняются.

При плохой речи можно сделать отдельный второй проход `--model large-v3` с новым ID. Модель
скачивается локально при первом использовании. Точность оценивается по самому фрагменту, а не по
названию модели.

## Этапы и нужные кадры

1. Агент читает TXT и JSON, отмечает объяснения правой/левой руки, соединение рук, названия нот,
   пальцы, счёт, повторы и смену упражнений.
2. `timeline-draft.json` помогает найти упоминания рук, но это только кандидаты с цитатой и
   временем. Слова о правой руке могут быть советом, а не началом нового этапа.
3. По нужным точкам извлекаются кадры исходного видео. Не пытаться просмотреть каждый кадр урока.

```powershell
pnpm lesson-video:frames --video "$video" --id lesson-01-60-120 --at 65,74.5,01:30
pnpm lesson-video:frames --video "$video" --id lesson-01-storyboard --every 30 --start 0 --end 10:00
```

`--at` — список абсолютных времён через запятую. `--every` — шаг обзорной раскадровки; эти режимы
несовместимы. По умолчанию максимум 80 кадров; `--max-frames` допускает 1–200. Если обзор превышает
лимит, CLI предлагает увеличить шаг или сократить диапазон. Кадры сохраняются в `frames/`, а
`frames.json` связывает каждый JPG со временем исходника с точностью до миллисекунды. Конец
диапазона не включается. Новые точки можно добавлять той же командой с прежним ID и тем же
источником.

4. Агент смотрит кадры с табами и положением рук. Если таб изменился между обзорными кадрами,
   запросить более плотные точки вокруг изменения. Сопоставить буквы, октавы, пальцы, одновременные
   ноты, длительности, паузы и повторы с аудио и показом клавиш.
5. Подготовить локальный план урока с этапами, фразами и ссылками на подтверждающие кадры/таймкоды.
   Записать неясности. Не выбирать октаву, ритм или границу этапа только по тексту ASR.
6. После проверки содержания сохранить MusicXML в `local-lessons/.course/<lesson>/`, затем
   подключить `local-lessons/course.json` по [описанию курса](LESSON_COURSE.md). Путь фразы в
   манифесте: `.course/lesson-01/phrase-01.musicxml`. Только проверенное содержание получает
   `reviewed: true`; этот pipeline никогда не делает это автоматически.

Глубина `.course/<lesson>/` отделяет новые фразы от старого импорта библиотеки.
`local-lessons/.analysis/`, `local-lessons/.course/` и `.browser-artifacts/` уже игнорируются git. В
публичный PR входят инструменты и документация, а не музыка, видео, аудио, модели или кадры курса.

## Речь, музыка и темп

ASR переводит речь в текст. Он может пропускать слова, путать названия нот и галлюцининировать на
музыке; вероятность слова не доказывает правильность. Длинный сегмент над музыкальным вступлением не
доказывает точный момент произнесения. Даже пустой текст не означает отсутствие музыки. Нужна сверка
с кадрами и прослушиванием спорного фрагмента.

Музыку нельзя получить как достоверные ноты MusicXML этим распознавателем. Отдельная транскрипция
фортепиано в MIDI может помочь, но должна проверяться по табам, клавишам и слуху. В этой версии
отдельный музыкальный транскриптор не установлен. Темп самого упражнения определяется по счёту,
атакам нот и указаниям преподавателя; скорость разговора и длина видео не являются BPM партитуры.
Ритм и октавы фиксируются до подключения фразы в курс.

## План для следующего агента

Сохранить `lesson-plan.md` в той же локальной папке анализа. Он содержит:

- Источник, ID анализа, интервал, ASR-модель и ссылки на JSON/SRT/кадры.
- Цель урока, предусмотренные этапы и рекомендуемый порядок фраз со стабильными ID.
- Для каждой фразы: начало/конец демонстрации, ноты с октавами, пальцы, длительности и паузы,
  одновременность рук, повторы и их порядок.
- Темп в BPM с единицей доли, источник подтверждения (счёт автора, видимый метроном или измерение
  атак) и уверенность. Изменения темпа указать отдельно. Видеосекунды не заменяют музыкальные доли.
- Неизвестные значения и противоречия, необходимые дополнительные кадры/прослушивание и вопросы.
- После сверки: соответствие каждой фразы её MusicXML и результат проверки в синтетическом
  тренажёре. До этого план и timeline остаются `reviewed: false`.

Для текстового Qwen передавать TXT/JSON и этот план. Кадры может разбирать модель с поддержкой
изображений; текстовому агенту нужны проверенные описания кадров от агента, который их видел. Не
приписывать обычной текстовой модели возможность видеть видео. Работа по этому документу не требует
отдельного инструмента Codex и сохраняет тот же формат для Claude Code.

Исходные инструменты: [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (CUDA/cuDNN,
отметки слов, VAD) и [PyTorch](https://pytorch.org/get-started/previous-versions/).
[Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) — отдельная модель распознавания речи для
возможного сравнения; обычный Qwen в LM Studio её не заменяет. Qwen3-ASR этим pipeline не
установлен.

Все команды работают в управляемом процессе без фоновых серверов. Ctrl+C останавливает текущий
дочерний процесс. `--help` у любой команды только показывает справку и не готовит файлы.
