# Текущая очередь исправлений — 26.10.2026

## Выполняется: отображение клавиатуры

- Сброс расположения: естественная глубина 3D-клавиш вместо старого 2D-соотношения.
- Ракурс «Игрок»: целые белые клавиши и видимые задние части с живыми руками и без них.
- Далее в этом этапе: подтвердить и устранить чёрные квадраты в скруглённых углах 2D-нот.

Сохраняются пользовательская камера, настройки классики/аркады/печати, исходная геометрия клавиш и
принятые руки. Стенд пользователя5190 не меняется; задача в отдельном worktree.

## Затем: удобство музыкального курса

1. Развести группы кнопок по вертикали.
2. Проверить исчезновение вариантов после отсчёта: переход должен иметь ясную инструкцию и доступное
   следующее действие, без застревания.
3. Первые задания без знаков при ключе; тон/полутон сначала на белых клавишах, изменения высоты
   вводятся позже с объяснением и примером. Сохранённый явный выбор сложности не стирать.
4. Вынести настройки из обрезаемого фрагмента учебной панели в отдельное доступное окно.
