# Задача: точные подсказки рук через скелет и меш

Статус: отложено. Сейчас цельные текстуры рук сохраняют исходные пропорции без растяжения;
независимую постановку каждого пальца реализуем позже через скелет и меш.

## Результат для игрока

Кончики всех задействованных пальцев совпадают с клавишами указанной аппликатуры. Рука не уходит под
клавиатуру; белые и чёрные клавиши учитываются по высоте и глубине. При движении ладони и сгибании
пальцев сохраняется узнаваемая форма руки.

## Предлагаемое решение

- Подготовить текстуру и сетку с весами привязки к костям ладони и пальцев.
- Разметить три фаланги обычных пальцев и две фаланги большого пальца.
- В чистом TypeScript рассчитывать положение суставов по целевым клавишам через IK.
- Ограничить растяжение, углы суставов и пересечения пальцев. Когда клавиша недостижима, перемещать
  ладонь; для несовместимой аппликатуры предусмотреть понятную подсказку.
- Рендерить деформацию сетки в Pixi и применять общую проекцию клавиатуры.
- Читать время PracticeSession; учитывать ожидаемый аккорд в режиме «Ждать ноту».

## Проверка готовности

- Левая и правая руки: одна нота, аккорд, октава, белые и чёрные клавиши вместе.
- Каждый видимый нажимающий палец соответствует номеру пальца из песни.
- Совпадение кончиков с клавишами сохраняется при смене камеры и размера окна.
- На паузе ожидания рука остаётся на нужных клавишах; смена аккорда не вызывает скачка.
- Чистые расчёты покрыты тестами, а анимация проверена в видимом браузере.
- Пройдены `pnpm check` и `pnpm spec:validate`.

Перед реализацией создать отдельное OpenSpec-изменение: согласовать пределы деформации, поведение
при недостижимом аккорде, формат ассетов и необходимость дополнительных зависимостей.
