# Профили пианино и тембры MIDI

В настройках «Пианино» можно выбрать профиль инструмента, изменить его название и выбрать тембр.
Профиль описывает команды встроенного звукового модуля пианино, а не содержит аудиосэмплы. Каталог
не меняет звук браузерного синтезатора.

В списке профилей доступно «Не выбран»: приложение не применяет каталог и его тембр. Этот выбор
сохраняется после перезагрузки. Добавление нового профиля и пример JSON остаются доступны;
возвращение к Grace не выбирает тембр автоматически.

Изначально выбран Grace BP-300, тембр — «Не менять». Встроенный каталог содержит 238 записей
VOI000–VOI237, переписанных с предоставленных владельцем страниц 15–16 бумажной инструкции. В
названиях сохранены исходные опечатки и повторы, в том числе Marimba 2 под номерами 139 и 140.
Фотографии и локальные ноты в репозиторий не включаются.

Для VOI000–127 указаны базовые MIDI Program Change. На реальном инструменте в этой сессии
проверялись рояль и Pan Flute (program 75); остальные записи не выдаются за аппаратно проверенные.
Для VOI128–237 команды банков неизвестны: эти тембры видны в каталоге, но отправлять и прослушивать
их нельзя до появления достоверной MIDI-таблицы. Нельзя просто отправить program 176: MIDI Program
Change принимает только 0–127.

## Импорт

Кнопка «Добавить пианино из JSON» читает один профиль. Пример поставляется как
[`public/examples/piano-instruments.json`](../public/examples/piano-instruments.json) и доступен для
скачивания рядом с описанием формата в интерфейсе.

```json
{
  "version": 1,
  "name": "Моё пианино",
  "midiOutputName": "Piano MIDI Device",
  "instruments": [
    { "name": "Рояль", "program": 0 },
    { "name": "Панфлейта", "program": 75 },
    { "name": "Дополнительный тембр", "panelNumber": 176, "program": null }
  ]
}
```

- `name` — название пианино; в записи тембра — название для списка.
- `program` — целое MIDI-значение 0–127. Если команда неизвестна, указывается `null`.
- `bankMSB` и `bankLSB` — необязательные целые 0–127, только при числовом `program`. Они
  отправляются как CC0 и CC32 перед Program Change. Значения берутся из MIDI-документации
  конкретного пианино. Если поля отсутствуют, приложение не отправляет выбор банка. Для возврата из
  дополнительного банка при необходимости укажите параметры основного банка явно.
- `id` — необязательный уникальный идентификатор тембра; без него используется индекс записи.
- `group` — необязательная группа списка; `panelNumber` — справочный номер на дисплее.
- `midiOutputName` — необязательное точное имя порта, помогающее автоматическому выбору выхода.
- `version` — необязательная версия формата, сейчас поддерживается 1.

Лимиты: файл до 1 МиБ, 1–512 тембров, до 64 пользовательских профилей, название до 120 символов.
Ошибочный файл отклоняется целиком, не меняя существующие настройки. Повторный импорт создаёт
отдельный профиль; встроенный каталог и прежний импорт не перезаписываются.

## Прослушивание

Выберите тембр и подключённый MIDI-выход, поставьте исполнение на паузу и нажмите «Прослушать
тембр». Прозвучит короткая простая мелодия на аппаратном инструменте. Её можно остановить; закрытие
настроек, смена назначения и запуск игры также прекращают её. Preview не перематывает урок и не
меняет оценку. При конфликте канала подсветки или неизвестной команде прослушивание недоступно с
пояснением.

Выбор профиля, его название и тембр сохраняются локально в браузере. Новые начальные настройки: 3D,
автоматический MIDI-выход и звук на обоих устройствах. Ранее сохранённые настройки, включая «Нет»
для MIDI-выхода, сохраняются.

## Проверка реализации 24 октября 2026

- `pnpm check`: 3227 тестов прошли, 10 пропущены; 23 проверки React Compiler и production build
  прошли. `pnpm spec:validate`: 68 объектов прошли.
- Независимое review проверило parser, сохранение, Auto, конфликты каналов и lifecycle preview.
  Preview отпускается синхронно перед запуском аудио урока; переименование не отправляет Program
  Change повторно. Таймеры и MIDI-эхо покрыты тестами.
- Видимый Chrome: 320×568, 390×844, 667×375 и 1366×768; RU/EN, прокрутка и формат JSON без
  горизонтального overflow. Импорт примера добавил три тембра; program 176 отклонён без изменения
  сохранённого каталога. «Не выбран» переживает reload.
- Через интерфейс и реальный Web MIDI Auto выбрал Piano MIDI Device при подключённом MiniFuse 2 MIDI
  Out. Выбор Pan Flute отправил Program Change 75 на канал 1, кнопка preview отправила короткую
  мелодию. Владелец подтвердил на слух звучание панфлейты. Остальные тембры, неизвестные банки и
  поведение других моделей аппаратно не проверены.

Функция поставляется отдельным PR в `dev`; проверка ветки не означает слияния или публикации сайта.
