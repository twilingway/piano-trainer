# Мировой горизонт нот

Горизонт содержит постоянные точки появления нот для каждой клавиши выбранного диапазона. Прямое и
перспективное поля сохраняют свои настройки отдельно. Он отличается от экранного горизонта
художественной проекции.

| Параметр  | Пределы                       | Что меняется                                                                    |
| --------- | ----------------------------- | ------------------------------------------------------------------------------- |
| Высота    | −100…100 м                    | Нижняя точка относительно белых клавиш; ноль и отрицательные значения допустимы |
| Дальность | 0…1000 м                      | Расстояние от задней линии клавиш                                               |
| Ширина    | 0,25…1000 м                   | Расстояние между крайними источниками — хорда дуги                              |
| Радиус    | от половины ширины до 10000 м | Кривизна окружности, без изменения ширины хорды                                 |

Все параметры доступны числом и ползунком с шагом 0,01 м. Слишком малый радиус ограничивается
половиной ширины; увеличение ширины при необходимости увеличивает радиус до того же геометрического
предела. Сохранённые значения используют ту же нормализацию. Пустое числовое поле не записывает
ноль; после ухода из него возвращается последнее допустимое значение.

«Линия» не использует кривизну, но сохраняет выбранный радиус. «Выпуклая дуга» поднимает середину,
«Вогнутая дуга» — края. Угловой шаг источников равномерный; отдельная клавиша остаётся по центру без
искусственного подъёма.

Старые настройки без радиуса получают радиус, равный ширине. При этом прежняя дуга в 60° и все
источники сохраняются. Настройки не очищают историю или сохранённую практику.

Ориентир H−30,05 м / D82,25 м / W95,25 м теперь помещается в допустимые пределы. Положение клавиш,
моменты попадания нот и музыкальное время от этих параметров не меняются. Большое поле учитывается
структурными bounds камеры.
