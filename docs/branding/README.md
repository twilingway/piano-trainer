# Логотип и карточка Нотопада

Выбран вариант 1: цветные падающие ноты над клавиатурой. Белые клавиши объединены в цельный блок,
чёрные клавиши удлинены, а границы белых проходят под ними. Цвета совпадают с палитрой игры.

## Прототипы

- [Три варианта рядом](prototypes.png), [векторный оригинал](prototypes.svg).
- [Падающие ноты](logo-1.svg) — выбранный вариант, [PNG 512×512](logo.png).
- [Клавиши «Н»](logo-2.svg).
- [Нота / Play](logo-3.svg).

Внизу листа показаны иконки размером 32 и 16 пикселей на светлой и тёмной вкладке.

## Подключённые файлы

- `public/favicon.svg` — основной масштабируемый favicon, совпадает с `logo-1.svg`.
- `public/favicon-32.png` — PNG для браузеров без поддержки SVG favicon.
- `public/favicon.ico` — совместимый вариант с размерами 16, 32 и 48 пикселей.
- `public/apple-touch-icon.png` — иконка 180×180 для добавления сайта на экран iOS.
- `public/social-card-ru-v3.png` — русская карточка «Нотопад», 1200×630.
- `public/social-card-en-v3.png` — английская карточка «Twiling Keys», 1200×630.

Исходники карточек — [social-card.svg](social-card.svg) и [social-card-en.svg](social-card-en.svg).
Они используют [app-preview.webp](app-preview.webp): реальный кадр публичной игры с встроенным
уроком, без пользовательских файлов. В кадре включены обе руки и одновременно нажаты клавиши обеих
партий: видны подсветка и эффект сгорания нот. Для изменения карточки править SVG и экспортировать
его в PNG 1200×630; оставлять `app-preview.webp` рядом с исходником. После изменения выбранного
логотипа синхронизировать его в `public/favicon.svg`, листе прототипов и карточке, затем обновить
растровые файлы.

## Метаданные и публикация

Данные `src/i18n/siteMetadata.ts` задают заголовок, описание, ключевые слова, canonical, Open Graph
и Twitter Card `summary_large_image`. Vite записывает их в исходный HTML для ботов без запуска
React:

- `https://keys.twiling.ru/` — английское превью с Twiling Keys; язык интерфейса определяется
  браузером.
- `https://keys.twiling.ru/ru/` — русское превью «Нотопад» и русская подсказка языка интерфейса.
- `https://keys.twiling.ru/en/` — английское превью Twiling Keys и английская подсказка языка.

Сохранённый ручной язык имеет приоритет над подсказкой URL. Смена языка обновляет метаданные в
браузере без изменения адреса или перезагрузки урока. Превью ссылки определяется её путём: для
русской карточки нужно отправлять `/ru/`. Все три страницы имеют собственный canonical и взаимные
ссылки hreflang ru/en/x-default. Картинки и адреса абсолютные, прежний домен сохраняется.

Имя пакета — `twiling-keys`; версия `0.0.<номер PR>` берётся из `package.json` и отображается в «О
программе» вместе с PR и SHA, если они переданы сборке. Версия обновляется по фактическому номеру
PR.

После публикации проверить, что HTML содержит новые теги, а изображение отдаётся с кодом 200 и типом
`image/png`. Затем проверить предпросмотр ссылки в Telegram и X: сервисы кешируют карточки, и
локальная проверка HTML не подтверждает фактический показ у них. При замене баннера использовать
новое имя файла и обновить оба `image`-тега, чтобы не зависеть от старого кеша.

Для Instagram автоматическая карточка зависит от места вставки ссылки. В Stories можно загрузить
готовый PNG и добавить стикер ссылки; обещать автоматическое изображение во всех экранах нельзя.

Источники: [Open Graph](https://ogp.me/),
[управление предпросмотром в Telegram](https://telegram.org/blog/reply-revolution),
[стикеры ссылок в Instagram Stories](https://about.fb.com/ja/news/2021/10/linkaccessstickers/).
Ключевые слова добавлены по запросу;
[Google их не использует для ранжирования](https://developers.google.com/search/docs/crawling-indexing/special-tags).
