# React Compiler

Vite использует стабильный Babel React Compiler через `reactCompilerPreset` из
`@vitejs/plugin-react` и `@rolldown/plugin-babel`. Компилятор работает при разработке и production
сборке; React 19 предоставляет `react/compiler-runtime`. Все дополнительные пакеты относятся к
`devDependencies`. Экспериментальный Rust-компилятор не используется.

Компилятор автоматически кеширует вычисления, функции и JSX с неизменившимися зависимостями.
Существующие `useMemo`/`useCallback`, от которых зависит жизненный цикл трейнера, остаются.
Компилятор не заменяет изоляцию частых подписок, корректные зависимости эффектов или очистку
ресурсов.

В режиме `test` компилятор отключён: проверки подписок и числа рендеров должны обнаруживать ошибки
архитектуры без помощи автоматической мемоизации. Обычные `pnpm dev` и `pnpm build` используют его.

## Проверка интеграции

Проверены `pnpm typecheck`, `pnpm build` и реальные dev-преобразования Vite. В преобразованных App,
LibraryDialog, SettingsPanel и ResultDialog присутствуют импорт compiler-runtime и кеши `_c(...)`;
Fast Refresh сохраняется. Production bundle содержит `useMemoCache` и `react.memo_cache_sentinel`.
Метрика продолжает добавляться только при сборке.

Однократный запуск logger стабильного `babel-plugin-react-compiler` 1.0.0 подтвердил успешную
компиляцию этих четырёх компонентов и `useTrainer`. Logger не включён в обычную сборку.

## Известные ограничения стабильного компилятора

Три существующих хука безопасно исполняются без автоматической мемоизации из-за неподдерживаемого
синтаксиса, который logger классифицирует как `Todo`:

- `useComputerKeyboard`: вычисляемое свойство в деструктуризации объекта.
- `useFullscreen`: `try` с блоком `finally`.
- `usePlayerLibrary`: `throw` внутри `try/catch`.

Эти пропуски не относятся к границам App и окон. Они не требуют отключения проверки правил React или
подавления диагностики; редкие операции клавиатуры, fullscreen и библиотеки сохраняют свой прежний
жизненный цикл. После обновления компилятора ограничения следует перепроверить.
