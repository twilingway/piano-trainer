## Что меняется

- До запуска текущая сцена декодирует нейтральный кадр, все достижимые проверенные C4/D4/E4-позы,
  нужные sprite sheets и звезду; SVG image href (включая ключ) проверяются перед present.
- Подготовка идёт через прежний presentation gate, параллельно audio prepare. PracticeSession
  остаётся единственными музыкальными часами. Demo count-in остаётся0, ученический — из PR323.
- Успешно декодированные изображения кэшируются; ошибки не кэшируются. Abort убирает обработчики;
  старые callbacks, смена сцены и StrictMode cleanup не запускают другую сцену.
- Ошибка необходимой картинки даёт явную локализованную ошибку и повторное открытие этапа.
  Отсутствующее обязательное изображение не считается готовым. Поздняя runtime img error тоже
  передаётся владельцу сцены. Старые/чужие sceneId игнорируются.
- Учитель использует один img, готовый src меняется без key/remount. В ожидании следующего кадра
  сохраняется последний декодированный кадр текущей сцены; другая сцена его не наследует.
- Портретный учитель увеличен примерно на8%; видимый силуэт центрируется по уже проверенному
  envelope x29..480/y16..528 кадра512×544. Ни один raster/source/alpha-файл не изменяется.
- Play/ученический отсчёт находятся вне потока, измеряют SVG content и клавиатуру. При тесном экране
  занимают область клавиш, не первые ноты. Resize/scroll/visualViewport zoom и замена SVG обновляют
  геометрию событиями, без нового frame loop.
- Hold: короткая полоса справа с зазором до соседних нот и пальцев. При плотности либо скрытой за
  pinned header головке остаётся64px подсказка ниже видимой нотной графики у курсора, с clamp к
  visualViewport. Текст Держи/Отпусти и реальный progress продолжаются. Подсказка исчезает только
  без актуального accepted hold или пригодной геометрии, при exit/hidden/stale/dispose.
- Производные четыре ми наследуют attributes/tempo после первого такта, без второго ключа и размера.
  XML learner содержит1clef/1time, четыре половинные E4, палец3, начала0/2/4/6,72BPM. Родительские
  MusicXML/hash/revision не меняются.
