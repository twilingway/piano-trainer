# Одинаковые фразы в маршруте

Основная дорожка показывает каждый музыкально одинаковый мотив один раз для игры с помощником и один
раз для самостоятельной игры. Высота, ритм с паузами, длительности, записанные пальцы, руки/партии и
полный размер фразы должны совпадать. Начальные знакомства, длительности и полный финал остаются
самостоятельными шагами. В первой мелодии основной список короче на четыре этапа.

Другие исходные повторения доступны через «Другие повторы». Выбор открывает прежний node ID, поэтому
сохранённые результаты остаются связанными с настоящими нотами и тактами. Валидный старый зачёт
повтора также отображается на основном представителе мотива, без переписывания receipt. Поддельный
либо неполный proof не создаёт звёзд. Счётчики отражают только основной список.

После явно выбранного старого повтора продолжение ищет следующий основной этап после его исходной
позиции. Это предотвращает возврат назад. Восстановление старого выбора не скрывает его материал.
Полная песня, исходные партитуры, sourceHash и порядок нот не меняются.

Локальные проверки: сигнатуры разных высот/ритмов/пальцев/рук/партий, строгий legacy credit,
раскрытие повторов и переходы. Видимую браузерную проверку выполняет интегрирующий root; эта запись
сама по себе не подтверждает слияние или публичный релиз.

Полный локальный гейт: pnpm check — 5228 тестов и 30 compiler tests, успешно; pnpm spec:validate —
99/99. Узкая проверка маршрута, старого зачёта, UI и переходов — 32/32. Browser и релиз не
заявляются.
