# Приёмка повторения за помощником — 5 ноября 2026

Стенд: ветка `fix/course-result-fit`, отдельный worktree, localhost:5191. Пользовательский
localhost:5190 не запускался и не останавливался. Эта запись подтверждает локальную приёмку; слияние

## Поведение

- Начальные notes/duration/guided сначала показываются помощником, затем после одного нового отсчёта
  начинается ответ ребёнка. Просмотр из меню возвращается в ready. Отмена, пауза, скрытие вкладки и
  прерывание звука не возобновляют старую попытку.
- По последнему уточнению пользователя обычный ответ идёт непрерывно в tempo. Отдельный review
  остаётся wait. Настоящие key-down/key-up оцениваются по высоте, началу и длительности. Проверенные
  старые wait-результаты обычных этапов сохраняются; финал требует tempo.
- До и ре дополняет отдельная исходная ми E4, палец 3, перед смешанной фразой. Старые IDs,
  sourceHash и результаты сохранены. Высота не сдвигается на октаву. В начальных notes/duration
  отключено сопровождение: низкий бас больше не маскирует учебный звук.
- Полоса ответа не движется в показе. Дорожка принятой ноты показывает «Держи» → «Отпусти» по
  PracticeSession, останавливается на паузе и не заменяет реальное отпускание при оценке.

## Видимая браузерная проверка

Проверены 320×568, 390×844, 667×375, 768×1024 и desktop 1920×1080, затем нативное окно 1689×1229.
Горизонтального переполнения нет. На 320 px середина результата прокручивается, действия остаются
доступны. Звёзды расположены в ряд; следующий шаг салатовый, повтор голубой. В игре один выход и
одна пауза. FPS не перехватывает клики меню. Play находится над клавиатурой, не меняет размеры SVG
при показе отсчёта, скрывается при открытом меню.

На короткой фразе SVG и viewBox совпали в ready, показе, обоих отсчётах и ответе. Четыре физических
нажатия C4 с отпусканием дали реальный результат 3/3: высота, начало и удержание по 100%. Для
каждого нажатия дорожка прошла промежуточное заполнение → 100% и подсказку отпускания. Отдельный
результат с удержанием 75% дал 1/3, обе кнопки полностью видны на 667×375.

На длинной исходной мелодии за 22 наблюдения scrollLeft изменился с 191 до 528, экранные координаты
закреплённых ключа, размера и курсора остались постоянными. Начальная маска закрывает исходный
движущийся префикс, оригинальный SVG остаётся доступен для экспорта. Полые и целые ноты сохраняют
написанную длительность. Desktop показывает полную клавиатуру; компактный экран — учебный диапазон.

Эмуляцию фиксированных 1920 px после проверки отключили: в более узком физическом окне она обрезала
правую часть и создавала ложное смещение. На нативном размере центр заголовка и Play совпадает с
innerWidth / 2. Это исправление среды проверки, а не изменение CSS.

Снимки находятся в локальном `.browser-artifacts/`: `course-final-ready-*.png`,
`course-final-result-*.png`, `course-final-long-staff.png`,
`course-final-native-window-centered.png`. Изображения в git не добавляются. Аппаратный USB MIDI и
субъективная слуховая оценка всех мелодий в этой приёмке не подтверждались.
