# Локальное сохранение удержания баса — P4b-3

Схема 7 добавляет `heldBass` в существующую IndexedDB `piano-trainer`, store `settings`, запись
`reading-course-v2`. Сохраняются seed, версия генератора, фильтр источника и последние 20
завершённых серий из десяти фрагментов. Выбор `held-bass-reading` и общие настройки помощи
переживают перезагрузку. Текущие удержания, незаконченная попытка и изменяемый clock не сохраняются:
курс открывается с первого фрагмента остановленным и требует нового нажатия «Играть».

Доказательства clock и ввода входят только в окончательный результат. Чистый валидатор заново строит
десять фрагментов из seed и версии генератора, проверяет идентичности, разрешённые атаки, достижение
музыкального конца баса по clock, физическое отпускание и закрытый горизонт доставки. Метрики
самостоятельности, помощь и ошибки сверяются с доказательствами. Достаточное прошедшее время при
неподвижном clock не доказывает удержание; итог с отсутствующим или поддельным clock отклоняется.
Повреждённые результаты исключаются из доступной истории с ошибкой чтения.

Миграция схем 1–6 добавляет пустое состояние удержания баса, сохраняя все допустимые прежние данные:
P1/P2-профиль, журнал предъявлений, интервалы, ритм, басовое чтение и координацию двух рук.
Результаты нового задания не обучают P2. Исходная запись `reading-course-v1` в localStorage остаётся
резервной копией без удаления или изменения.

Запись объединяется с последним содержимым базы в одной транзакции. Только изменённые поля заменяют
выбор серии, фильтр и общие предпочтения; истории sibling-курсов объединяются независимо. Уже
принятый runId не заменяется устаревшей копией из другой вкладки, одинаковый ID не добавляет второй
результат. История сортируется по времени завершения и ограничивается двадцатью сериями. Поздняя
загрузка не отменяет новый локальный выбор и завершённый во время загрузки результат.

Неизвестная будущая версия и повреждение блокируют запись поверх исходных данных. Ошибка чтения
также запрещает такую запись. При quota или abort результат остаётся в памяти, прежняя запись
сохраняется, оболочка сообщает о сбое. Запись считается успешной только после commit транзакции.

Старая вкладка схемы 6 при чтении схемы 7 использует свой прежний предел версии и отказывается
перезаписывать более новую запись. При откате клиента база не понижается и не очищается; после
обновления старые вкладки следует перезагрузить.
