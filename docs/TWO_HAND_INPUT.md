# Ввод для двух рук

Парное задание принимает физические down/up до обычной оценки ноты. Первая нота сама по себе не
получает hit; только окончательный результат политики подтверждает всю ожидающую группу через
PracticeSession. Музыкальное время остаётся у этой же сессии. Обычные песни, чтение одной ноты и
ритм сохраняют свои прежние маршруты ввода.

Сырые timestamps MIDI, ПК и экранных указателей передаются без замены временем доставки. Компенсация
устройства применяется отдельно, один раз. Политика пары сама проверяет свежесть, возраст, порядок и
физическое отпускание; старый ReadingAttackGate в этом пути не используется. Локальный звук ПК и
экранных клавиш включается сразу, до окончательной оценки.

Экранная клавиатура хранит pointerId → высота. Два касания удерживают разные клавиши независимо; два
владельца одной высоты дают один down и один up после последнего отпускания. Один указатель мыши при
перетаскивании сначала отпускает старую клавишу, затем нажимает новую, без защёлкивания. Плоские и
проекционные клавиши проходят через один stage-маршрут, без повторной доставки от sprite.

Реальный pointerupoutside сохраняет timestamp и считается физическим отпусканием. Pointercancel,
потеря capture, скрытие, blur и уничтожение обработчиков сначала отменяют попытку, затем очищают
владение. Синтетические up после очистки не служат доказательством успешной пары. Пауза, новая песня
и перемещение позиции также отменяют незавершённую попытку.

Программные тесты проверяют независимые указатели, общую высоту, drag, отмену до очистки, сохранение
timestamps и атомарный зачёт без частичного hit или обычного дубля. Проверка на настоящем
мультитач-экране, MIDI-инструменте и слышимость звука остаются отдельной аппаратной приёмкой.
