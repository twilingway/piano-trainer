# Чистое ядро «Играю два ритма»

`src/independentRhythm` не запускает таймеры и не двигает музыкальное время. Генератор создаёт
MusicXML; Song читается из этого XML. Проверка пульса — восемь четвертей C4, два такта. Основная
серия — четыре такта A,A,B,B в одном из шести порядков: A — C3 половинными и C4 четвертями, B —
наоборот. Всего24 атаки,12 каждой рукой,8 совместных начал. Темп60BPM, размер4/4. Одинаковые
seed/version воспроизводят ноты и IDs; nextSeed меняет порядок, произвольные seeds могут совпасть по
порядку.

Каждая фаза — отдельный `IndependentRhythmPhaseSession` с фиксированными run/presentation,
источником, MIDI-устройством и компенсацией. `present` подтверждает реально показанную партитуру;
`showKeys` принимает реально показанные клавиши только до старта. `start` требует полного
физического release. Новый проход и вторая фаза получают свежие presentation/Song; вторая фаза
наследует выбранный MIDI-канал первой. Первая доставленная свежая graded Down фиксирует канал, даже
если высота неправильная. Доставленная позже более ранняя raw-атака канал не меняет.

`tick` и `input` принимают реальные `PracticeSession.tempoClockReceipt`. Четыре секунды отсчёта
принадлежат этому clock, а не XML. Receipt содержит непрерывные actual anchors и фактический end
crossing. Начало музыкального нуля можно проецировать в будущем во время отсчёта; конец считается
наступившим только после crossing. Нулевой start/pause prefix Trainer.load не запускает курс.
Изменённый prefix, скорость, скачок времени, пауза или переполнение отменяют фазу без результата.

Оценка replay сортирует атаки по raw timestamp, затем delivery sequence. Доставки определяют канал,
raw replay определяет physical up/down и ближайший свободный noteId той же точной высоты. Окно
±150мс включительно; каждый член совместной группы получает собственный hit/miss. Два hit со
spread300мс допустимы. Неверная C2 — extra неизвестной руки, без подстановки физической руки. Рука
результата означает нотную партию, а не обнаруженную руку или палец исполнителя.

Raw age0..250мс включительно допустим, future и251ms Down игнорируются. Matching251ms Up отменяет
фазу и очищает только своего более старого владельца. Старый Up не снимает свежий Down; prefix
release не воскрешает владельца при поздней доставке. Автоповтор и несколько владельцев одной высоты
не создают новую атаку до общего release. Up duration, педаль, легато и пальцы не оцениваются.

Corrected time — raw минус фиксированная компенсация. Grade domain [−150мс,duration); первый−151
подготовительный. Miss появляется после actual crossing onset+150мс и строго позже performance этой
границы+max(0,offset)+250мс. Например, при offset+1000мс hit с corrected временем перед концом ещё
может прийти после actual end. При offset−1000мс miss всё равно ждёт actual crossing.

Финал требует actual end и строго now>endPerformance+max(0,offset)+250мс, без обязательного Up.
Удержание всё равно блокирует следующий старт. Восемь предварительных hit не открывают серию:
поздняя допустимая extra до закрытия горизонта делает проверку пульса неуспешной. Допуск не
сохраняется после отмены или reload; неуспешный пульс отдельно не попадает в историю.

`createIndependentRhythmResult` объединяет успешный pulse proof и завершённую основную серию,
которая может содержать ошибки. Strict validator заново строит обе партитуры, сравнивает XML и
fingerprints, проверяет identity/origin/offset/clock/input/help/deadline и replay всех метрик.
Результат — отдельная копия; входные массивы не разделяются с хранилищем. Лимиты каждой фазы: 256
input events,64 clock anchors,32 presentation/help receipts. Ничего не обрезается до видимости
валидного результата: overflow отменяет проход.

Сводка показывает hit/miss/extra, ранние/поздние начала и signed/absolute median deviation для
каждой нотной партии. Unknown extras учитываются в общей сумме. Median spread считается только для
совместных групп с двумя hit. Пустая выборка остаётся `null`. Фильтр источника выбирает целые
результаты со всеми ошибками. Это onset accuracy и учебный pulse gate, без заявления mastery,
самостоятельного чтения новых нот или изменения профиля P2. Настоящие MIDI/rollover/мультитач и
слышимость ждут совместной аппаратной проверки после всех шагов roadmap.
