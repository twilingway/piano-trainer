# Игра на компьютерной клавиатуре

Откройте **Настройки → Ввод с ПК**. Доступны три раскладки из KEYBOARD_LAYOUTS.md: «Широкий
диапазон» (по умолчанию, C2–D6), «По октавам» и «Бас и аккорды». Назначения показаны на макете.
Русский язык ввода не меняет физические клавиши.

Shift повышает новую ноту на полутон, Alt понижает; вместе они компенсируются. Чтобы сыграть C minor
в «Бас и аккорды»: удерживайте N, нажмите Alt+Comma, отпустите Alt, затем нажмите Slash. Уже
звучащие ноты не меняются от модификатора.

По умолчанию Space удерживает sustain, ArrowDown/ArrowUp сдвигают следующие ноты на октаву
вниз/вверх. Автоповтор октаву не сдвигает; смена раскладки сбрасывает регистр. Ctrl+Space включает
паузу; рестарт и библиотека доступны кнопками верхней полосы. Alt+P/R/L теперь играют ноты.

Нажмите правой кнопкой по клавише макета (либо обычным нажатием на сенсорном экране). Выберите ноту
с октавой, педаль, сдвиг октавы или отключение и нажмите «Сохранить». «Перехватить клавишу»
позволяет нажать другую физическую клавишу, в том числе цифрового блока; её текущее назначение
показано до сохранения. Исходная клавиша не переносится. Escape отменяет захват, «Отмена» закрывает
редактор без изменений.

Выбор и пользовательские назначения сохраняются отдельно для каждой раскладки. «Сбросить эту
раскладку» не удаляет изменения остальных. В текстовых полях обычный ввод сохраняется. При уходе из
окна удержания освобождаются. Системные и зарезервированные браузером сочетания могут не
доставляться странице и поэтому не назначаться.
