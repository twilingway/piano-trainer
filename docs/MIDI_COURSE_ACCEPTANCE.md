# Общая MIDI-приёмка курсов

По указанию пользователя аппаратную проверку выполняем после завершения шагов roadmap. Пока это план
проверки, а не подтверждение работы оборудования. Агент ведёт игрока по одному действию, ждёт
результат, сверяет экран и только затем даёт следующий шаг. Автоматические события браузера не
заменяют реальные нажатия. Перед общим проходом дополняем этот список реализованными P4b-3,
независимыми ритмами и следующими курсами; названия проверяем в актуальном интерфейсе.

## Подключение и исходное состояние

1. Игрок подключает включённое пианино USB MIDI и сообщает агенту, что готов.
2. Открываем основной `http://localhost:5190/` в видимом Chrome/Edge, обновляем страницу. Агент
   проверяет актуальную сборку. Пользовательский dev-сервер не перезапускаем.
3. Нажимаем «Настройки» → «Пианино», в поле «Пианино» выбираем конкретное устройство. Если браузер
   запрашивает доступ, игрок разрешает его. Если устройства нет, сначала разбираем подключение; не
   ставим галочку успешной проверки и не заменяем MIDI компьютерным вводом.
4. Записываем название устройства, USB/BLE, диапазон и используемый канал. Для C3–G3/C4–G4 нужен
   реальный доступ к обеим октавам; используем подписанное MIDI C4=60, а не только номер октавы в
   руководстве производителя. Транспонирование пианино проверяем диагностикой C3=48/C4=60.
5. По одной нажимаем и отпускаем C3, G3, C4, G4. На экране включается и выключается соответствующая
   клавиша. Отдельно проверяем звук пианино и программный звук/метроном, отмечая, что именно слышно.
   «Выход MIDI» и подсветку устройства не включаем без необходимости: они отличаются от входа.
6. Сохраняем исходные настройки игрока; не очищаем localStorage/IndexedDB и не удаляем историю.

## Текущие курсы: действия и ожидаемый результат

Каждый курс открываем кнопкой «Библиотека». Перед нажатием агент называет точную ноту с экрана и её
MIDI-высоту; примеры ниже не подменяют текущий случайный seed. Помощь включаем намеренно только в
проверке помощи, чтобы различать самостоятельность и решение после подсказки.

| Курс и кнопки                                                            | Что делает игрок                                                                                              | Что проверяем                                                                                                                                                       |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «Читаю пять нот» → «Читаю отдельные ноты» → «Играть»                     | Неверная высота, затем ожидаемая C4–G4; далее заканчивает серию                                               | Ошибка оставляет ноту, правильная продвигает; MIDI-источник и ошибка входят в результат                                                                             |
| «Читаю короткие фразы»                                                   | Играет ноты фразы по курсору, одну из них намеренно ошибочно                                                  | Продвижение, исправление, отсутствие потери физического off и переноса помощи на другие ноты                                                                        |
| «Проверяю чтение без подсказок»                                          | Выполняет новую серию без ручной помощи                                                                       | Нет названий/подсветки ответа; результат проверки отделён от упражнения                                                                                             |
| «Повторяю трудные ноты»                                                  | Завершает повторение после ошибки в тренировке                                                                | MIDI-попытки попадают в свой прогресс; это не новая проверка чтения с листа                                                                                         |
| Отложенная проверка P2                                                   | Открывает её, когда доступна по настоящему сохранённому сроку                                                 | Доступность и результат отдельны; агент не перематывает системные часы ради кнопки                                                                                  |
| «Интервалы» → «Вижу и играю пару»                                        | Играет две показанные ноты по очереди, повторяет на второй паре                                               | Нет зависания перехода, повтор высоты требует реальной повторной атаки                                                                                              |
| «Интервалы» → «Слышу и выбираю интервал»                                 | Слушает, затем выбирает ответ кнопкой                                                                         | Слышимость и учёт прослушивания; кнопочный ответ не называется MIDI-ответом                                                                                         |
| «Ритм» → «Читать и отбивать ритм» → «Способ ввода ритма»: «MIDI-пианино» | Отсчитывает четыре доли, отбивает начала нот одной клавишей; отдельно нажимает на паузе                       | Работа входа, onset/паузы и повтор серии; высота и длина удержания здесь не оцениваются                                                                             |
| «Левая рука: пять нот» → «Левая рука: отдельные ноты»                    | Читает C3–G3, затем нажимает правильную высоту в неверной октаве                                              | Октава проверяется, бас не превращается в мелодию первой октавы                                                                                                     |
| «Левая рука: короткие фразы»                                             | Завершает одну фразу и серию                                                                                  | Порядок/переходы и отдельная басовая история                                                                                                                        |
| «Две руки: играю вместе» → «Начать десять пар» → «Играть»                | Нажимает показанные две ноты вместе, удерживает, затем отпускает обе                                          | Первая атака не продвигает пару, после второй требуется release, окончательный зачёт только после проверки                                                          |
| Тот же курс: ошибки                                                      | Сначала отпускает первую до второй; в другой попытке добавляет третью ноту до release; затем правильно решает | По одной ошибке на попытку, та же пара, восстановление после полного отпускания; первый разрыв200/201 проверяется автоматическими тестами, а не секундомером игрока |
| Тот же курс: повтор                                                      | Завершает десять пар, снова нажимает «Играть», затем обновляет страницу                                       | Новый проход начинается первой парой; история сохраняется, незаконченная попытка не становится результатом                                                          |

## Общие аппаратные случаи

- Удержать клавишу до «Играть», затем начать: она не должна стать свежей атакой курса координации.
- Проверить обычные Note Off и Note On velocity0, если устройство реально позволяет выбрать оба
  варианта; невозможный на этом пианино вариант записать как непроверенный.
- В координации нажать педаль и физически отпустить клавишу: звучащая нота не доказывает удержание.
- На реально используемом канале проверить down/up; channel16 проверить только если настройка
  пианино доступна. Не менять чужие назначения устройства без согласованного шага.
- В незаконченной попытке поставить паузу, открыть настройки, переключить вкладку, отключить USB.
  Проверить отмену без ложного результата, отсутствие зависшего звука и свежие атаки после возврата.
- Между попытками сменить MIDI на ПК/экранный ввод; внутри совместной атаки смешать два источника.
  Первый случай допустим, второй должен получить объяснение и не стать успехом.
- После завершения обновить страницу и открыть историю с фильтром «MIDI-пианино»: прежние ошибки и
  помощь выбранных успешных MIDI-попыток не исчезают. История других курсов сохраняется.
- Отдельно проверить обычную песню с «Обе руки», «Ждать ноту» и «В темпе», аккорды, педаль и
  отпускания на flat/road. Курс координации не меняет правила обычной игры.

## Держу бас, играю мелодию — реализовано в159

Библиотека → «Держу бас, играю мелодию» → «Знакомство с удержанием баса», затем «Начать десять
фрагментов с басом» и «Играть». Агент сначала называет обе высоты и октавы по текущему seed, затем
даёт по одному действию. Человек не измеряет200/250мс секундомером — точные границы остаются
автоматическим тестам.

| Случай                 | Действие игрока                                                                               | Наблюдение                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Нормальный фрагмент2/4 | Нажать бас и первую RH, держать бас через все ожидания и следующие RH; отпустить по сообщению | Следующая RH только по курсору, после конца/release следующий фрагмент            |
| Ранний up баса         | Отпустить бас при остановке курсора перед следующей RH                                        | Ошибка и повтор всего текущего фрагмента после полного release                    |
| Педаль                 | Нажать педаль и отпустить физическую басовую клавишу до конца                                 | Педаль не заменяет удержание, тот же full retry                                   |
| RH overlap             | Перекрыть две соседние разные RH; отдельно удержать их и добавить третью                      | Две допустимы, третья требует отпускания старой; иначе ошибка                     |
| Wrong/early RH         | После первой группы сыграть неверную или явно раннюю RH                                       | Нет перехода за эту ошибку; весь фрагмент повторяется, завершённые остаются       |
| Pause иповтор          | На текущем фрагменте поставить паузу; отдельно завершить10 и снова нажать «Играть»            | Отмена без ложного итога, свежие атаки; новый полный проход и сохранённая история |

Реальные MIDI/каналы/NoteOff/слышимость этих случаев пока не проверены. Выполним совместно после
всех шагов, сохраняя пользовательское устройство и настройки.

## Играю два ритма — P4b-4

Библиотека → «Играю два ритма» → «Знакомство с двумя ритмами» или «Открыть проверку пульса».
Выбираем «Способ ввода двух ритмов» → «MIDI-пианино» и конкретное устройство в настройках. Ниже
перечислены действия для совместного аппаратного прохода; сейчас они **не проверены**.

1. Нажать «Начать проверку пульса». Прослушать четыре доли отсчёта, сыграть восемь четвертей C4=60,
   перед каждой повторной атакой отпускать клавишу. Нужны восемь попаданий ±150 мс и ноль лишних
   атак. После музыкального конца дождаться окончательной проверки.
2. Намеренно провалить отдельный пульс неверной нотой или пропуском. Кнопка «Начать два ритма»
   недоступна. «Повторить с проверки пульса» создаёт новый ручной старт; «Перейти к курсу «Ритм»»
   открывает подготовительное упражнение.
3. После успешного пульса отпустить все клавиши и нажать «Начать два ритма». До старта видны обе
   партии четырёх тактов. Ещё раз прослушать четыре доли. C3=48 играет левую партию, C4=60 — правую;
   там, где две ноты начинаются вместе, нажать обе. Порядок тактов агент называет по текущим нотам,
   не по заранее выбранному seed.
4. В отдельной серии сыграть только одну партию; в другой — неверную октаву. Время продолжает идти.
   Сводка показывает независимые попадания/пропуски каждой партии, лишние атаки и разрыв совместных
   попаданий. Удержание половинной, легато и педаль не оцениваются.
5. Удержать клавишу до старта второй фазы: старт должен ждать полного физического отпускания. В
   конце серии удержать последнюю ноту: итог появляется после горизонта доставки, а следующий старт
   снова ждёт отпускания. Нажатие педали не заменяет физический release.
6. После допуска открыть настройки, скрыть страницу или отключить устройство: незаконченный проход и
   допуск отменяются. Возврат начинается вручную с проверки пульса. Смена канала инструмента не
   должна решать ноты прохода: канал фиксируется первой допустимой атакой.
7. После завершения обновить страницу. В «История двух ритмов» остаётся завершённая серия; фильтр
   «MIDI-пианино» сохраняет её ошибки и помощь. Допуск и активная фаза не сохраняются.

## Следующие этапы

Для чтения с листа, гармонии и диктантов конкретные клики добавляются по реализованным правилам. Не
выдаём отсутствующие кнопки за уже существующие.

## Запись результата

Агент записывает для каждого случая: сборку/коммит, устройство/канал, урок/seed, действие игрока,
наблюдаемый переход и слышимость, результат «пройдено / ошибка / не проверено». При ошибке сохраняет
контекст и минимальный способ повторить её. В git не публикуются идентификаторы устройства, личная
история, записи исполнения или сторонние учебные материалы. Пользовательские данные остаются
локально; публичный verification содержит только обезличенное описание проверки.
