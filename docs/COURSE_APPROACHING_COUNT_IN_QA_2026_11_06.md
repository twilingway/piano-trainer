# Подход ноты во время отсчёта — проверка 06.11.2026

Production: `2c4a519e0c45ae2d44394efd5e7c101e1622f8ce`, ветка `fix/course-approaching-count-in`,
база dev после PR #330.

## Изменение

- Перед ответом ученика в текущем курсе 4/4 звучат четыре подготовительных удара.
- Отрицательная опорная позиция −4…0 использует время PracticeSession и равномерную ось стана.
- Слева предусмотрен запас прокрутки; первая нота подходит справа к центральной линии на нуле.
- Ключ и размер закреплены независимо от временной прокрутки. Движущиеся копии префикса скрыты
  внешним CSS только в текущем reader; standalone SVG сохраняет исходные символы.
- Щелчки разрешены данной сессией только до нуля. Постоянный метроном и его preference не меняются.
- Pause сохраняет уже услышанные удары, в том числе при паузе точно на ударе; future voices
  отменяются. Новый retry получает новую сессию и четыре новых удара.
- Показ Твили сохраняет немедленный старт без отсчёта; подготовка сама не даёт прогресс и оценку.
