# Нейтральная поза учителя

Один спокойный кадр сидящего учителя: обе руки готовы к игре, цветной метки и нажатой клавиши нет.
Это прототип для пауз и промежутков между нотами. В игровом контексте его проверяет основная задача.

- `idle-frame.webp` и `idle-frame.png`: 512×544, общая опора (256,528).
- `idle-source.png`: неизменённый результат встроенного image_gen.
- `generation-prompt.txt`, `manifest.json`: точный промпт, вход и SHA-256.
- `normalize_idle.py`: только механическая нормализация прозрачности, общий кроп, масштаб и опора.
- `qa/`: светлая и тёмная композиции, сравнение клавиатуры с принятым Ми и машинный отчёт.

Клавиатура остаётся зеркальной: высокие звуки слева для зрителя; группы чёрных клавиш 3–2–3–2. По
срезу исходника y=775 проверены десять чёрных клавиш: максимальный сдвиг центра после
масштабирования — 1 пиксель. Цвет, лицо, руки или отдельные клавиши программно не перерисовывались.
Ореола на проверенных светлой и тёмной подложках нет. Прозрачность кадра 0…255; WebP сохраняет RGBA
PNG побайтово. Фотооригинал человека и личные сцены Blender в набор не включены.

Повторение из этой папки: `python normalize_idle.py` (нужен уже установленный Pillow). Скрипт читает
существующий `../animation-prototypes/teacher/mi-press-v2.png` как точный референс. Для сочетания с
принятыми позами До/Ре/Ми используйте их `sheets/*-press-frame.webp`: верхние `*-press-v2.png/.webp`
сохраняют исходный холст 1536×1024 и не являются кадрами 512×544.

Есть небольшое различие силуэта и деталей лица между генерациями. Четыре кончика пальцев читаются
отдельно; полную анатомию пяти пальцев этот ракурс не подтверждает. Нейтральный кадр позволяет
правдиво показать отсутствие нажатия, но не заменяет полный плавный цикл «нажать — удерживать —
отпустить».
