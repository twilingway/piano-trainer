# Иллюстрации «Первых шагов»

11 оригинальных иллюстраций созданы встроенным OpenAI image_gen 26.10.2026. Образец right-hand
использован как reference стиля для остальной семьи. Точные prompts, исходные и финальные SHA-256,
размеры и вес — в manifest.json.

Изображения декоративные: конкретную ноту и рекомендуемый палец показывает интерфейс из материала
задания. Иллюстрации не используются для определения высот или аппликатуры.

Финальный формат: прозрачный WebP 256×256, alpha 0–255. Суммарно 138 666 байт. Нормализация: обрезка
по alpha >8 с полем 1,5%; вписывание в 232×232 на холсте 256×256, WebP quality 84, method 6. Личные
модели, чужие персонажи и локальные учебные партитуры не использованы. Исходные PNG остаются вне
Git.

Проверены контактный лист на тёмном фоне и карточки библиотеки при 1440×1000 и 390×844. Все 11
изображений загрузились; заголовок и действие остаются текстом HTML, доступным без изображения.
Невидимые изображения загружаются лениво.
