# Пробные анимации до, ре и ми

Статус: графические прототипы, ещё не подключены к игре. Новая генерация и ручная перерисовка при
нормализации не выполнялись.

## Файлы

- `sources/*-source.png` — полные исходники встроенного image_gen, скопированные без изменения
  байтов. Имена генераций и SHA-256 сохранены в `manifest.json`.
- `prompts.json` — точные промпты генерации. Этот файл при нормализации не изменяется.
- `sheets/*-sheet.webp` — три прозрачных листа 1280×1152, сетка4×3. Размер кадра320×384, общая опора
  нижнего центра — (160,360).
- `previews/*-neutral.webp` — спокойное ожидание с морганием.
- `previews/*-correct.webp` — улыбка и радость.
- `previews/*-gentle-wrong.webp` — лёгкое удивление, огорчение и возвращение к спокойному лицу.
- `qa/contact-dark.webp`, `qa/contact-light.webp` — все36кадров на тёмном и светлом фоне с линией
  общей опоры.
- `qa/report.json` — размеры, исходная альфа, дрейф силуэта и проверки кодирования.
- `normalize.py` — повторяемая нарезка из сохранённых `sources`, требует уже установленный Pillow.

## Сетка и время

Строки: neutral, correct, gentle-wrong. В каждой4кадра слева направо. Координаты кадров, исходные
обрезки и переносы записаны в manifest. Длительности задаются отдельно для каждого состояния.
Анимированные WebP зациклены только для просмотра; в игре правильный ответ и ошибка должны
проигрываться один раз с последующим возвратом в ожидание.

Нормализация выполняет только целочисленный перенос и обрезку с запасом8px. Масштаб, пропорции, свет
и фактура рисунка сохранены. Рабочая альфа внутри обрезки не изменялась. Невидимые RGB-пятна
исходников имеют alpha1–7/255: поэтому просмотрщик, который игнорирует альфу, может показывать
цветной мусор. На проверенных светлой и тёмной подложках он визуально не мешает. Полные исходники
сохранены для контроля.

## Ограничения

У персонажей нарисован флажок восьмой ноты. Они подходят как отдельные персонажи и проба эмоций, но
не как универсальная замена целых, половинных и четвертей на нотном стане. Для учебной записи
понадобятся варианты с верной длительностью либо отдельно анимируемые лица при правильной форме
музыкального знака.

Силуэт исходных кадров отличается по ширине максимум на1px, по высоте максимум на1px. После переноса
нижняя опора совпадает во всех кадрах. Текстура и черты лица немного различаются между кадрами; это
не строгое скелетное движение. Контактные листы визуально проверены, сохранностьRGBAпосле WebP
подтверждена побайтовым декодированием, у каждого из9превью проверены4кадра. В игровом рендерере, на
мобильном устройстве и в реальном времени анимация ещё не проверялась.

Открыть любое `previews/*.webp` можно в браузере или просмотрщике с поддержкой анимированного WebP.
Не масштабировать спрайты неравномерно; при использовании атласа ограничивать выборку
прямоугольником кадра.
