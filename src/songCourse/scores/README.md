# Партитуры курса

Шесть MusicXML-файлов здесь созданы для этого курса самостоятельно. Исследованные учебные издания
служили проверкой диапазона, мелодического контура и учебных трудностей; их PDF, оформление,
аппликатура и готовые аккомпанементы в репозиторий не переносились.

- «Горячие булочки» — полная короткая мелодия на до, ре, ми; четверти, половинные и целые.
- «Тётушка Роди» — полная короткая учебная мелодия на до, ре, ми, фа.
- «Лодочка» — собственная одноручная адаптация с размещением всей мелодии в первой октаве.
- «Ода к радости — учебная тема» — адаптация темы Бетховена: ритм и средняя фраза упрощены до
  четвертей и половинных в диапазоне до–соль. Это учебная тема, не вся симфония.
- «Звёздочка» — полная короткая мелодия на до–ля. Аппликатура включает замену пальца на повторной
  соль и перенос руки к ля.
- «Радость миру — начальный мотив» — только начальный нисходящий мотив из восьми ступеней,
  транспонированный в до мажор для одной правой руки. Пунктир, восьмая и завершающая пауза
  сохранены; после фа первым пальцем третий переносится на ми.

Компьютерное сопровождение во всех файлах — собственный простой басовый пульс в отдельной партии.
Партии и руки назначаются явно манифестом; сопровождение не является неявно «другой рукой» ученика.
Звуки и длительности загружаются из XML.

`manifest.json` хранит версию, SHA-256 точного XML, число тактов и исходные ID нот ученика по
тактам. Тесты сверяют их с партитурами. Канонический ID имеет вид `songId@revision:xmlNoteId`; при
извлечении фразы он сохраняется, хотя runtime ID меняется.
