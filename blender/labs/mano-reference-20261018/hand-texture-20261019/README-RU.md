# Текстура кожи правой руки (до локтя) — 2026-10-19

Решения пользователя: пианист одет, качественные материалы нужны только кистям и лицу;
кожу руки делаем до локтя. На сайте SMPL есть только UV-развёртка SMPL (OBJ, за логином,
с 11.09.2020), текстур нет — поэтому своя развёртка + генерация Codex по видам.

Сделано:
- `export_flat_hand.py` — нулевая поза SMPL-H (пальцы прямые, ладонь плоская), правая рука:
  `flat-hand.obj` (кисть + 6 см), `HAND_PIECE=arm` → `flat-arm.obj` (до локтя + 3 см);
  `.json` хранят номера вершин и граней SMPL-H. Кисть 197 мм от запястья.
- `render_views.py` (Blender -b --factory-startup) — 5 ортовидов (dorsal, palmar,
  thumb-side, little-side, fingertips) + маски + `cameras.json`: `views/` кисть 0.255 мм/пикс,
  `views-arm/` рука 0.491 мм/пикс.
- `uv_unwrap.py` — развёртка руки до локтя: шов по линии тыл/ладонь, 2 острова, minimum
  stretch; `arm-uv.json` (грань SMPL-H → 3 UV, порядок углов как в model['f']),
  `flat-arm-uv.blend`, проверка `uv-sheet.png` — сетка ровная. ~0.1 мм/пикс на кисти при 4096.
- Codex (`codex-hand-prompt.md`, 516k входных токенов) → `generated/` 5 видов кисти.
  Совпадение силуэта с маской (IoU): dorsal 0.95; palmar 0.59, thumb-side 0.51,
  little-side 0.57, fingertips 0.38 (сдвиг/масштаб до ~50 пикс) + остаточное затенение.

- `align_views.py` (python -I) → `generated-aligned/`: аффинная регистрация силуэта
  (моменты + ECC) и нежёсткая доводка по контуру (ближайшая точка контура, гауссово
  размытие сдвигов σ=15, 2 прохода). IoU: dorsal 0.95→0.99, palmar 0.59→0.99,
  thumb-side 0.51→1.00, little-side 0.57→1.00, fingertips 0.38→0.99; зазор по краю ≤3.8 пикс
  (≤1 мм), доводка двигает кожу максимум на 10 пикс. Альфа = маска рендера. Листы:
  `sheet.png` (до/после), `residual-sheet.png`, `zoom-sheet.png`, параметры в `align.json`.
  Остаточное затенение (низ боковых видов, fingertips) не убрано — решать на шаге 2.

- `export_subdiv.py` (Blender -b) → `subdiv-hand.npz`: кисть с subsurf 2 (та же поверхность,
  что в рендерах), UV внутри базовой грани линейно (`uv_smooth = NONE`).
- `bake_views.py` (python -I, ~35 с) → `bake/albedo-4096.png`: проекция 5 видов, видимость по
  буферу глубины, вес cos⁴ × затухание 10 пикс у края кожи вида, смешивание в линейном цвете,
  один коэффициент на канал для боковых/fingertips по перекрытию с dorsal/palmar (поле
  коэффициентов по UV пробовали — пятна). 2.4% текселей кисти без вида — заполнены от соседей.
  Env: `TEX`, `BAKE_VIEWS`, `TAG` (вариант `bake-notips/` — без fingertips, хуже).
- `check_bake.py` (Blender -b) → `bake/check-*.png` + `hand-textured.blend` (текстура
  упакована, вьюпорт смотрит на руку). Сравнение: `bake/compare-variants.png`.
  Остаётся: торец среднего пальца (его не видит ни один вид, а в fingertips Codex нарисовал
  его иначе) и чуть темнее подушечка большого пальца.

- Боковины пальцев между пальцами (полосы и клочки, скриншоты пользователя): поза с
  раздвинутыми пальцами `HAND_POSE=spread` (`export_flat_hand.py` → `spread-hand.obj`, те же
  грани), 4 косых вида под 45° (`render_views.py` → `views-spread/`), Codex
  (`codex-spread-prompt.md`, 866k вход / 792k из кэша, 6 мин) → `generated-spread/`,

  (`PATCH_WEIGHT=0.1`): на полном весе они размывали складки костяшек и вены. Тексели без
  вида: 91 452 → 6 044. Было/стало: `bake-5views/` и `hand-textured-5views.blend`;
  `bake/compare-patch.png`, `bake/compare-sides-zoom.png`. Осталась мелкая тёмная метка у
  одной перепонки.

- Смягчение швов (просьба пользователя: «на всех границах и швах смягчение»), всё в

  пальцем, `OCCLUSION_FADE_PX`); двухполосное смешивание — тон переходит между видами по
