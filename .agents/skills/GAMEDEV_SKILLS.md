## Применение

- Загружать только навык текущей задачи. Общий router и остальные навыки каталога не установлены.
- Сохранять единое время `PracticeSession`: примеры адаптировать к существующему кадровому циклу,
  не добавлять отдельный источник времени песни.
- GLSL адаптировать к WebGL2 и материалу Three.js; проверять в браузере.
- Для профилирования использовать Chrome и Three.js. Сравнивать один сценарий на одном устройстве;
  примеры Godot/Unity/Unreal не переносить буквально.
- Изображения генерировать через доступный imagegen. В сценариях `ref2game` сохранять его процесс.
- Скриптам графики нужен Pillow из `create-game-assets/scripts/requirements.txt`. Он не добавлен
  в зависимости приложения; при необходимости использовать отдельное локальное окружение.
- Музыкальные данные, аппликатура, оценка исполнения и синхронизация остаются в предметных
  модулях проекта.

## Обновление

Обновлять выбранные папки целиком с явно выбранного коммита. Сохранять `LICENSE` и `NOTICE`,
проверять локальные ссылки и комплектность, затем запускать проверки проекта. Не устанавливать
весь каталог и не обновлять зависимости приложения автоматически.
