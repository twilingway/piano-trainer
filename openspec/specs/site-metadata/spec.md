# site-metadata Specification

## Purpose

Определяет названия, описания и превью Twiling Keys / Нотопад для русского и английского интерфейса,
локализованных ссылок и сборок с версией по номеру PR.

## Requirements

### Requirement: Версия сборки по PR

Пакет SHALL называться `twiling-keys`. Версия package.json SHALL иметь формат `0.0.<номер PR>` для
PR, содержащего изменение сборки, и SHALL отображаться в разделе информации о сборке вместе с
доступными PR и SHA. Локальный режим SHALL показывать версию пакета с отметкой локальной сборки.

#### Scenario: PR сборки

- **WHEN** изменение оформлено в PR с номером N
- **THEN** package.json содержит version `0.0.N`, а информация о сборке показывает эту версию

### Requirement: Локализованный бренд и метаданные

Название SHALL быть «Нотопад» для русского интерфейса и «Twiling Keys» для английского. Заголовок
вкладки, описание, ключевые слова, названия и описания Open Graph/Twitter Card и описание
изображения SHALL соответствовать выбранному языку до первого рендера и после переключения.
Canonical, og:url и hreflang SHALL сохранять идентичность адреса независимо от ручного языка.
Переключение SHALL сохранять текущую песню, позицию, адрес и пользовательские данные.

#### Scenario: Смена языка

- **WHEN** игрок переключает интерфейс RU на EN
- **THEN** название, title и description переходят на Twiling Keys и английский текст без
  перезагрузки

#### Scenario: Идентичность адреса при переключении

- **WHEN** на `/ru/` игрок выбирает English
- **THEN** title и описание английские, а canonical и og:url остаются `/ru/`

### Requirement: Статическое превью локализованной ссылки

Сборка SHALL содержать HTML для `/`, `/ru/` и `/en/`, читаемый без JavaScript. `/ru/` SHALL иметь
русские метаданные и карточку «Нотопад», `/en/` — английские с «Twiling Keys», `/` — английское
превью. Карточки SHALL иметь размер 1200×630 и отдельные версионированные URL. Страницы SHALL иметь
собственный canonical и og:url, взаимные hreflang ru/en и x-default для корня. Общие ассеты и
production-only аналитика SHALL оставаться доступными для каждого входа.

#### Scenario: Бот читает русский URL

- **WHEN** бот получает сырой HTML `/ru/`, не исполняя JavaScript
- **THEN** он получает русские title, description, Open Graph, Twitter Card и изображение

#### Scenario: Обычная ссылка в русском браузере

- **WHEN** русский браузер без ручного предпочтения открывает `/`
- **THEN** приложение показывает Нотопад, а сырой HTML обычной ссылки остаётся английским для ботов

#### Scenario: Английская карточка

- **WHEN** бот читает `/en/`
- **THEN** описание и запечённые подписи карточки английские, изображение доступно как PNG 1200×630

#### Scenario: Нормализация локализованного URL

- **WHEN** открывается `/ru` или `/ru/index.html`
- **THEN** canonical и og:url указывают на `/ru/`; английские варианты нормализуются к `/en/`
