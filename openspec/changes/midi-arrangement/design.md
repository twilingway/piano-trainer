## Context

После `midi-part-roles`, `practice-parts` и `midi-score` у MIDI-песни есть партии с ролями, руки по
ролям и стан, записанный из нот (`withWrittenScore`). `useSong` держит загруженную песню
(`sourceSong`), транспонирует её в `baseSong` и решает аппликатуру; ключ аппликатуры и дублей —
`overridesKey(baseSong)` по названию и числу нот. Мотивация — в proposal.md.

## Goals / Non-Goals

**Goals:** упрощение — чистая функция `Song → Song`, проверяемая без интерфейса; версия выбирается
до транспонирования, так что всё дальше работает без изменений.

**Non-Goals:** упрощение ритма, уровни сложности, MusicXML.

## Decisions

### D1. `simplifiedSong` в `src/song/arrangement.ts`

Ноты каждой руки группируются по началу (`startBeat`, шаг 1/8 четверти). Правая группа →
`rightChord` (верх мелодии и до двух ближайших нот в октаве под ним), левая → `leftChord` (бас и до
двух звуков, перенесённых в октаву над ним, по таблице предпочтений). Затем `oneVoice` обрывает ноты
на следующем начале руки (двоичный поиск по началам), подъём правой руки по процентилям регистров,
перенос за пределами 88 клавиш. Ноты сохраняют id и время MIDI; изменённые ноты — копии. Стан —
`withWrittenScore` с концами нот через `quartersAt` и ключевыми знаками из стана оригинала. Песня из
MusicXML возвращается как есть.

### D2. `Song.simplified` и ключ

У упрощённой песни `simplified: true`; `overridesKey` добавляет `:simplified`, поэтому аппликатура,
состояние тренажёра и дубли версий не смешиваются. Ключи оригинала не меняются.

### D3. Выбор в `useSong`

`simplified` — состояние `useSong`, сбрасывается в `showSong` и `openLesson`.
`arranged = simplified ? simplifiedSong(sourceSong) : sourceSong` идёт в `transposeSong`;
тональность определяется по оригиналу. Массив партий тот же, поэтому выбор партии (`practice-parts`)
переживает смену версии. `useSong` отдаёт `arrangement` только для MIDI; `App.tsx` передаёт его во
вкладку «Песня» одной строкой (лимит 500 строк).

## Risks / Trade-offs

- Перенос аккордов в октаву над басом даёт тесное звучание в низком регистре; зато аккорд всегда
  берётся одной рукой.
- Оркестровый MIDI (15 дорожек) сокращается вдвое и остаётся плотным: роли аккомпанемента сливаются
  в левую руку. Упрощение ритма — отдельная задача.
- Файл с одной дорожкой ниже до первой октавы целиком уходит в левую руку — наследие деления по
  высоте, вне этого изменения.
