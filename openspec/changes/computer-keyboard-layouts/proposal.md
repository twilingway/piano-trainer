# Три раскладки и настройка компьютерной клавиатуры

## Why

Текущая компьютерная клавиатура даёт только фиксированную раскладку без редактора. Игроку нужны три
раскладки из предоставленного KEYBOARD_LAYOUTS.md и назначение физических клавиш на визуальном
макете по образцу Everyone Piano.

## What Changes

- Добавить «Широкий диапазон», «По октавам» и «Бас и аккорды» с точными таблицами из файла.
- В новых раскладках Shift повышает ноту на полутон, Alt понижает; вместе они компенсируются.
- Добавить макет компьютерной клавиатуры: правая кнопка открывает редактор назначения, игрок
  выбирает ноту с октавой либо sustain/сдвиг октавы/отключение и может захватить физическую клавишу
  нажатием. Дать доступ к редактору также обычным нажатием для сенсорных экранов.
- Сохранять выбранную раскладку и её пользовательские назначения после перезагрузки, дать сброс
  выбранной раскладки без потери настроек остальных.
- Заменить нынешнюю раскладку тремя новыми; по умолчанию выбрать «Широкий диапазон».
- **Согласовано игроком:** Alt+P/R/L играют бемоли, пауза доступна через Ctrl+Space, рестарт и
  библиотека — через кнопки интерфейса.

## Capabilities

### New Capabilities

- `computer-keyboard`: раскладки, назначение клавиш, модификаторы, перехват и безопасное отпускание.

### Modified Capabilities

Нет: правила оценки и источник времени сессии не меняются.

## Impact

Модули ввода, useKeyInput, useShortcuts, настройки клавиатуры и композиция App. Новые
production-зависимости, сетевые сервисы и публикация сторонних ресурсов не нужны. Цель — игра и
настройка в браузере. Системное переназначение клавиатуры и гарантированный перехват сочетаний ОС не
входят в задачу. Приложение отменяет доступные ему события назначенных клавиш; недоступные браузеру
сочетания остаются ограничением платформы.

Исходный файл использован как данные требований, а не как инструкция агенту.
