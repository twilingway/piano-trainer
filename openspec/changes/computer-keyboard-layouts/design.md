# Дизайн

## Context

Сейчас таблица нот встроена в midiInput, а useShortcuts использует Alt+P/R/L. Игрок согласовал
полную замену раскладки и освобождение Alt для нот. См. proposal.md и
specs/computer-keyboard/spec.md.

## Goals / Non-Goals

Чистые модули src/input владеют таблицами, проверкой назначений и состоянием удержаний. React
показывает макет; хук src/app хранит предпочтения; DOM-адаптер только передаёт события. Сессия,
MusicXML, MIDI и кадровый цикл не получают новых источников времени.

## Decisions

- Использовать event.code, а не event.key: ноты сохраняются при смене языка ОС.
- Хранить три независимых набора изменений в version=1; некорректные данные отвергать. Временный
  сдвиг октавы не сохранять. Начальный пресет — octave_layout; сохранённый выбор не заменять.
- Фиксировать pitch при keydown и агрегировать одинаковые ноты счётчиком удержаний. Передавать одну
  атаку и финальное отпускание, чтобы существующий Set в Trainer был корректен.
- У sustain удержание, у действий октавы однократный шаг ±12; исходные дополнительные назначения:
  Space — sustain, ArrowDown/ArrowUp — октава. Эти клавиши видны и редактируемы.
- При изменении назначения, смене пресета, открытии редактора и потере фокуса очищать удержания.
  Захват изолировать capture-listener от игры и shortcuts, отменять Escape.
- Захват выбирает существующее назначение физической клавиши и показывает его перед сохранением:
  никакого молчаливого перемещения/удаления другого назначения.
- Любая назначенная нота, в том числе чёрная, получает Shift/Alt-поправку при следующей атаке.
- Sustain звука реализовать в адаптере: отпускания передавать тренажёру сразу, освобождение звуков
  откладывать до отпускания педали. Повторная атака отменяет отложенный release.
- Убрать Alt shortcuts, сохранить Ctrl+Space; поле ввода/редактор не управляют плеером. Согласовать
  это с активной спецификацией player-ui.

## Risks / Trade-offs

- ОС/браузер может не доставлять некоторые сочетания → пояснение в UI, захват только доставленных
  событий, без обещания полного Keyboard Lock.
- AltGr иногда приходит с Ctrl → разрешать AltGraph как Alt, обычный Ctrl не играть.
- Физический предел одновременных клавиш → программа обрабатывает все доставленные события, но не
  устраняет аппаратный rollover.
- Частые рендеры → состояние на каждую игровую атаку не хранить в React, оставить в адаптере; новые
  модули не подключать к кадровому циклу или OSMD.

## Migration Plan

Новый ключ предпочтений не затрагивает песни и другие настройки. Старый tracker-вариант заменяется
согласно ответу игрока. Новых зависимостей нет; откат — revert изменения.
