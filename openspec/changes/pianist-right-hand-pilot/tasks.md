# Задачи пилота правой кисти

## 1. Основа стенда

- [x] 1.1 Сохранить отдельную сцену цельного SMPL+H с существующим пианино; проверить пути, масштаб
      модели и ширину клавиши 23,5 мм.
- [x] 1.2 Проверить нейтраль, большой палец, сгиб указательного и локоть против исходного
      вычислителя; сохранить отчёт сравнения поверхности.

## 2. Правая кисть

- [ ] 2.1 Подготовить форму, кожу, ногти и соединение запястья без смены исходных пропорций по
      отдельным осям; сохранить крупные виды сверху, сбоку и общий вид.
- [ ] 2.2 Подготовить естественное положение покоя над клавиатурой и проверить отсутствие
      пересечений финальной поверхности.

## 3. Одиночные нажатия

- [ ] 3.1 Сохранить C4/D4/E4/F4/G4 пальцами 1/2/3/4/5 с пересчитанной деформацией и дискретным
      переключением; проверить постоянство сетки, длин и масштаба.
- [ ] 3.2 Проверить зазор целевой поверхности не более 1 мм, проникновение не глубже 0,5 мм,
      соседние белые/чёрные клавиши и межпальцевые пересечения; сохранить локальный отчёт PASS/FAIL.
- [ ] 3.3 Просмотреть каждую позу сверху и сбоку; сохранить изображения и отметить визуальные
      ограничения отдельно от геометрического результата.

## 4. Проверка и передача

- [ ] 4.1 Провести независимое ревью геометрии, исходных файлов и соблюдения локальности; устранить
      блокирующие замечания.
- [x] 4.2 Выполнить pnpm check и pnpm spec:validate на ветке задачи; зафиксировать точные причины
      недоступных проверок.
- [ ] 4.3 Подготовить PR только с разрешённой документацией в dev; проверить отсутствие приватных
      моделей в индексе и ветку основной папки dev.
- [ ] 4.4 Получить визуальную приёмку пользователем формы кисти и пяти нажатий на стенде Blender; не
      считать численный PASS такой приёмкой.
