# Задачи пилота правой кисти

## 1. Основа стенда

- [x] 1.1 Сохранить отдельную сцену цельного SMPL+H с существующим пианино; проверить пути, масштаб
      модели и ширину клавиши 23,5 мм.
- [x] 1.2 Проверить нейтраль, большой палец, сгиб указательного и локоть против исходного
      вычислителя; сохранить отчёт сравнения поверхности.

## 2. Правая кисть

- [x] 2.1 Подготовить форму, кожу, ногти и соединение запястья без смены исходных пропорций по
      отдельным осям; сохранить крупные виды сверху, сбоку и общий вид.
- [x] 2.2 Подготовить естественное положение покоя над клавиатурой и проверить отсутствие
      пересечений финальной поверхности.

## 3. Одиночные нажатия

- [x] 3.1 Сохранить C4/D4/E4/F4/G4 пальцами 1/2/3/4/5 с пересчитанной деформацией и дискретным
      переключением; проверить постоянство сетки, длин и масштаба.
- [x] 3.2 Проверить зазор целевой поверхности не более 1 мм, проникновение не глубже 0,5 мм,
      соседние белые/чёрные клавиши и межпальцевые пересечения; сохранить локальный отчёт PASS/FAIL.
- [x] 3.3 Просмотреть каждую позу сверху и сбоку; сохранить изображения и отметить визуальные
      ограничения отдельно от геометрического результата.

## 4. Проверка и передача

- [x] 4.1 Провести независимое ревью геометрии, исходных файлов и соблюдения локальности; устранить

- [ ] 4.4 Получить визуальную приёмку пользователем формы кисти и пяти нажатий на стенде Blender; не
      считать численный PASS такой приёмкой.

## Результат локальной проверки

Стенд и шесть статических поз сохранены отдельно. Проверка конечной поверхности Blender пройдена во
всех шести случаях; повторное открытие восстанавливает позы, корректировки кожи, ногти и состояния
клавиш. Проведено независимое ревью. Источники сохранены, основная папка остаётся на dev.
Документация опубликована отдельным черновиком PR #195.

Визуальная приёмка пользователем остаётся открытой. После первого просмотра пользователь попросил
исправить разворот большого ногтя, увеличить его и сделать ногти объёмно выгнутыми. Эти исправления
внесены; новый вариант передан на повторный просмотр. Численные проверки не заменяют эту приёмку.

## Уточнение позы покоя и фиксация результата

Пользователь выбрал изгиб четырёх свободных пальцев из показанного кадра нажатия большим пальцем. В
кадр 1 перенесена эта форма, большой палец отпущен, все клавиши подняты. Запястье, тело и пять поз
нажатий сохранены. Повторная проверка конечной поверхности прошла во всех шести кадрах; отдельное
открытие сохранённого файла подтвердило восстановление поз, корректировок и состояний клавиш.
Геометрия 25 ногтей в пяти кадрах нажатий совпадает с предыдущей версией.

Пользователь попросил коммит и пуш и перейти к планированию атласа. Это фиксирует текущий результат,
но не подменяет отдельную визуальную приёмку всех пяти нажатий. План следующего покрытия приведён в
design.md; дополнительные позы ещё не созданы.
