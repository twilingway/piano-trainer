# Design

## Context

Основной вид (`FallingNotesView`) раскладывает ноты, клавиатуру, дорогу, эффекты и руки по карте
«высота → прямоугольник клавиши пианино». В словесном режиме одну высоту печатают несколько клавиш
ПК, поэтому ноты нельзя показать в нём как есть. Первая версия режима рисовала отдельную полосу и
HTML-клавиатуру — копию части основного вида, без перспективы, рук, карточек и переключателей.

## Goals / Non-Goals

Цели: один вид игры для обоих режимов; в словесном режиме — клавиатура ПК вместо пианино и колонка
на физическую клавишу; палитра слепой печати. Не цели: руки над клавиатурой ПК, 3D-грани каждой
клавиши ПК в перспективе (клавиатура ложится одной плитой с её картинкой).

## Decisions

- Чистый модуль `src/wordTyping/touchTyping.ts` владеет таблицей «физическая клавиша → рука и палец»
  по обычной русской схеме; `src/wordTyping/keyboardRows.ts` — рядами клавиш и постоянной колонкой
  каждой клавиши (условная высота). Это таблицы, тесты проверяют полноту.
- Палитра слепой печати — таблица `TYPING_FINGER_COLOR` (рука × палец) рядом с `FINGER_COLOR` и из
  его цветов: указательные различаются по руке, у средних фиолетовый большого пальца.
- `FallingNotesView.setComputerKeys(tokens)` переключает вид на клавиши ПК; без токенов — пианино.
  Всё остальное (ноты, дорога, эффекты, оценки, карточки, переключатели) — тот же код.
  - `src/render/computerKeyboardLayout.ts` (чистый): ряды со сдвигом на Tab, Caps и Shift, геометрия
    клавиатуры, колонка каждой клавиши шириной её грани.
  - `src/render/ComputerKeyboardLayer.ts`: Pixi-клавиатура с интерфейсом `KeyboardLayer`
    (`KeysLayer`): грань и подпись запекаются при раскладке, кадр меняет только тон, прозрачность и
    сдвиг. Ожидаемая клавиша ярко, следующая слабее, нажатая утоплена.
  - `src/render/computerKeys.ts` (без рисования): песня для вида строится `laneSong` (колонка вместо
    высоты, палец и рука слепой печати, партитура и `sourceIndex` сохраняются); кадр трейнера,
    который говорит настоящими высотами, переводится в колонки: ожидаемые ноты по id, нажатие и
    оценка — в колонку ожидаемой ноты этой высоты, иначе последней начатой; аккомпанемент в колонки
    не попадает. Нажатие мышью играет настоящую высоту ожидаемого токена.
  - `NotesLayer.setSong(song, writtenPitch)`: карточки, их место на стане и названия нот строятся по
    настоящей высоте, колонки — по условной.
  - На дороге клавиатура ПК передаётся одной клавишей во всю ширину: перспективная клавиатура кладёт
    её картинку плитой, а не строит грани пианино.
- Отвергнуто: отдельная полоса из деталей вида (была первой версией — расходилась с обычным видом,
  теряла перспективу и настройки); клавиши ПК одним рядом без сдвига (ноты не падали бы на настоящую
  клавишу).

## Risks / Trade-offs

- [Один физический ключ — несколько высот (Shift/Alt) и одна высота — несколько ключей] → колонка по
  физической клавише; нажатие высоты, общей для нескольких клавиш, подсвечивает клавишу ожидаемой
  ноты, иначе последней начатой.
- [Лимит 500 строк основного вида] → логика режима вынесена в отдельные модули, вид только
  переключает слой клавиш и переводит кадр.
- [Перспектива клавиатуры ПК плитой] → проверка глазами; при необходимости — грани по рядам.
