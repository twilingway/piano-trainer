# Задачи

## 1. Политика и контроли

- [x] 1.1 Выделить естественную политику и схему отчёта; проверки показывают, что высота безопасного
      свободного пальца сама по себе не отклоняет позу, а неверное касание нажатого пальца
      отклоняет.
- [x] 1.2 Проверить отрицательные контроли: проникновение свободного пальца в клавишу, неверная
      клавиша и лишнее нажатие дают отказ; зафиксировать команды и результаты в локальном отчёте.

## 2. GPU-поиск

- [x] 2.1 Добавить отдельный адаптер целевой функции и явные старты с мягким приоритетом свободных
      пальцев; compile и dry-run проходят, прежние файлы и SHA не меняются.
- [x] 2.2 Выполнить ограниченный GPU-smoke на проблемных C3 с точным аудитом; отчёт содержит
      устройство, исходные SHA, новую политику, прежние диагностические метрики и реальные
      результаты.
- [ ] 2.3 Пройти оставшиеся позиции существующего атласа порциями; для каждого выбранного кадра есть
      проверенный результат или явный отказ без ухудшения записанного исходника.
