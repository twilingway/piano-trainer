# Автовыбор и быстрый переключатель языка

## Context

Есть единое предпочтение `interface-language-v1`, подписки через `useI18n` и полные RU/EN словари.
Сейчас отсутствие предпочтения даёт русский. `DEFAULT_LOCALE` также обозначает исходный язык
словаря: его простая замена сломает перевод.

## Goals / Non-Goals

Цель: чистое правило выбора и тонкий адаптер браузера. Вне задачи: сеть, GeoIP, новые зависимости,
изменение режима печати, таймера и рендера партитуры.

## Decisions

- Чистая функция `selectInterfaceLocale` получает неизвестное сохранённое значение и язык браузера,
  возвращает RU/EN. Резерв интерфейса EN отделён от исходного языка словаря RU.
- Адаптер читает `navigator.language`, при его отсутствии `navigator.languages[0]`. Проверяем только
  главный язык, а не наличие русского в любом месте списка: так соблюдается предпочтение игрока.
  Недоступный navigator даёт EN, запрещённое хранилище не мешает автовыбору.
- Автовыбор синхронный до первого React-рендера. Сохраняется только ручное действие, существующий
  ключ и данные остаются совместимыми. Повторные кадры не читают браузер и хранилище.
- Connected-компонент в `app` связывает `useI18n` с тонкой кнопкой в `ui`; верхняя панель получает
  плашку через слот. На телефоне плашка 34×34 рядом с управлением, на desktop рядом с настройками.
  Кнопка напрямую переключает два языка; меню не требуется.

## Risks / Trade-offs

- Язык браузера может отличаться от желаемого → заметная плашка и приоритет ручного выбора.
- Дополнительная кнопка в мобильной колонке → проверить 320×568, 390×844, 667×375 и desktop.
- Подписка не должна сбрасывать практику → существующий тест сохранения тренажёра и времени.
- Источником отсутствующего перевода остаётся русский текст; fallback первого входа EN не меняет
  словари и чистую функцию перевода.

## Migration Plan

Миграция данных не нужна. Перенести проверенные изменения в dev и открыть PR в main. Откат кода
сохраняет тот же ключ ручного предпочтения.
