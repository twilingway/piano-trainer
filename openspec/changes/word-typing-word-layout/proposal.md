## Why

С постоянной раскладкой всей песни (одна буква — одна высота) слова на гимне в среднем 3–3.5 буквы
при любых весах: подходящих слов длины L примерно `N / высот^L`, и даже словарь в 48 000 слов даёт
лишь 4.3 буквы. Игрок хочет длинные разнообразные слова и другой текст для той же песни по запросу.
Прототип с раскладкой, своей для каждого слова, даёт 9.8–12 букв в среднем уже на словаре 1 000–10
000 слов (замер в `.browser-artifacts/word-typing/`, мелодия гимна, без пар).

## What Changes

- Переключатель раскладки: «на песню» (нынешнее поведение) и «на слово», где буква играет одну
  высоту только внутри своего слова, а в следующем слове может играть другую. По умолчанию — «на
  слово»; выбор сохраняется после перезагрузки.
- В раскладке «на слово» клавиша играет высоту из текущего слова (слова ближайшей ожидаемой ноты);
  клавиша режима, которой нет в текущем слове, играет фальшивую ноту рядом с ожидаемой (обычно на
  полутон ниже, но не на высоте соседней ноты) и засчитывается ошибкой.
- Кнопка «Другие слова»: другой вариант текста для той же песни, партии, языка и раскладки.
  Результат детерминирован для набора входных данных и номера варианта; номер не сохраняется после
  перезагрузки.
- Генератор избегает повторов одного слова в тексте.
- Benchmark сравнивает обе раскладки.
- **BREAKING** (внутреннее): результат генератора в раскладке «на слово» не содержит постоянного
  mapping всей песни; ключ кеша включает раскладку и вариант.

## Goals / Non-Goals

Цели: средняя длина слова на мелодии гимна в раскладке «на слово» не меньше 6 букв; перегенерация
даёт другой текст; правила раскладки «на песню» не меняются (меняется только выбор слов из-за штрафа
повторов).

Не цели: чистка словаря от имён и междометий (отдельный change позже), словарь больше 10 000 слов,
смена раскладки на паузах между фразами, класс высоты без октавы, ограничение длины слова в UI.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `word-typing`: раскладка на слово, ввод по текущему слову, перегенерация, разнообразие слов,
  воспроизводимость с учётом раскладки и варианта.

## Impact

- `src/wordTyping` (генератор, типы, конфигурация, новый чистый модуль ввода по слову).
- `src/input/computerKeyboard.ts`: словесный ввод получает функцию «клавиша → высота» вместо
  статической таблицы.
- `src/practice/Trainer.ts`: только чтение ближайшей ожидаемой ноты.
- `src/app/useWordTyping.ts`, `wordTyping.worker.ts`, `wordTypingPreferences.ts`, `App.tsx`,
  настройки режима в `src/ui`.
- `src/wordTypingTools/benchmark.ts`.
- Зависимость порядка: дельта меняет требование «Воспроизводимые словари и отчёт» в редакции
  `word-typing-fingers`; `word-typing-fingers` архивируется первым.
- Новых зависимостей и лицензий нет.
