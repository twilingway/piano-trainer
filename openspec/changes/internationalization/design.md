# Design

## Context

Строки распределены между React, данными вариантов, сообщениями оболочки и HUD Pixi. `Song.title` участвует в ключах аппликатур и истории: его нельзя менять при переключении языка.

## Goals / Non-Goals

Чистое форматирование и словари, отдельное состояние языка в оболочке. Локализация не входит в вычисление аппликатуры, часы практики, содержимое пользовательских партитур и генерацию слов.

## Decisions

- Небольшой чистый TypeScript-модуль: явный язык, реестр, каталоги, именованные параметры, русский резерв. Для дат и чисел используется Intl. Внешняя библиотека пока не нужна для двух языков и простых сообщений.
- Русские исходные сообщения служат читаемыми ключами каталога; переводы собраны по владельцам интерфейса. Тип словаря требует все зарегистрированные языки, тест сверяет параметры. Динамический пользовательский текст не проходит через произвольный поиск переводов.
- Адаптер языка использует версионированный localStorage и подписку React. Перевод сообщений выполняется при показе: ранее возникшая ошибка обновляется вместе с языком. Ядро не читает глобальный язык и хранилище.
- Названия встроенных упражнений переводятся на границе отображения; исходный Song и ключи сохранений сохраняются.
- HUD обновляет тексты только при смене языка и появлении оценки; кадровые расчёты и текстуры нот не перестраиваются. Рендер партитуры не зависит от интерфейсного языка.

## Risks / Trade-offs

- Пропущенные строки → аудит исходников, проверка каталогов и компонентов, обзор независимым reviewer.
- Более длинные английские строки → проверка адаптивного интерфейса на существующем стенде, если он доступен.
- Отказ localStorage → русский при старте и работающий выбор в памяти.
- Случайная смена идентичности песни → тесты стабильности состояния при переключении.

## Migration Plan

Добавляется только ключ `interface-language-v1`. Другие настройки и пользовательские данные не изменяются. Откат удаляет поддержку нового ключа без удаления данных.
