## Why

Сейчас песня, открытая через «Открыть файл», живёт до перезагрузки страницы: чтобы продолжить
занятие, её приходится открывать заново. Уроки из `local-lessons/` видны только на машине
разработчика — это папка сборки, а не библиотека игрока. Игроку нужна собственная библиотека,
которая переживает перезагрузку и не требует сервера.

## What Changes

- Открытый файл песни (MusicXML, `.mxl`, MIDI) сохраняется в браузере игрока (IndexedDB) и
  появляется в списке уроков в группе «Мои песни». Повторное открытие того же файла заменяет прежнюю
  копию.
- Песню из «Моих песен» можно удалить.
- Игрок может выбрать папку на диске (Chrome, Edge — File System Access API). Браузер запоминает
  доступ; песни из папки и её подпапок появляются в группе «Папка: <имя>» при каждом запуске. Если
  браузер снова просит разрешение, тренажёр показывает кнопку «Дать доступ к папке».
- Чтение файла песни выносится из `App.tsx` в чистый модуль.

## Non-goals

- Синхронизация между устройствами, учётные записи, сервер.
- Правка файлов в выбранной папке: тренажёр её только читает.
- Уровни внутри песен из библиотеки (у встроенных уроков и `local-lessons` они остаются).

## Capabilities

### New Capabilities

- `song-library`: хранение песен игрока в браузере и подключение папки с песнями.

### Modified Capabilities

(нет — базовых спецификаций пока нет)

## Impact

- Новые модули `src/library/` (файл песни, IndexedDB, папка); `App.tsx` — список уроков, открытие
  файла, удаление, выбор папки.
- Dev-зависимость `fake-indexeddb` (Apache-2.0) только для тестов; в сборку не попадает.
- Выбор папки есть только в Chrome и Edge; в других браузерах кнопки нет, «Мои песни» работают
  везде.
- Данные живут в одном браузере: очистка данных сайта удаляет библиотеку.
