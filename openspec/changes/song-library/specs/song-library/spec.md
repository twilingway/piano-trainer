## Purpose

Библиотека песен игрока: песни, которые он открыл сам, хранятся в его браузере, а песни из выбранной
им папки на диске подхватываются при каждом запуске, без сервера.

## ADDED Requirements

### Requirement: Открытый файл сохраняется в «Мои песни»

Тренажёр SHALL сохранять в браузере каждый успешно открытый файл песни (MusicXML, `.mxl`, MIDI)
вместе с его именем и показывать его в списке уроков в группе «Мои песни», новые сверху. Файл,
который не удалось прочитать как песню, SHALL NOT сохраняться.

#### Scenario: Песня переживает перезагрузку

- **WHEN** игрок открывает файл `Ода к радости.musicxml` и перезагружает страницу
- **THEN** в списке уроков в группе «Мои песни» есть «Ода к радости», и выбор её загружает ту же
  песню с теми же нотами

#### Scenario: Тот же файл не дублируется

- **WHEN** игрок второй раз открывает файл с тем же именем и тем же размером
- **THEN** в «Моих песнях» остаётся одна запись этой песни

#### Scenario: Нечитаемый файл не сохраняется

- **WHEN** игрок открывает файл, который не является песней, или песню без нот
- **THEN** тренажёр показывает ошибку, и в «Моих песнях» ничего не появляется

### Requirement: Песню можно удалить из «Моих песен»

Когда выбрана песня из «Моих песен», тренажёр SHALL показывать действие «Удалить из моих»; после
него песня SHALL исчезнуть из списка и из хранилища, а тренажёр SHALL вернуться к первому уроку.

#### Scenario: Удаление

- **WHEN** игрок выбирает песню из «Моих песен» и нажимает «Удалить из моих»
- **THEN** песни больше нет в списке, в том числе после перезагрузки, и открыт первый встроенный
  урок

### Requirement: Папка с песнями

В браузере с доступом к папкам тренажёр SHALL давать выбрать папку на диске и SHALL показывать песни
из неё и её подпапок (на один уровень вложенности) в группе «Папка: <имя папки>», подпись — путь
внутри папки. Выбор папки SHALL запоминаться между запусками; папку SHALL можно отключить. Тренажёр
SHALL только читать папку. В браузере без доступа к папкам действие выбора папки SHALL NOT
показываться.

#### Scenario: Песни из папки

- **WHEN** игрок выбирает папку, где лежат `Вальс.mid` и `Этюды/Этюд 1.musicxml`
- **THEN** в группе «Папка: <имя>» есть «Вальс» и «Этюды/Этюд 1», и выбор любого загружает эту песню

#### Scenario: Доступ снова спрашивается

- **WHEN** при следующем запуске браузер не дал доступ к запомненной папке без вопроса
- **THEN** тренажёр показывает «Дать доступ к папке», и после подтверждения игроком песни из папки
  появляются в списке

#### Scenario: Файл из папки удалён

- **WHEN** игрок выбирает песню из папки, а файл уже удалён с диска
- **THEN** тренажёр показывает ошибку и перечитывает папку

#### Scenario: Браузер без доступа к папкам

- **WHEN** тренажёр открыт в браузере без File System Access API
- **THEN** действия выбора папки нет, а «Мои песни» работают

### Requirement: Песни из библиотеки ведут себя как уроки

Песня из «Моих песен» или из папки SHALL поддерживать всё, что поддерживает открытый файл:
аппликатуру и её правки, смену тональности, запись дублей и их историю. Правки пальцев и дубли SHALL
храниться по песне, как для открытого файла.

#### Scenario: Правки пальцев сохраняются для песни из библиотеки

- **WHEN** игрок меняет палец у ноты песни из «Моих песен», выбирает другой урок и возвращается
- **THEN** правка на месте
