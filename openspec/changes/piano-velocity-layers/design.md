# Design: слои силы удара

## Context

Два звуковых движка делят один набор сэмплов. `pianoSound.ts` держит `Tone.Sampler` для клавиш,
нажатых мышью и компьютерной клавиатурой. `scheduledVoices.ts` держит `Tone.ToneAudioBuffers` и
планирует программную руку, аккомпанемент и прослушивание с точным временем, в том числе с середины
ноты после перемотки. Оба брали один слой (`v8`) с `tonejs.github.io`.

## Decisions

### Слои и файлы

`public/audio/salamander-v1/` хранит слои v1, v5, v10, v15 нарезки `@tonejs/piano` (30 нот через
малую терцию на слой, `<Note>v<layer>.mp3`, 120 файлов). Сэмплы длиннее 8 с обрезаны до 8 с с
затуханием 1,5 с (команда в `README.txt` папки): 21 → 12 МБ загрузки и ~550 → ~290 МБ
декодированного PCM. Нота, которую держат дольше 8 с, затухает раньше настоящей (решение
пользователя). Версия в пути — правило кэша: nginx отдаёт `/audio/` с `max-age=31536000, immutable`,
новый набор получает `salamander-v2`.

### Чистый выбор слоя: `src/audio/pianoLayers.ts`

`pianoLayer(velocity, loaded)` возвращает слой и усиление в дБ. Он не знает о Tone.js.

- Центры слоёв по силе: v1 → 8, v5 → 40, v10 → 80, v15 → 120 (слой Salamander k записан примерно при
  силе 8k). Берётся ближайший центр среди загруженных; границы при полной загрузке — 24/60/100.
- Громкость сохраняет прежнюю кривую. Прежний звук: слой v8 с линейным усилением `v/127`. Средняя
  громкость атаки (первые 0,5 с, 30 нот) относительно v8 измерена ffmpeg `volumedetect`: v1 −13,0,
  v5 −2,9, v10 +1,7, v15 +7,4 дБ. Усиление слоя = `20·log10(v/127) − offset`, поэтому граница слоёв
  не даёт скачка громкости, а полная сила звучит как прежде. Все усиления в полосах слоёв ≤ 0 дБ:
  клиппинга не добавляется.

### Движки

Раньше оба движка качали и декодировали один слой каждый себе — две копии PCM. Теперь
`src/audio/pianoSamples.ts` владеет буферами: по `ToneAudioBuffers` на слой, загрузка один раз,
сначала v10, после его готовности — остальные три. Ошибка загрузки слоя оставляет его незагруженным
— `pianoLayer` его не выберет.

- `pianoSound.ts`: по `Tone.Sampler` на слой, созданному из общих буферов (`Sampler` принимает
  `ToneAudioBuffer`), когда слой готов. Нота играет тем сэмплером, который выбрал `pianoLayer`;
  отпускание идёт во все сэмплеры (у не игравшего нота не найдена — no-op). Готовность — загрузка
  первого слоя, а не `Tone.loaded()`, который ждал бы все слои.
- `scheduledVoices.ts`: берёт буфер ближайшей ноты из выбранного слоя, усиление передаётся вместо
  `velocity/127` в `ToneBufferSource.start`.

## Risks

- **Кадр.** Выбор слоя — сравнение четырёх чисел на ноту, вне кадра Pixi; риска для частоты кадров
  нет. Декодирование 120 mp3 идёт в фоне через `decodeAudioData` и может дать короткую нагрузку на
  слабом телефоне во время игры.
- **Память.** Декодированный PCM float32 стерео: ~290 МБ на четыре слоя после обрезки, столько же,
  сколько прежде занимали две копии одного полного слоя. Если телефоны не справятся — грузить три
  дополнительных слоя только при подключённом MIDI (отдельная задача).
- **Репозиторий.** 12 МБ бинарников в истории git навсегда.
