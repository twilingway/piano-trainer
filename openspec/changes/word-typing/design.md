# Design

## Context

Запрос пользователя — видимый игровой прототип по трём предоставленным файлам. Существующий KeyboardState добавляет полутоны и подавляет атаки перекрывающихся aliases, поэтому его нельзя использовать для нового режима без отдельного поведения.

## Goals / Non-Goals

Цели: STRICT, RU/EN, мелодия/бас, адаптивный текстовый вид клавиатуры, существующий звук и часы, воспроизводимый benchmark. Не цели: аккорды, смена mapping внутри песни, рейтинг, новые piano presets.

## Decisions

- Чистые модули `src/wordTyping` владеют типами, нормализацией/Trie, извлечением линии, bounded beam search, scoring и метриками. Они не используют DOM/таймеры/React.
- Использовать существующий Song: сначала правая рука для melody/левая для bass; если выбранная рука пуста, UI сообщает об этом. Одновременные атаки сводятся к верхней/нижней ноте; длительность ограничивается следующей атакой. Исходный Song не меняется. Учебный Song содержит только линию; все её ноты назначены правой руке, руки сессии принудительно right без изменения сохранённой настройки.
- `useWordTyping` хранит только отдельные предпочтения и результат генерации. Генерация выполняется в worker, кешируется вне чистого ядра. При смене песни/языка отменяется старый результат. Пока результат не готов, словесный ввод блокируется.
- Существующий listener получает необязательный resolver physicalKey/modifier и отдельное состояние удержаний: никаких octave/sustain/sharp/flat из других режимов. Повтор клавиши подавляется, каждая новая физическая буква даёт атаку даже для aliases. Note-off последней удерживаемой alias прекращает звук; cleanup очищает удержания.
- App компонует режим; UI рисует текст и физические ряды с высотами только назначенных клавиш. Workspace сохраняет Pixi host для кадрового цикла, но перекрывает его словесным видом. Его диапазон/пресеты не определяют отображаемую словесную клавиатуру.
- Текущая буква берётся по статусам нот сессии и времени Trainer, а не вторыми часами. Допустим любой alias требуемой высоты: это музыкальная тренировка, точность печати букв отдельно не оценивается.
- Частотные ресурсы: FrequencyWords 2018, версия по SHA источника; отфильтрованные 3000 слов на язык, отдельная атрибуция CC BY-SA 4.0. CLI подготовки умеет локальный кеш; runtime читает подготовленные статические данные. Новых зависимостей нет; Node-инструменты запускаются с strip-types и существующим happy-dom для MusicXML.

## Risks / Trade-offs

- Beam search ограничен, качество текста зависит от мелодии; UI честно показывает покрытие словами и fallback.
- Частотные списки субтитров могут содержать разговорную лексику; фильтр явной нежелательной лексики документирован.
- Для очень длинной песни worker не блокирует кадры, но поиск занимает время; отмена и сообщение загрузки обязательны.
- Сравнение записей словесного режима должно использовать выбранную учебную линию и отдельный songKey, иначе результаты смешаются с обычным уроком.
