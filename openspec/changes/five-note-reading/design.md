# Design

## Context

См. proposal.md. Локальный курс ограничен десятью уроками и зачётом 30/70; новый курс отделён от его
данных. Trainer уже объединяет ввод и запись, Staff рендерит MusicXML. onInput вызывается до
фильтров и не подходит для учебной оценки.

## Goals / Non-Goals

Чистое ядро владеет заданием и метриками, оболочка передаёт события и timestamps. Сохранить одну
Song/PracticeSession на серию. Не менять политику обычных уроков, не добавлять зависимости,
адаптацию или новые часы песни.

## Decisions

- `src/reading`: типы задания/попытки/результата, seed-генерация сбалансированных 20 нот, исходный
  XML и чистая вырезка текущего задания, ReadingSession с явно переданными timestamps и активностью.
  XML парсится существующим songFromMusicXml; публичный материал создаётся генератором.
- Trainer получает необязательную учебную policy: подготовка текущей due-ноты, допуск до pressKeyAt
  после стандартных фильтров, callback результата и кадра. Gate запрещает раннее совпадение wait
  только для чтения. Held-состояние различает source/device/channel/pitch, обрабатывает up даже вне
  допуска. Слышимость и pressed feedback сохраняются.
- Staff сообщает предъявление актуального prompt после relayout и видимого кадра с run/prompt
  identity. Серия остаётся одной Song, XML только представляет текущую ноту/фразу; callback не
  перезапускает take. Обычные промежутки четвертей 0,5 с сохраняются. Старые promises игнорируются.
- Время реакции использует raw performance timestamp, музыкальный matcher — corrected timestamp.
  ReadingSession исключает паузы/загрузку/невидимость; hintLevel определяется историей реально
  показанных подсказок на момент атаки.
- Подсказки — transient cue policy, а не запись глобальных prefs. На level 2 подсвечивается лишь
  текущая клавиша; аппаратные огни только при сохранённом разрешении игрока. Реальное нажатие не
  окрашивается аппликатурой. В проверке помощь полностью запрещена.
- Отдельный Redux slice, reading-course-v1 и существующий persistence notice. Хранятся настройки,
  выбор задания, seed и до 20 завершённых результатов на задание; активный запуск не сериализуется.
  Выход/перезапуск прерывает незавершённый результат. UI получает чистые props; App остаётся
  композицией.

## Risks / Trade-offs

- Рендер OSMD дорогой → XML меняется только при смене ноты/фразы; frame не парсит XML; готовность
  блокирует только ответ.
- Два источника ввода/поздние события → timestamps, run identity и fresh-attack gate; тесты
  mixed-source и паузы.
- Сохранённые настройки раскрывают ответ → единый effective profile, нейтральный pressed color и
  MIDI cue filtering, без изменения prefs.
- Существующие тайминг/игровые настройки → scoped override wait/right/speed=1/no accompaniment/no
  ranked/no loop/no stop-on-error; обычные prefs сохранены. Диапазон не исключает учебные ноты из
  player ownership.

## Migration Plan

Новый ключ без миграции старых данных. PR в dev после проверок; пользователь сливает, затем ff-only
обновление основной папки и приёмка на 5190. Откат PR не меняет старые предпочтения; новый ключ
можно оставить без использования.
