# Переход дороги и нот вида «3D»

Все задачи ниже относятся к первому этапу style=3d; остальных renderer и полное удаление Pixi они не
объявляют выполненными. Артефакты написаны до производственной реализации.

## 1. Чистая геометрия и контакт

- [ ] 1.1 Подготовить чистый снимок видимых нот: note.id, pitch, состояние, цвет, границы
      длительности и контакт. Переиспользовать существующие holdBounds/источники состояния.
      Проверка: unit-тесты коротких/длинных нот, повтора и двух голосов одной высоты; pnpm
      typecheck.
- [ ] 1.2 Построить общие мировые якоря для клавиш и ближней дороги при keysOffset=0, включая
      pan/scale. Проверка: чистые тесты 49/61/88, белых/чёрных клавиш, трёх пресетов, крайних
      допустимых ракурсов и resize; проекции контактов совпадают в пределах одного CSS-пикселя, не
      появляются NaN. Выполнить pnpm exec vitest run src/render/three.
- [ ] 1.3 Передать общий контакт источникам света и экранным эффектам без второго преобразования.
      Проверка: unit-тесты совпадения contact/light/FX при keysOffset=0 и прежнего независимого
      сдвига клавиш при ненулевом offset без изгиба дороги; изменение только геометрии, без
      изменения time/status/оценки; обновить design при уточнении формата кадра.
