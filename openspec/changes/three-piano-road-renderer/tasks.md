# Переход дороги и нот вида «3D»

Все задачи ниже относятся к первому этапу style=3d; остальных renderer и полное удаление Pixi они не
объявляют выполненными. Артефакты написаны до производственной реализации.

## 1. Чистая геометрия и контакт

- [ ] 1.1 Подготовить чистый снимок видимых нот: note.id, pitch, состояние, цвет, границы
      длительности и контакт. Переиспользовать существующие holdBounds/источники состояния.
      Проверка: unit-тесты коротких/длинных нот, повтора и двух голосов одной высоты; pnpm
      typecheck.
- [ ] 1.2 Построить общие мировые якоря для клавиш и ближней дороги при keysOffset=0, включая
      pan/scale. Проверка: чистые тесты 49/61/88, белых/чёрных клавиш, трёх пресетов, крайних
      допустимых ракурсов и resize; проекции контактов совпадают в пределах одного CSS-пикселя, не
      появляются NaN. Выполнить pnpm exec vitest run src/render/three.
- [ ] 1.3 Передать общий контакт источникам света и экранным эффектам без второго преобразования.
      Проверка: unit-тесты совпадения contact/light/FX при keysOffset=0 и прежнего независимого
      сдвига клавиш при ненулевом offset без изгиба дороги; изменение только геометрии, без
      изменения time/status/оценки; обновить design при уточнении формата кадра.

      ракурс, неподвижный горизонт при отдельном перемещении клавиатуры.
- [ ] 2.2 Добавить переиспользуемые объёмные ноты со скруглением, фаской, цветной поверхностью и
      светящимся контуром. Проверка: короткие/длинные/повторные ноты на белых/чёрных клавишах, торцы
      не растягиваются; тесты пула/размеров и pnpm typecheck.
- [ ] 2.3 Сохранить цвет пальца/руки/оценки, яркость принятого удержания, карточки, пропорции цифр и

- [ ] 2.4 Провести направляющие через центры белых и чёрных клавиш с более слабой чёрной линией.

- [ ] 2.5 Добавить ограниченные неоновые ленты между соседними нотами одной высоты без изменения

- [ ] 2.6 Усилить насыщенную заливку объёмных нот и emissive звучащих клавиш. Проверка: тесты

- [ ] 2.8 Окружить фактически спроецированный контур ноты экранным гауссовым ореолом, сохранить
      гранёный материал и устранить z-fighting. Проверка: тесты геометрии/billboard/ресурсов,
      видимые короткие/длинные ноты, оба торца и разные ракурсы без резких границ и мерцания.

- [ ] 2.9 Добавить связные непрерывные переливы внешней лавы ThreeNoteAura по всей длине: два слоя

      исходной ноты и постоянная геометрия оболочки без временного vertex-смещения. Проверка: тесты
      знакового tailOffset с clipping/repeatGap/отрицательным расширением, 192/384, независимых нот,
      перехода дальняя обрезка → полная нота → сгорание, pause/clear/dispose и видимая текучая
      плазма вокруг формы с перекрытием задней стороны и читаемыми цифрами. Новые

- [ ] 2.10 Сделать пресет top строго 90° с совпадающими ортографическими матрицами world/Three.
      Проверка: чистые тесты проекции, контакта/полного пути и видимый верхний ракурс на
      desktop/mobile; прочие сохранённые камеры не меняются.
