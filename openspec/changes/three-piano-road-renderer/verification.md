# Проверки текущего этапа

Реализация непрерывных переливов, независимой скорости перспективы, native-ready и палитры прошла
полный контроль 2441 теста. Материал также проверен на GPU и в видимом приложении. Пользовательская
приёмка открыта. Ниже — результаты основного исполнителя, а не утверждение о завершении миграции.

## Автоматические проверки

- Итоговый pnpm check, включая native-ready и палитру: 2441 тест пройден, один пропущен; React
  Compiler — 23, сборка прошла.
- pnpm spec:validate: 55/55.
- Независимое reviewer-ревью не нашло замечаний, требующих исправления; последующая проверка
  подтвердила исправление P2 о выборе профиля скорости и не выявила новых проблем.
- Unit-проверки подтверждают выключенный исходный метроном с сохранением opt-in и default/restore
  предпочтения «Линии дороги». Общая визуальная матрица и пользовательская приёмка не закрыты.

## Видимый браузер

В свежей видимой странице 1440×900 проверены настоящий верхний ракурс 90°, диапазон 49 клавиш, руки,
отсутствие разлиновки и отображение внешней лавовой оболочки. Кадр основной папки:
.browser-artifacts/three-lava-reference-final-live.png; он остаётся вне git.

С текущими непрерывными переливами записаны восемь секунд действующего приложения при pitch=25,
позиция песни примерно 02 → 10 секунд. Запись .browser-artifacts/three-flow-perspective-capture.webm
и просмотренный лист .browser-artifacts/three-flow-perspective-motion.png находятся вне git. Виден
перспективный пролёт и сокращение длинных нот; это не полная матрица визуальной приёмки. Предыдущая
верхняя запись: canvas 1440×828 в окне 1440×900.

На свежей странице WebGL-предупреждений не было. Было только стартовое предупреждение AudioContext;
слышимость и аппаратный MIDI этой проверкой не подтверждены.

## Диагностика изменения пикселей на GPU

Проверен фактический shader на одном сохраняющемся участке ноты 40×260 при фиксированном времени.
Для переходов обрезанная → полная, полная → сгорающая и сгорающая → знаковое расширение читаемости
changedPixels=0; средние RGB-разницы соответственно 0,000641/0,000577/0,000192. Это диагностические
показатели данного участка, а не утверждение о полном равенстве всех пикселей.

В отдельной пробе при неподвижных границах менялось только shader time с 4 до 4,7 секунды:
изменились 9988 пикселей, средняя RGB-разница 33,34269. Во всей диагностике glError=0. Файл:
.browser-artifacts/three-lava-flow-anchor-gpu.json; исходные локальные материалы не копируются.

Это подтверждает анимацию при фиксированной геометрии. Это не сравнительный замер
производительности, не аппаратная приёмка и не подтверждение требуемого внешнего вида.

## Независимая скорость перспективы

Чистый roadApproach отделяет верхний профиль pitch>=80 (2,22 секунды песни) от перспективного
pitch<80 (6 секунд). Unit-сценарий top → player → hands → top проверяет 2,22/6/6/2,22 при одинаковом
времени сессии. Музыкальные часы и legacy/2D/Word Typing не менялись.

В действующем видимом приложении при pitch=25 скорость головы nativeWorldNote измерена по
dZ/dvisualTime: 2339 оценок дали медиану времени подхода 6,0000000001 секунды. Локальный файл
основной папки .browser-artifacts/three-perspective-speed.json остаётся вне git. Это измерение
визуального пролёта, не производительности или слышимости. Свежий общий pnpm check завершён успешно.

## Последние небольшие изменения

Замечание P2: новые профили скорости теперь выбираются только при фактическом drawsNativeRoad, а не
по сохранённому стилю «3D». Пока Three не готов, действует прежний множитель lookAhead×4. Два
unit-сценария с выключенным host и базовым окном две секунды дают восемь секунд и для верхней, и для
перспективной камеры. Reviewer подтвердил исправление P2; новых замечаний нет.

Общая палитра по последнему выбору пользователя: палец 2 — тёплое золото #ffcf32, палец 4 — неоновый
малиновый #ff285b. Клавиши, ноты, FX и Word Typing используют одну палитру; новых подписей
интерфейса нет. Эти правки вошли в успешную итоговую общую проверку.

Подбор двух референсных ракурсов — только браузерное превью 49 клавиш на 1920×900, без изменения
исходных камер в production. Кандидат 1: fov 84,2; pitch 40; height 130; distance 260; targetY −46;
scale 1,2. Кандидат 2: fov 82,2; pitch 44; height 110; distance 250; targetY 184; scale 1,4. Кадры
основной папки .browser-artifacts/camera-reference-1-new-palette.png и
.browser-artifacts/camera-reference-2-new-palette.png остаются вне git. Точное совпадение с
изображениями не заявлено.

## Открыто

Последний выбор пользователя — связные непрерывные переливы лавы по всей внешней поверхности, без
разрозненных спиралей и независимого дрейфа. Знаковый tailOffset от исходного начала, сокращение
длинного хвоста до нуля и постоянная геометрия сохраняются. Новый fragment shader меняет
взаимосвязанное поле жара локально, без спирального каркаса и осевого конвейера. Удалён только
пустой hitLine Graphics. Полный контроль 2441 теста, GPU-проба и видимая перспективная запись
выполнены для текущего материала. Визуальная приёмка ауры, полная матрица ракурсов, сравнение
производительности и ресурсы открыты. Изменение не архивируется.
