# Устройство учебного курса

## Context

Существующие локальные уроки — Exercise с вариантами партитур, поэтому этапы рук не должны заменять уровни сложности. onTake закрывает запись также при seek, load и destroy и не доказывает полный проход.

## Goals / Non-Goals

**Goals:** реализовать согласованные сценарии в spec.md, подключать уроки постепенно, сохранить данные библиотеки.

**Non-Goals:** перенос музыки курса в этой задаче, новые зависимости, собственные часы табов, переписывание солвера.

## Decisions

- Чистые типы и функции живут в `src/course/`. CourseStage = right | left | both; CoursePhrase = id, version, musicXml; CourseLesson = id, number, title, goal, stages, phrases; CourseSelection = lessonId, stage, phraseId. Пустые phrases означают неподготовленный урок. Версия включает версию автора и fingerprint XML, чтобы исправленная музыка не наследовала зачёт случайно.
- CourseProgress — сериализуемые отметки по lesson/stage/phrase/version. Функции вычисляют завершённость этапов/урока, первое незавершённое и следующее задание. Политика зачёта читает явный результат естественного окончания с from/to, руками, попаданиями, полной доступностью диапазона и признаком прерывания.
- `local-lessons/course.json` содержит только проверенные уроки с номером 1–10, stable id и относительными путями XML. Подключение через import.meta.glob, без загрузки произвольных путей. Ошибки и пустая музыка оставляют соответствующий урок «Скоро». По умолчанию десять нейтрально названных карточек; реальные названия/цели берём из локального манифеста или существующих папок, не копируя музыку в src.
- Redux course slice содержит progress, selection, view = tabs | staff, accompaniment = false. Адаптер и listener сохраняют его по `lesson-course-v1`, вне reducers и вне кадрового цикла. Последнее задание восстанавливается только если локальная фраза доступна. Временное нахождение вне курса не стирает последнюю учебную позицию.
- Trainer публикует отдельный результат естественного окончания. Чистый tracker сбрасывается при загрузке и отмечает неполный старт/seek/частичный диапазон/смену опций; обычная пауза не прерывает зачёт. История Take сохраняет прежний контракт. Обработчик проверяет идентичность задания и songKey, исключает печать/сравнение.
- Учебная фраза загружается как обычная песня из MusicXML. Выбор курса не меняет глобальные handChoice/accompaniment: useTrainer получает override играемых рук и сопровождения, существующее управление внутри курса меняет course slice. Режим темпа/ожидания и скорость остаются обычными настройками. Вне курса прежние настройки сразу действуют снова.
- Connected-компоненты связывают каталог и store с чистым UI. Табы получают Song и время из trainer snapshot; не используют таймер. Группировка по startBeat позволяет выровнять руки и аккорды, выделение текущей позиции следует времени сессии. Вид переключает только отображение workspace и не перегружает песню.
- Синтетическая партитура существует в тестах и документированном browser-fixture; не становится подготовленным уроком публичного курса.

## Risks / Trade-offs

- [Неизвестные ритм и октавы кадра] → подключать только reviewed манифест после отдельной сверки; в этой задаче музыка не переносится.
- [Частые React renders] → время читается только connected табами, каталог и карточки читают постоянные данные; derived модель табов строится при изменении песни.
- [Старый результат при смене задания] → songKey и стабильная выборка сверяются перед зачётом; естественное окончание отделено от записи дубля.
- [Файлы курса отсутствуют на другом компьютере] → карточки «Скоро», прежняя библиотека продолжает работать.

## Migration Plan

Существующие localStorage и история не мигрируют и не сбрасываются. Добавление манифеста открывает только соответствующие подготовленные уроки. Откат интерфейса оставляет прежние ключи и XML нетронутыми. Работа идёт через PR в dev, браузерная проверка — на уже разрешённом стенде; недоступность стенда явно фиксируется.
