# Design

## Context

См. proposal.md. Восемь SpotLight остаются частью PBR-программы даже при нулевой интенсивности;
линейный RectAreaLight добавляет дорогой LTC. Отключение этих источников дало около 42–45 FPS при
исходном DPR. CPU и GPU timer query разделены честно: расширение GPU-таймера недоступно.

## Goals / Non-Goals

Облегчить свет автоматически без смены геометрии, разрешения, времени или настройки вида. Не вводить
качество шейдеров через хрупкую замену GLSL: проба дала меньший выигрыш. Не обещать устранение всех
чёрных кадров без воспроизведения конкретного действия.

## Decisions

- Thin shell определяет основной сенсорный указатель через matchMedia(pointer: coarse). Профиль
  света передаётся в ThreeStage. На сенсорном устройстве не создаётся дорогой пул прожекторов нот, а
  линейный дополнительный свет заменяется мягким направленным. Базовое освещение и цветовое свечение
  клавиш остаются; desktop получает прежний rig.
- Старые материалы удерживаются до успешного native-кадра. Несколько layout до кадра сохраняют
  только последнее текущее и одно прежнее поколение. Общие текстуры не принадлежат этим клонам.
- Resize сравнивается с реальными параметрами Three и canvas, а не с общим screen, который
  Application успевает обновить перед вызовом. Новые размеры задаются за одну операцию.
- Pure core не меняется. Чистый выбор профиля и lifecycle проверяются unit-тестами;
  DOM/медиа-проверка остаются в оболочке. Музыкальное время читает PracticeSession.

## Risks / Trade-offs

- Мобильный свет выглядит проще → это согласованный выбор; визуально проверить ноты и нажатия.
- Отложенное освобождение может течь → тесты нескольких rebuild и dispose, ограничение поколений.
- Новые варианты шейдеров всё ещё требуют первой компиляции → проверять прогретые и холодные случаи
  отдельно.
- Чёрный экран зависит от параметра → проверять диапазон, камеру, размер и 20 переходов меню на
  устройствах.

## Migration Plan

Отдельный PR в dev. Настройки и данные не мигрируют. Совместный preview с лоадером собирается
временно; task PR содержит только своё изменение. Откат коммита восстанавливает прежний renderer.
