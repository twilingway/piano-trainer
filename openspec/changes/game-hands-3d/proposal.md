# 3D-руки в игре

## Why

В игре над клавиатурой четыре рисованные позы кисти (пять пальцев, секста, септима, октава):
трезвучие, обращение, отдельные пальцы и подкладывание показываются ближайшей из них и выглядят
приблизительно. После #106 есть 42 позы одной модели руки из Blender, решённые по реальным
растяжкам, в одном масштабе и с вида сверху, — ими можно показывать руку по-настоящему.

## What Changes

- Второй вид рук — «3D»: 42 рендера из `tools/hand-rig` (покой, 31 сочетание пальцев, терция …
  подкладывание) рядом с прежними рисованными, а не вместо них (решение пользователя).
- Выбор в настройках «Вид» рядом с «Вид клавиш»: «Вид рук: Рисованные / 3D». По умолчанию
  «Рисованные», как сейчас; кнопка «Руки» на боковой панели по-прежнему только показывает и скрывает
  руки (решение пользователя).
- Левая рука — зеркальная правая, как у рисованных (решение пользователя).
- Для каждой позы из Blender снимаются пиксели подушечек всех пяти пальцев на рендере и масштаб
  (пикселей на белую клавишу); по ним работает прежний подбор позы и сдвиг по клавиатуре.
- Игровой набор рендеров экспортируется отдельно от страницы `hand-study.html`: полный кроп рендера,
  80 px на белую клавишу против 30 у страницы.
- 3D-позы загружаются, только когда выбран этот вид; пока они грузятся или если не загрузились,
  видны рисованные руки.

## Goals

- Рука над клавиатурой совпадает с реальной аппликатурой по числу и положению пальцев, а не
  ближайшей из четырёх картинок.
- Прежний вид рук и его поведение не меняются.
- Первый экран не грузит лишнего: 3D-набор (~0.85 МБ) скачивается только по выбору.

## Non-Goals

- Анимация пальцев между позами (переходы не моделируются; позы сменяются прежним перекрёстным
  затуханием).
- Отдельные рендеры левой руки.
- Исправление известных пробелов решателя (большой палец под ладонью в fingers-1/17/tucked,
  отклонения sixth и fingers-23) — отдельная задача; после неё рендеры перевыпускаются тем же
  экспортом.
- Позы на чёрных клавишах кроме имеющейся `black`.

## Decisions

- **Лицензия.** Модель — Blender Studio Human Base Meshes v1.4.1, CC0: рендеры можно публиковать без
  атрибуции.
- **Зависимости.** Новых пакетов нет; Blender нужен только для перевыпуска рендеров и кончиков.
- **Репозиторий.** 42 webp, ~0.85 МБ, остаются в истории git.
- **Совместимость.** Сохранённые настройки без нового поля читаются как «Рисованные».

## Capabilities

### New Capabilities

- `hand-styles`: выбор вида рук, 3D-позы и их подбор, загрузка по выбору и откат к рисованным.

### Modified Capabilities

Нет: требование «Руки над клавиатурой» (change `note-fx`, ещё не в архиве) описывает поведение обоих
видов и не меняется.

## Impact

- `tools/hand-rig/`: скрипт снятия кончиков в Blender, игровой экспорт в `export.py`.
- `src/render/hands/rendered/` (42 webp и кончики), каталог 3D-поз рядом с `handSpriteCatalog.ts`.
- `HandsLayer` (два каталога, загрузка по выбору), `FallingNotesView`, `useFallingView`.
- `useStaffPrefs` (новое поле), `KeyboardSettings`, `App.tsx`, строки локализации.
