# Возврат к месту в окнах

## Context

Мотивация — proposal.md. SettingsPanel хранит active tab, но размонтирует содержимое. Библиотека
размонтируется в ConnectedPlayerWindows. Scroll-контейнеры — settings-content и game-dialog__body.
Фильтры источника P1–P4 уже принадлежат runtime/store. state-persistence запрещает дисковую запись
окон.

## Goals / Non-Goals

Сохранить лёгкое представление окна в памяти живущей оболочки. Не копировать DOM, input values,
runtime, предпочтения или прогресс. Закрытые тяжёлые карточки и неактивные вкладки по-прежнему
отсутствуют. Pure core, кадровый цикл, PracticeSession и зависимости не изменяются.

## Decisions

### Память представления

Память принадлежит экземпляру оболочки, не глобальному singleton: scrollTop и открытые details по
стабильным data-ключам отдельно для вкладок. Снимок обновляется до смены вкладки/закрытия. При
открытии восстанавливаются details, затем scroll после native show/showModal. История использует ID
результата, не индекс или локализованный текст. Фильтры остаются у прежнего владельца;
восстановление не посылает input/change и не запускает урок. keepMounted всех карточек нарушает
правило закрытых окон; постоянная запись не требуется запросом.

### Приоритет явной навигации

Помощь выбирает вкладку, затем прокручивает и фокусирует параметр. Старый snapshot не перетирает эту
команду; следующее закрытие запоминает новую позицию.

### Существующий транспорт

SettingsPanel получает controls slot вне прокручиваемой вкладки; GameDialog — headerActions.
Подключённый компонент читает узкие runtime selectors и использует прежний runtime.play, playing,
countdown и готовность звука. Слот не строится у закрытого окна. Только для обычной песни
settingsOpen исключается из countdown.blocked. Course/input блокировки, библиотека, pending/errors,
захват и калибровка остаются прежними. При practiceActive неподдержанный транспорт в настройках не
показывается. Новые подписи проходят t() и EN catalog.

## Risks / Trade-offs

- Закрытый dialog не имеет размеров: восстановление после открытия, не в рендере.
- Details меняют высоту: раскрытия до scroll, стабильные ключи.
- Список/viewport изменён: clamp; исчезнувший материал не открывается повторно.
- Частые snapshots: узкие selectors и отсутствие closed-content.
- PR217/218 не в dev: новую память не связывать с их импортами и не заявлять интеграцию.

## Migration Plan

Миграции нет, откат не меняет данные. Component/navigation/transport проверки, видимый Chrome,
полный gate, отдельный PR в dev.
