## Context

`FallingNotesView` рисует всё тонированными спрайтами из белой текстуры: тело ноты, цифру пальца,
клавиши, линию удара. Цвет ноты — цвет руки (`HAND_COLOR`) или `colorOf` от сравнения записи.
Подсказка клавиши — светлый цвет руки (`HAND_HINT`). Кадр строит `Trainer`, вид только рисует
`FrameState`.

## Goals / Non-Goals

Цель — читаемость «какая клавиша, каким пальцем» с одного взгляда и красивый вид в духе роликов
Synthesia без просадки кадров. Не цель — темы, реалистичные руки, редактор эффектов в приложении.

## Decisions

### Кто за что отвечает

- `src/render/fingerColors.ts` (чистый): `FINGER_COLOR: Record<Finger, number>` и
  `noteColor(note, mode)` для режимов `"finger" | "hand"`.
- `src/render/noteGlyph.ts` (чистый): длительность в четвертях → знак (`whole`, `half`, `quarter`,
  `eighth`, `sixteenth`, флаг `dotted`), ближайшая не большая записанная длительность. Длительность
  в четвертях считается через `quartersAt(song, start + duration) - startBeat`.
- `src/render/handPose.ts` (чистый): для руки и её ближайших нот с пальцами — x кончика каждого
  пальца в пикселях клавиатуры, какие пальцы опущены, и центр кисти. Пальцы без ноты интерполируются
  между соседями с естественным шагом (ширина белой клавиши), кисть не шире допустимого размаха.
  Сглаживание переезда — по времени кадра, тоже чистой функцией.
- `src/render/HandsLayer.ts` (Pixi): контурная кисть, нарисованная `Graphics` каждый кадр по позе из
  `handPose` (все контуры, затем все заливки поверх — видна только внешняя граница; `AlphaFilter`
  даёт прозрачность всей кисти разом). SVG-риг от Codex отвергнут: пальцы выходили отдельными
  «сосисками». Следующий шаг — PNG-позы кисти от Codex (`handSprites.ts`: выбор позы, ближайшей к
  клавишам, и её сдвиг по клавиатуре) с цветными кончиками поверх. Было: риг кисти из SVG
  (`src/render/hands/hand-right.svg`: `palm` и `finger-1…5` с точками `base` и `tip`), левая —
  зеркалом. Палец поворачивается вокруг `base` и тянется к кончику из `handPose`; подушечка
  тонируется цветом пальца. Разбор SVG — `Graphics.svg()` Pixi 8 (сигнатуру проверить по
  документации перед кодом).
- `src/fx/` : манифест атласов (генерируется `pnpm fx:bake`), загрузка PNG, пул `AnimatedSprite` по
  эффекту. Эффекты печатаются белыми и тонируются цветом пальца на месте.
- `FallingNotesView` только рисует: блок, свечение, знак, цифру, подсветку клавиш, вызывает пул
  эффектов по событиям кадра.

### Блок и свечение

Скруглённый блок — nine-slice текстура (`NineSliceSprite`), запечённая один раз; свечение — вторая
nine-slice текстура с размытым краем, запечённая через `generateTexture` с `BlurFilter` один раз при
старте, под блоком с аддитивным смешиванием. Фильтры на кадр не вешаются.

### Нотные знаки

Знаки запекаются в текстуры при старте (как цифры и названия нот): векторная отрисовка головки,
штиля и флажков через `Graphics`, по одной текстуре на знак. Знак стоит на голове блока, цифра
пальца — над ним. Предположение: цифра остаётся и в режиме «по пальцу» — цвет не читается у
дальтоников и на ярких блоках.

### События для эффектов

`FrameState` получает список нот, взятых в этом кадре (`struck`), и удерживаемых нот (`held`). Их
считает `Trainer` из того же, чем сейчас красит попадания. Вид запускает вспышку по `struck` и
держит свечение по `held`.

### Запекание эффектов

`scripts/bake-fx-atlases.mjs` — перенос скрипта towerdefander: статический сервер над папкой
редактора, Playwright с системным Chrome, `AFX.Model.loadEffectFile` + `AFX.Atlas.build`, проверка
пустых кадров, атомарная запись PNG + `meta.json`, генерация `src/fx/manifest.ts`. Исходники
эффектов — `src/fx/effects/*.json` + `catalogue.json`. Эффекты: `hit-sparks` (вспышка, ~0.4 с) и
`key-glow` (петля свечения). Режим атласа — белый на прозрачном, чтобы тонировать.

## Risks / Trade-offs

- **Кадр.** Сотни блоков — по две nine-slice на ноту; видимых нот на экране десятки, это в пределах
  нынешнего числа спрайтов ×2. Эффекты — пул фиксированного размера, лишние вспышки отбрасываются.
- **Аддитивное свечение** на светлых клавишах теряется — свечение рисуется только в полосе нот.
- **Риг из SVG** может не совпасть с раскладкой клавиш по пропорциям — кончик тянется к клавише
  поворотом и масштабом пальца, пропорции ладони подгоняются по ширине белой клавиши.
- **Codex-SVG** — сгенерированный ассет; коммитится только после просмотра и согласия пользователя
  (репозиторий публичный).
- **Arcadia** не в сборке; без submodule `pnpm fx:bake` не работает, но приложение собирается из
  закоммиченных атласов.
