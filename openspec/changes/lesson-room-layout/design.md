# Design

## Context

См. proposal.md. Урок исключён из `data-piano-layout-reference`; полоса клавиш берёт `24vh`, а урок
резервирует фиксированные 100/120 px. Flex/grid по умолчанию сохраняют минимальную высоту
содержимого, поэтому итог переполняет область.

## Goals / Non-Goals

Цель — использовать уже существующий расчёт `viewGeometry` относительно внешней рабочей области и
резерв `--piano-required-height`. Профили обучения, диапазон и сохранённые настройки не меняются.

## Decisions

Включить общий опорный расчёт для `lessonBoard`, не для остальных специальных режимов. Урок получает
`min-height: 0`, ограничение фактической оставшейся flex-высотой и собственную прокрутку; клавиатура
остаётся отдельным несжимаемым соседом. Это устраняет зависимость от произвольных 100/120 px.
Содержимое результата переносится в доступной ширине.

Чистый `viewGeometry` уже владеет размером; React только выбирает контекст измерения, CSS размещает
область. `PracticeSession` продолжает владеть временем. Никаких новых измерений в кадре или
перерисовок партитуры.

## Risks / Trade-offs

- На 568×320 весь урок одновременно не помещается → итог и действия доступны вертикальной прокруткой
  выше клавиш.
- Смена высоты полосы при первом измерении → проверить устойчивость повторных ответов, resize,
  reload и точность экранного ввода.
