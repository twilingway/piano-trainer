# Design

## Context

См. proposal.md. `noteNames` сейчас связан со станом и падающими нотами; `fingers` относится только
к стану. `labels` печатает на клавише одновременно C4 и «до», `octaveLabels` независим. Native
дорога получает finger/label, но в свободной камере экранный слой подписей скрыт.

## Goals / Non-Goals

Независимость в пределах существующего StaffPrefs без нового хранилища и дублирующего состояния. Не
менять PracticeSession, подсветку физического нажатия, подсчёт помощи, звук и компьютерные буквы.

## Decisions

- Добавить `keyboardFingers`, `fallingFingers` (по умолчанию true), `fallingNoteNames` (off/ru/en).
  Существующие `labels`, `octaveLabels`, `noteNames`, `fingers`, `chords`, `fingerColors` сохранить.
  Не вводить выбор языка клавиш: он потерял бы двуязычные старые наклейки либо добавил лишний режим.
- Отсутствующий fallingNoteNames наследует валидный старый noteNames; присутствующее повреждённое
  значение получает off. После нормализации поля независимы и сохраняются существующим listener.
- Три блока имеют уникальные названия и доступные подписи элементов. Поля стана не дублируются в
  других блоках. Обычный показ клавишных пальцев не выключает свечение и окраску клавиш.
- Учебные профили и разрешения hints остаются верхней границей: сохранённые предпочтения не
  раскрывают скрытый ответ и не подавляют обязательные управляемые уроком рекомендации. Выход из
  курса возвращает предпочтения; их значения не перезаписываются профилем. Печатная игра прежняя.
- Flat подписи используют уже запечённые текстуры. Native подписи получают отдельный атлас,
  запечённый при создании владельца, и ограниченный instanced-слой. Он использует те же lane/dock/
  performance преобразования, что тела нот. Экранный дубль native-подписей отключается только когда
  native слой доступен; fallback остаётся работоспособным. API атласа эффектов не расширять.
- Названия и пальцы допускаются одновременно; без пальца название занимает свободное место. Карточки
  с нотным станом сохраняют свою нотацию без дополнительного названия, но их finger badge
  подчиняется переключателю падающих пальцев. Название обычного блока следует звучащей
  транспонированной высоте с существующим написанием диезов.
- В HandsPopover убрать закрытие после onHands/onRole. Trigger, Escape и клик снаружи закрывают
  меню; Escape/trigger сохраняют доступный возврат фокуса. Выбор продолжает проходить штатную
  подготовку партии и не запускает часы дополнительно.

## Risks / Trade-offs

- Дубли native/overlay → явная готовность native и тест одного видимого набора.
- Рост draw calls и повторное рисование текста → один ограниченный batch, текст не печётся в кадре.
- Новые настройки обходят учебную политику → регрессии профиля, hints=false и восстановления.
- Старый формат меняет вид → тест миграции names, defaults и reload после раздельных изменений.
- Короткие ноты и дальняя перспектива → ограничение размера подписей геометрией ноты; native подписи
  следуют тем же преобразованиям, без отдельной анимации или часов.

## Migration Plan

Обычное обновление нормализует старый объект и сохраняет новые поля при записи предпочтений. Старый
клиент игнорирует новые поля; прежние ключи и их смысл сохранены. Новых зависимостей нет.
