# Design

## Context

См. proposal.md. Геометрию клавиатуры считают чистые `viewGeometry` (пианино) и `computerGeometry`
(печать); стан подбирает целые строки под долю окна `maxShare`; бегущая строка стоит над
`--hit-line`, которую вид пишет на свой контейнер.

## Decisions

- Чистый модуль `src/app/screenLayout.ts` владеет моделью `ScreenLayout` (доля стана, подъём,
  масштаб клавиатуры, отступ строки), пределами, нормализацией сохранённого и чтением/записью ключа
  `screen-layout` с разделами `piano` и `typing`. React-хук только держит состояние.
- Геометрия получает `KeysPlacement { lift, scale }`: подъём — доля высоты вида, добавляемая к полю
  под клавишами; масштаб — множитель желаемой высоты (у пианино — длины клавиш, у компьютера —
  размера клавиши). Обе функции ограничивают клавиатуру так, чтобы нотам осталась четверть вида. В
  дороге подъём уходит в `handRoom`, и камера опускается выше; высоту перспективных клавиш задаёт
  камера.
- Вид дополнительно пишет `--keys-bottom`; ручки клавиатуры в `.lane` стоят по `--hit-line` и
  `--keys-bottom`, поэтому React не читает геометрию и не зависит от кадра.
- Перетаскивание: общий `DragHandle` захватывает указатель и сообщает смещение от начала. Подъём и
  высота пересчитываются из значений на момент нажатия, без накопления ошибок. Новая высота вида
  применяется через `setKeysPlacement` → `layout()`, как при изменении размера окна.
- Стан: во время перетаскивания двигается только ручка (CSS-смещение); по отпусканию многострочный
  стан получает долю `высота / окно`, однострочный — масштаб `zoom × новая / прежняя`.
- Сдвиг клавиатуры (`x`, `y` в `KeysPlacement`) не пересчитывает геометрию: вид смещает корень
  клавиш и руки при прокрутке, а попадание мышью вычитает сдвиг. Линия удара остаётся на месте. В
  дороге клавиши — часть картинки дороги, и сдвиг к ним не применяется.
- Верх дорожки без стана — пустой блок перед дорожкой высотой в долю экрана.
- Режим определяется включённым режимом печати; сравнение дублей использует то же положение.

## Risks / Trade-offs

- Кадровый цикл: `layout()` вызывается только при изменении положения, а не на каждом кадре.
- Рендер OSMD дорог → стан перестраивается один раз по отпусканию.
- Ручки над клавиатурой могут перехватить нажатие клавиши мышью → полоса захвата 10 px по краю.
- Масштаб однострочного стана общий для режимов: это настройка стана, а не раскладки.
