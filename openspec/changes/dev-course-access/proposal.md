# Свободный просмотр курса на dev

## Why

Для проверки перенесённых песен на локальном dev-стенде приходится повторно проходить предыдущие
финалы. Пользователю нужен свободный доступ ко всем уже подготовленным урокам.

## What Changes

- На Vite dev-сервере подготовленные уроки доступны независимо от предыдущих зачётов.
- Карточки, прямые команды, смена этапа и восстановление используют одну политику доступа.
- Production сохраняет последовательное открытие. Непроверенные материалы остаются «Скоро».
- Свободный доступ не создаёт зачёты и не меняет правило результата 30/70 с порогом 75%.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `lesson-course`: проверка подготовленных уроков на dev без последовательной блокировки.

## Impact

Чистая модель курса получает явную политику доступа; оболочка выбирает её по Vite `DEV`. Контроллер,
восстановление и карточки передают одинаковый режим. Новых зависимостей, формата сохранения,
лицензируемых материалов и изменений часов упражнения нет. Цель — доступ для проверки; перенос ещё
не подготовленной музыки и административные права в production не входят в изменение.
