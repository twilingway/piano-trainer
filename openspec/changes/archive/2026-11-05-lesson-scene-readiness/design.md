# Design

## Context

PracticeSession владеет временем. Playback уже ожидает audio prepare и presentation параллельно.
Учитель меняет key при смене src; первый decode происходит после запуска. Play находится вне потока,
но центрируется по viewport без учёта реальной партитуры. Hold overlay центрируется под головкой.

## Goals / Non-Goals

Готовые кадры и неперекрывающие подсказки без повторного OSMD layout. Не менять нотную геометрию,
оценку, учебный путь, исходную альфу, фотореференсы, темп и независимые часы.

## Decisions

- Браузерный ресурс декодирует idle, достижимые проверенные CDE-позы/компаньоны и наградную звезду;
  мемоизация успешных decode. Hook связывает ресурс с существующим presentation gate. При error
  показывает локализованную ошибку; retry создаёт новый scoped ресурс. Dispose отменяет ожидание,
  старые callback не вызывают present. Аудио продолжает готовиться параллельно.
- Изображение учителя одно, без key по позе. Готовые src сменяются; пока следующий decode ожидается,
  остаётся предыдущий декодированный кадр. Отмена/скрытие не показывает старую позу другой сцены.
- Чистые функции рассчитывают прямоугольники Play и короткого hold. DOM-обвязка измеряет content
  SVG, следующую нотную группу, viewport/keyboard. Play обновляется ResizeObserver,
  mutation/scroll/zoom событиями, без нового кадрового цикла. Hold использует уже существующий frame
  только для прогресса.
- На тесном экране Play располагается поверх клавиш, а не над нотами. Кнопка не участвует в layout
  партитуры. Размер корректируется по свободной области.
- Центровка учителя использует существующие проверенные visible bounds из manifest без переработки
  текстуры; масштаб и компенсация пустых краёв — только CSS.

## Risks / Trade-offs

- Нет места справа от головки либо её закрыл header → компактная64px полоса ниже SVG/имён, у
  видимого курсора, с clamp к visualViewport. Она не исчезает из-за плотности нот и сохраняет текст
  и progress. Null допустим только для отсутствующего accepted hold или непригодной геометрии.
- Медленная/неудачная загрузка → урок не запускается с отсутствующей необходимой графикой; явный
  retry.
- Тесты DOM не доказывают визуальную композицию → интегратор проверяет cold-cache,
  portrait/landscape, resize/zoom в существующей вкладке, без дополнительных окон.
