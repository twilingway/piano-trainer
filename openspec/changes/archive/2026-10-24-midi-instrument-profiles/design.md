# Design

## Context

См. proposal.md. `useMidiOutput` владеет выбранным выходом и адаптером автоматических нот.
`Trainer.setMelodyOutput` перестраивает аудио: смену тембра нельзя привязывать к этому вызову.
Открытие выхода асинхронно, поэтому команды должны применяться после готовности control и при
переподключении. Ранее выбранный `null` означает явное «Нет» и не становится Auto при обновлении.

## Goals / Non-Goals

Чистое описание каталога, атомарный импорт, сохранение выбора и ограниченный MIDI-preview. Сэмплы,
SysEx, поиск банков перебором и рендеринг не входят в изменение.

## Decisions

### Формат и встроенный каталог

JSON: `version` (необязательно, поддерживается 1), `name`, необязательный `midiOutputName`, массив
`instruments`. Запись содержит необязательные `id`, `group`, `panelNumber`, обязательные `name` и
`program` (целое 0–127 либо null), необязательные `bankMSB` / `bankLSB` (целые 0–127). Отсутствующий
id инструмента создаётся из индекса. Повторяющиеся id запрещены, названия допустимы. Банки разрешены
только при числовом program; отсутствующий банк не отправляет CC и не угадывается. Лимиты: 1 МиБ на
файл, 512 тембров на профиль, 64 пользовательских профиля, 120 символов на имя.

Чистый parser и генератор команд находятся в `src/input`; Redux и localStorage — только в shell.
Встроенный Grace содержит 238 записей по фото страниц 15–16. VOI000–127 используют базовые номера
GM; их физическая проверка ограничена роялем и Pan Flute 75. VOI128–237 имеют `program: null`.
Исходные названия и повторяющиеся записи сохраняются. Фото не публикуются; в Git только факты
каталога и описание происхождения. По умолчанию Grace выбран, тембр — «Не менять».

### Импорт и интерфейс

Отдельный блок в настройках «Пианино»: профиль, название, тембр с группами, JSON-импорт, ошибка,
раскрываемое описание и скачиваемый пример. Импорт добавляет новый профиль с отдельным внутренним
id, а не перезаписывает встроенный; повторный импорт также не уничтожает предыдущую версию. Название
можно изменить без изменения команд. Неизвестные MIDI-сопоставления видны, но недоступны для
отправки. Новый или выбранный профиль не выбирает тембр автоматически. Ошибка не меняет профили,
выход или исполнение. Подписи и ошибки локализованы RU/EN.

### Выход и команды

Default `both`, канал 1, keyboardStyle `3d`; сохранённые валидные значения имеют приоритет. Для
отсутствующего сохранённого MIDI-выбора используется Auto; явный null сохраняет «Нет». Повреждённый
выбор остаётся безопасным «Нет». Auto выбирает единственное точное совпадение с `midiOutputName`
активного профиля (для Grace — Piano MIDI Device), иначе единственный выход. При неоднозначности
нужен ручной выбор; чужой MiniFuse случайно не выбирается.

Bank Select MSB (CC0), LSB (CC32), затем Program Change отправляются на канал мелодии после явного
выбора тембра, готовности выхода, смены канала и reconnect. При browser-only автоматической отправки
нет; preview явно разрешает её. Конфликт с включённым каналом подсветки блокирует команды. Выбор
тембра не вызывает Trainer.load/seek/setMelodyOutput и не сбрасывает дубль или камеру.

### Прослушивание

Короткая фиксированная простая мелодия в пределах C4–G4, только выбранный MIDI-выход и тембр. Кнопка
остановки доступна во время preview. Игра должна быть на паузе; без выхода, сопоставления или при
конфликте каналов preview недоступен с пояснением. Смена тембра/профиля/выхода/канала, закрытие
настроек, pagehide, запуск игры и unmount отменяют таймеры и отпускают только свои ноты. Таймер
preview не продвигает сессию; MIDI-эхо preview исключается из оценивания.

## Risks / Trade-offs

- MIDI не подтверждает фактический тембр ответом → UI не выдаёт отправку за аппаратную проверку.
- Банк не указан в инструкции → значение не подставляется; расширенные записи недоступны до импорта
  достоверного сопоставления. Для возврата из нестандартного банка каталог должен явно задавать его
  параметры, если они нужны устройству.
- Быстрая смена / StrictMode / reconnect → generation guards, явная готовность control и тесты
  отсутствия запоздалых сообщений.
- Размер каталога → лимиты и чтение только вне кадрового цикла; OSMD и renderer не участвуют.

## Migration Plan

Добавить отдельную версию сохранения профилей без удаления прежних настроек. Значения по умолчанию
применяются только к отсутствующим настройкам. Старые профили отсутствуют: миграция не требует
сброса localStorage. Удаление функции не меняет сохранённые песни и записи.
