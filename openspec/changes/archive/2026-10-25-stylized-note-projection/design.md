# Дизайн

## Контекст и аудит

ThreeKeysHost/ThreeStage владеют общим WebGLRenderer. ThreeRoadFrame содержит готовые границы нот из
одного PracticeSession; nativeKeyContactPoint и реальные mesh/hinge дают контакты. Камера и модель
клавиатуры остаются прежними. Старые метрические параметры свободного мира не смешиваются с новой
экранной системой.

## Решение

Чистые функции в src/render/stylizedProjection строят 88 anchors, sagitta окружности и X(y) через
общий smoothstep между max(horizonY) и общей полосой выпрямления выше min(keyY). Порядок обоих
наборов X сохраняет порядок во всех горизонтальных сечениях. Y(u)=lerp(H.y,K.y,u^depthExponent).
Радиус ограничивается spread и доступным вертикальным пространством, эффективное ограничение видно в
диагностике. Отрезки полилиний проверяются попарно, а не только при одинаковом u.

Адаптер ThreeStage проецирует контактные точки существующих meshes камерой клавиатуры в CSS px без
DPR. Отдельный orthographic слой рисует фон, дороги и заполненные сегменты нот; готовые top/bottom
из ThreeRoadFrame переводятся в u без новых часов. Длительность остаётся временной; кадры не
интегрируют смещение. Материалы/буферы переиспользуются; пересечения проверяются при изменении
геометрии, не каждый кадр.

Фон процедурный: градиент заката и облачная дымка с границей той же horizonYAtX. Экранный слой
композится до существующих клавиш/рук; эффекты контактов сохраняются. Отдельный debug слой
подписывает pitch/index, C4 и предупреждения, допускает каждую 12-ю дорожку и чистую геометрию.

## Совместимость

Legacy остаётся по умолчанию и при неподдерживаемой клавиатуре/неупорядоченных якорях. Новый режим
не меняет сохранённый диапазон или камеру; все физические 88 контактов учитываются, видимые края
обрезаются viewport. Режим вне экрана/при обратном взгляде сообщает об offscreen/order без скрытого
переставления. Настройки version=1, значения нормализуются без NaN. Открытых продуктовых решений
нет: приняты обязательные этапы ТЗ, optional arcLength и физическая сфера исключены.

## Проверка

Чистые тесты: 88 pitch, круг, симметрия, радиус, C1/концы, все пары путей для трёх пресетов и
четырёх экранов. Интеграция: реальные камеры/контакты, длительная нота, seek/pause/resize/DPR и
возврат legacy. Браузер: исходный/новый FPS и draw calls, desktop/mobile, screenshots. Независимое
ревью и общий pnpm check/spec:validate.
