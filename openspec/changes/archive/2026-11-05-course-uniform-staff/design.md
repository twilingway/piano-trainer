## Context

Staff отключает installUniformStaffLayout для course. Его viewport интерполирует оптические
координаты нот и не имеет завершающего anchor. Обычный uniform renderer уже умеет размещать ноты по
timeAtBeat, но локальные гаттеры сохраняют переменную скорость у границ тактов.

## Goals / Non-Goals

Равные интервалы музыкального времени дают равные экранные смещения при постоянной скорости. Курсор
проходит последнюю длительность до настоящей тактовой черты. Ручной lessonZoom реально масштабирует
ноты после базового вписывания. Не меняем обычную гравировку, время или оценку.

## Decisions

Переиспользуем installUniformStaffLayout с отдельной continuousTime-опцией только для presentationId
song-course: и singleLine. Один глобальный pixelsPerSecond учитывает реальные границы символов и
подписей; локальные гаттеры выключены. Inset остаётся постоянным сдвигом атак; соответствующее место
добавляется к концу последнего stave, чтобы финальная временная точка совпадала с его тактовой
чертой.

layoutStaffTimeline добавляет истинный конец последнего такта и границы темпа на ту же ось. Смещение
cropped SVG по x учитывается в координатах курсора. Экспорт сохраняет исходные ноты, ID и интервалы;
клонированные неподвижные ключ/размер остаются вне scrolling SVG.

Сначала вписывается базовая фраза при значении DEFAULT_STAFF_PREFS.lessonZoom, затем применяется
отношение сохранённого lessonZoom к этому default без повторного density/room fit. Текущие 150% по
умолчанию сохраняют прежний вид, 100% уменьшают его, 200% увеличивают. Большой масштаб может
требовать прокрутки. Preferences не перезаписываются; число 1.5 не дублируется в renderer.

Проверка на телефоне 390×844 показала головки по 9 px: обычный минимум 72 px/s растягивал четыре
четверти, после чего four-event fit уменьшал и символы. Только continuousTime курса использует
минимум 18 px/s. Границы реальных символов, подписей и финальной черты по-прежнему поднимают одну
глобальную плотность при необходимости; локального сжатия времени нет. Обычный renderer сохраняет 72
px/s. Это ограничение пустого горизонтального места, а не изменение сохранённого масштаба.

## Risks / Trade-offs

Равномерная гравировка может стать шире оптической, особенно с длинными подписями; это ожидаемая
цена постоянной скорости. Масштаб выше default может показывать меньше нот одновременно. Простое
снятие !course без устранения гаттеров и начального inset не удовлетворяет постоянной скорости. Весь
расчёт выполняется при layout, без новых timers/RAF, React-рендеров по времени и easing.

## Migration Plan

Миграции нет. Существующая lessonZoom и временная ось Song продолжают использоваться напрямую.
Обычный renderer и иллюстрации/миниатюры не включают новую опцию.

## Open Questions

Нет: пользователь явно запросил равномерность, конец у тактовой черты и работающий масштаб.
