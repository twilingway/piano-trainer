# Design

## Context

Прод собирается на Mac из чекаута `~/piano-prod/repo`: `deploy-production.sh` передаёт `GIT_SHA`
аргументом сборки, `.git` в образ не копируется. Merge-коммит GitHub называется
`Merge pull request #N from …`.

## Decisions

- `deploy-production.sh` берёт номер PR из темы целевого коммита и передаёт его аргументом `GIT_PR`
  через compose в `Dockerfile`; у прямого коммита в `main` номера нет, аргумент пустой.
- `vite.config.ts` подставляет константу `__BUILD_INFO__` с `sha`, `pr` и временем сборки в ISO UTC.
  Модуль `app/buildInfo.ts` типизирует её; разбор пустых значений чистый и тестируемый.
- `AboutSettings` получает сведения о сборке пропсом и только рисует их. Время показывается в
  часовом поясе игрока в формате `ru-RU`. Без SHA (локальный `pnpm dev`) — «локальная сборка».
- PR и SHA — ссылки на GitHub; соцсети — подписанные ссылки, открываются в новой вкладке с
  `rel="noreferrer"`.
- Альтернатива с запросом номера PR к GitHub API из браузера отклонена: лимит 60 запросов в час на
  адрес и лишний сетевой вызов при каждом открытии настроек.

## Risks / Trade-offs

- Тема коммита не по шаблону (squash, прямой пуш) → PR не показывается, остаются SHA и время.
- Константа сборки в тестах → Vitest берёт `define` из того же конфига; компонент тестируется с
  явными пропсами.
- Кадровый цикл и нотный стан не затрагиваются: раздел статичен и строится только при открытии.
