# Design

## Context

См. proposal.md. OSMD остаётся владельцем глифов и музыкальных координат. Независимое архитектурное
ревью разрешило реализацию с точным индексом головки и музыкальными якорями ключей.

## Goals / Non-Goals

Цель — изменить оформление учебной SVG-оболочки. Не менять генератор, раскладку MusicXML,
PracticeSession, правила подсказки, saved preferences или независимые карточки персонажей.

## Decisions

- Материал использует широкое диффузное освещение без specular/screen блика. Прежний эффект давал
  белым нотам металлический вид.
- Одинаковое SVG-лицо находится в отдельной декоративной группе с pointer-events:none. Заполненность
  определяется NoteTypeXml, точная головка — feedbackNotehead. У OSMD 2.1.3 ошибочное имя «eigth»
  оставляет настоящую восьмую с UNDEFINED; только в этом случае разрешён явный обычный заполненный
  код глифа vb, без эвристики по звучащей длительности. Лица состоят из non-path SVG-примитивов с
  собственными цветами и не участвуют в перекраске музыкального глифа и не зависят от ступени;
  неизвестные головки безопасно пропускаются.
- Ключи используют сгенерированные прозрачные матовые текстуры внутри исходного bbox с
  нормализованными музыкальными якорями. Публичный модификатор VexFlow связывается с исходным SVG по
  его точному начальному pen anchor M x y M; контур не распознаётся эвристикой. Необычные ключи и
  октавные подписи остаются исходными. Исходный глиф сохраняется для точного отключения; декорация
  не расширяет измеряемую область.
- Все проходы выполняются после engraving, не в кадровом цикле; повторный вызов идемпотентен.

## Risks / Trade-offs

- Лицо может перекраситься → отдельная группа вне descendant paths музыкальной головки.
- Полая нота может потерять смысл → лица только для известных заполненных NoteTypeXml.
- PNG может сместить смысл ключа → музыкальные якоря и реальная визуальная проверка G2/F4.
- Мелкий размер может скрыть детали → простые глаза/улыбка, проверка телефона и desktop.
- Лишние элементы могут менять fit → все элементы внутри исходных bbox, тесты повторного прохода.

## Совместимость с трёхмерным постером

`publishWorldScore` прежде удалял все image из SVG. После декоративной замены ключа исходный контур
скрыт, поэтому удаление картинки оставляло постер без ключа. Оба WebP импортируются с `?inline`:
SVG-as-image не зависит от внешней загрузки. Экспорт допускает image только при AND совпадении
правильного маркера и точного data URL из этих двух статических импортов. Это не общий allowlist по
MIME или префиксу. Все остальные изображения остаются запрещены. Новых таймеров, кадровых аллокаций
или изменений геометрии нет.
