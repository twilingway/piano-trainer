# Design

## Решение

course.listenOnly — отдельное сохраняемое предпочтение Redux. Адаптер принимает старую запись без
поля как false и отвергает некорректное поле. useTrainer отличает его от временного listeningSource:
завершение сбрасывает только временное прослушивание. Выбор этапа не сбрасывает предпочтение; явный
выбор руки в селекторе сбрасывает. Кнопка «Стоп» останавливает текущий Trainer без смены выбора.

Постоянное прослушивание запускается при его включении в уже загруженной фразе. Загрузка нового
задания и восстановление всегда остаются на паузе. «Сначала» сохраняет предпочтение.

## Границы

PracticeSession остаётся единственными часами. При прослушивании набор играемых рук пуст, поэтому
существующий чистый зачёт отвергает проход. Redux и React только связывают предпочтение с этим
режимом. Нотные события, MusicXML и цикл кадров не меняются; дополнительных рендеров нотного стана
нет.

## Проверки

Hook tests проверяют конец, повтор, смену фразы и этапа, восстановление, «Стоп» и выход через руки.
Persistence tests проверяют round-trip, старую запись, повреждение и ошибки хранилища. Браузерная
приёмка на dev выполняется после слияния; до слияния результат не объявляется видимым пользователю.
