# Направление иллюстраций начальных уроков

- Назначение: маленькие понятные детям изображения действия, не замена музыкальному заданию.
- Контекст: тёмный интерфейс с бирюзовым акцентом; карточка показывает изображение примерно 80–112
  CSS px, короткую цель, прогресс и одну кнопку.
- Стиль: мягкие округлые формы, простые ясные силуэты, спокойный бирюзовый/кремовый цвет, небольшие
  коралловый, жёлтый и лиловый акценты. Без текста, подписей и интерфейса внутри картинки.
- Первое действие: один образец с пианино/нотой проверить в карточке, затем использовать его как
  reference для согласованной семьи. Выбор направления делегирован запросом на переработку карточек;
  окончательную пригодность проверяет фактический preview.
- Семья: правая рука, левая рука, интервалы/соседние ноты, ритм, две руки вместе, удержанный бас с
  мелодией, два ритма, чтение новой фразы, аккорды, повтор на слух, объединённый мини-урок;
  дополнительный общий образец допускается для заголовка группы.
- Картинки не показывают учебно значимую точную аппликатуру: верные ноты, цифры и обозначения рук
  рисует интерфейс из музыкального материала. Изображение не обещает измерение пальца.
- Выход: прозрачные растровые spot illustrations, сжатый финальный webp/PNG либо проверенный atlas;
  фиксированные области/размеры, читаемость на 1× и 2×, без вырезанных краёв и случайного текста.
- Бюджет: стремиться к суммарному весу до 350 KB для библиотеки; измерить фактический размер и
  качество, лениво загружать невидимые изображения.
- Происхождение: генерация для проекта, без чужих персонажей, личных моделей, локальных видео или
  неразрешённых партитур. Манифест хранит tool, дату, prompt/reference, финальные размеры, alpha,
  вес и результат просмотра.
