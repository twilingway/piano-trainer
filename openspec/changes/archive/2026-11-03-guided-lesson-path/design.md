# Design

## Context

См. proposal.md. Исходная библиотека составляет независимые карточки в ConnectedPlayerWindows;
существующие history нормализуются адаптерами курсов. Знакомство хранится только в React и не имеет
постоянной отметки. Истории ограничены по длине.

## Goals / Non-Goals

**Goals:** единый чистый реестр шагов и предсказуемая рекомендация, честная устойчивая отметка,
тонкая интеграция прежних команд.

**Non-Goals:** изменение часов PracticeSession, правил оценки или музыкальных генераторов;
копирование графики, кода, мелодий либо серверных данных Duolingo.

## Decisions

1. Чистый TypeScript-модуль владеет реестром стабильных stepId и расчётом
   completed/current/available; вход — проверенные завершённые результаты и подтверждённые отметки.
   UI получает данные и команды через connected-компонент.
2. Отдельный малый версионированный журнал хранит завершённые stepId, с поэлементной валидацией,
   объединением вкладок и защитой неизвестной будущей схемы. Он не изменяет reading-course-v2. Это
   предотвращает потерю отметки при вытеснении старого результата. Альтернатива только history
   отвергнута из-за её ограниченной длины.
3. Кнопка перехода знакомства в практику сохраняет только факт знакомства. Закрытие ничего не
   сохраняет; старые практические результаты не выдумывают знакомство.
4. reading.start асинхронный: закрывать библиотеку только при selected=true. Ошибка видима в
   маршруте и повторяет ту же команду. Общие музыкальные темы открывают существующий выбор заданий и
   не фиксируют сложность тайно.
5. Маршрут — новое основное представление; старый каталог в сворачиваемом разделе с существующей
   памятью окна. История не строится пока каталог закрыт. Помощник — сжатый прозрачный WebP и
   текстовая реплика; анимация только CSS и учитывает prefers-reduced-motion.
6. Личные фото и APK локальны. В продукт входит производная иллюстрация, запрошенная пользователем;
   provenance фиксируется без включения личных исходников.

## Risks / Trade-offs

- Потеря читаемости на мобильном → проверка 320/390 px и настольного экрана.
- Частые снимки runtime → узкие подписки, отсутствие расчётов в кадровом цикле и повторного рендера
  OSMD.
- Повреждение/недоступность storage → безопасное чтение и явное сообщение о невозможности сохранить,
  исходная история не затрагивается.
- Сходство лица субъективно → сначала один визуальный образец, корректировки пользователя до
  производства семейства поз.

## Migration Plan

Маршрут подхватывает только проверенные существующие результаты без изменения их данных; знакомства
не мигрируются. Откат UI не влияет на истории, отдельный журнал можно игнорировать старой версией.
