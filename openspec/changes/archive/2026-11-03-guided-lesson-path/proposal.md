# Proposal

## Why

В сетке начальных курсов новичку трудно выбрать следующий шаг; знакомство спрятано среди
дополнительных действий. Нужен последовательный учебный маршрут с короткими целями и узнаваемым
персональным помощником.

## What Changes

- Основной экран «Первые шаги» становится вертикальной дорожкой небольших заданий с одним
  предложением продолжить.
- Первые темы раскрываются на знакомство, отдельные ноты, фразы и самостоятельную проверку;
  остальные существующие начальные курсы следуют за ними.
- Помощник — пластилиновый персонаж по предоставленным пользователем фотографиям: узнаваемое
  взрослое лицо, очки, цилиндр, тёмное пальто и рыжий воротник. По уточнению пользователя голова
  ближе к естественным пропорциям, лицо более пластилиновое.
- Все прежние задания и подробный прогресс остаются в свободном каталоге. Прогресс сохраняется,
  блокировок нет.
- Существующие результаты дают только фактическую отметку соответствующего задания; явное завершение
  знакомства хранится отдельно от музыкальных навыков.

## Capabilities

### New Capabilities

- `guided-lesson-path`: последовательность небольших шагов, рекомендация продолжения и честные
  отметки завершения.

### Modified Capabilities

- `song-library`: начальные уроки открываются как дорожка с помощником, прежние карточки доступны
  отдельно.

## Impact

Чистая модель маршрута, connected-адаптер существующих команд, UI библиотеки, локализованные RU/EN
строки, отдельный небольшой журнал отметок знакомства и завершённых шагов. Музыкальные генераторы,
PracticeSession, история и её фильтры сохраняются.

Продуктовые решения: последовательность рекомендательная, без жёстких замков и без заявления об
освоении. Новых production-зависимостей нет. APK и личные исходные фотографии остаются локальными; в
приложение попадает только созданный по просьбе пользователя персонаж. Материалы Duolingo
используются для исследования, не копируются в продукт. Переработка самих музыкальных генераторов и
новые типы упражнений вне этого изменения.
