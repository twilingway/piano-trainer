## Context

Результат хранит версию рубрики и воспроизводимое доказательство. Граница начала попытки уже знает
CourseMaterial.node.kind, чистая оценка получает только config. Нельзя определять вводный этап по
строковому ID или переоценивать сохранённую v2 новой формулой.

## Goals / Non-Goals

Цель — две звезды при pitch100/onset100/hold75 в знакомстве с нотами. Не меняются допуски
удержания/начала отдельных нот, источник, transport, часы PracticeSession, ревизии музыки и старые
результаты.

## Decisions

- Добавить song-course-v3, оставить явные v1/v2 в допустимых версиях.
- Опциональный introductory:true в config/result задаётся только из material.node.kind===notes.
  Отсутствие флага означает стандартный порог 80.
- v3 с introductory:true использует порог второй звезды 75, pitch80. Первая звезда требует pitch60.
  Третья проверяется первой: pitch95, hold90, onset90 либо null.
- Валидация сохранения воспроизводит исходный контекст и версию. v1/v2 не принимают новый флаг. При
  зачёте узла introductory:true дополнительно требует canonical node.kind=notes; подмена типа на
  performance не создаёт зачёт.
- Старые receipts не переписываются, новые результаты используют v3. Каталог, MusicXML и sourceHash
  остаются прежними.
- Граница app только передаёт флаг в чистый core; новых таймеров/подписок/кадровых вычислений нет.

## Risks / Trade-offs

Опциональный флаг позволяет оставить стандартными синтетические и непомеченные попытки; его
допустимость всегда подтверждает исходный узел при практическом зачёте. Проверки обязаны отличать
сохранённые v2 с одной звездой от новых v3 с двумя на одинаковых процентных осях.

## Open Questions
