# Приёмка: отдельный масштаб стана и табов

Дата: 27.10.2026. Ветка `fix/reader-scale`, база dev `f9ebb9b`.

## Поведение

- `zoom` остаётся масштабом стана, `tabsZoom` задаёт размер табов. Оба 50–200%, шаг 10%.
- Отсутствующий tabsZoom наследует нормализованный legacy zoom; явно повреждённое значение получает
  default 1. Ключ staff-prefs и существующий механизм сохранения не меняются.
- Базовая подгонка стана определяется отдельно от tab spacing; ручной множитель применяется после
  неё. WeakMap не удерживает старые OSMD, внешний viewport/CSS-бюджет и смена engraving mode
  инвалидируют базу; внутренний scrollbar и tabsZoom её не меняют.
- Обе руки табов получают один размер. Shared spacing резервирует место по названиям нот, названиям
  и общему zoom, не увеличивая размер нотных символов от tabsZoom.
- Wrapped SVG получает фактическую ширину ink/staves через публичный backend.resize с прежним
  отношением pixel/viewBox. Содержимое прокручивается внутри прежней области чтения.
- Специальная подгонка P1–P8, музыкальное время, ноты и оценка сохранены. Внешний вид курсора и его
  окончание — отдельная следующая задача.

## Видимый Chrome

Точные viewport заданы через device emulation, подтверждены innerWidth/innerHeight. Материал:
доступная в dev фраза 1 урока 2, обе руки; плотные четверти доли справа и длинные удержания слева.
Это проверка отображения и программных UI-команд, не аппаратного MIDI/аудио.

- Single-line, 1440×1000: staff 100→150% увеличил первую notehead 11,98718×10,44676 →
  17,98145×15,67072 CSS px; табы обеих рук остались 20,8 px. Затем tabs 100→150% дал обеим рукам
  31,2 px, notehead осталась 17,98145×15,67072.
- В wrapped найден и устранён дополнительный дефект: при неизменном staff 140% изменение tabs
  100→150% меняло notehead 11,69659→12,72295 px. Регрессия теперь проверяет реальный OSMD после
  повторной раскладки и изменения внутренних scrollbar.
- Финальный wrapped, 1440×1000, staff 140%: tabs 200→100→150% даёт обеим рукам 41,6→20,8→31,2 px;
  ширина первой notehead 12,722733→12,722900→12,722946 px (разность менее 0,001 px). Staff 140→150%
  затем даёт notehead 13,63185 px, табы сохраняют 31,2 px.
- RU-названия при tabs 200%: обе руки 33,8 px на 320×568; фактического наложения соседних подписей
  одной руки не обнаружено.
- Только табы, только стан и совместный показ проверены; порядок после повторного включения
  сохраняет прежние правила. Внутренняя прокрутка достижима: staff scrollLeft=800 и scrollTop=100,
  tabs scrollLeft=800, document width остаётся 320.
- До исправления wrapped на 320×568 пять notehead выходили за SVG width 245. После исправления и
  финального cache: SVG 868 px, staff client 245 px, выходящих notehead 0. При 390×844: client
  315/scroll 888; при 667×375: client 592/scroll 850; выходящих notehead 0, document width в каждом
  случае равен viewport.
- Регуляторы RU на 320×568 и EN на 390×844 доступны в окне, без overflow. При 667×375 окно 651×359
  расположено x=8/y=8, закрытие доступно.
- Воспроизведение при изменении staff zoom: progress 2→10%, после паузы 15→15%. Перезапуска фразы не
  произошло; табы сохранили свой коэффициент. Reload восстановил staff 150% и tabs 150%,
  автоматического старта нет.
