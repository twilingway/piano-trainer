## Context

Каталог содержит отдельные узлы одинаковой музыки из разных тактов. Удаление IDs ломает историю, а
простой фильтр скрывает старый зачёт. Финальная партитура должна оставаться полной.

## Goals / Non-Goals

Сократить основной маршрут, сохранив каждый этап доступным и все доказанные результаты. Не менять
grading, MusicXML, sourceHash, историю, часы сессии и разные учебные цели.

## Decisions

Чистый coursePath(source) строит immutable-проекцию visibleNodes/повторы/representative IDs. Только
guided-phrase сравниваются с guided-phrase, independent-phrase — с independent-phrase. Сигнатура
включает высоту, относительные начала и паузы в долях, длины в долях, записанный палец,
руку/партию/стан и полный размер фразы. Абсолютный такт и source-ID не входят. Источник разбирается
один раз, результат кешируется WeakMap по неизменяемому объекту source. UI не строит материал в RAF.

pathProgress проверяет каждый receipt против ЕГО исходного узла прежними strict-функциями, затем
объединяет только отображение лучшего зачёта эквивалентных узлов. Сырые ID не меняются. Основные
карточки, счётчики и продолжение используют одну проекцию. Повторы остаются отдельными карточками в
локализованном раскрытии. Старый выбранный узел остаётся доступным; основная карточка подсвечивает
представителя. Next ищет первый видимый этап после исходной позиции старого узла, чтобы не
возвращаться назад. Начальные ноты, длительности и финал не сворачиваются.

## Risks / Trade-offs

Похожая высота с другим ритмом, пальцами, паузой или учебной целью не считается дубликатом.
Частичный либо поддельный proof не переносится. Неверный источник не получает выдуманный зачёт.

## Migration Plan

Миграции хранения нет. Старые node IDs и выбор остаются разрешимыми, route-group — представление.
