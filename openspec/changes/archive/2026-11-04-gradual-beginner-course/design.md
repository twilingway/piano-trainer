# Design

## Context

См. proposal.md. ReadingSession считает 20 ответов, а общий runtime выбирает один policy чтения.
Старый генератор ограничен пятью высотами.

## Goals / Non-Goals

Чистое ядро нового курса владеет диапазоном, размером, версией и валидацией. React отвечает за
выбор, видимость и сохранение, PracticeSession остаётся единственными музыкальными часами. Старые
результаты не мигрируют и не меняют seed.

## Decisions

- Каталог 16 стабильных стадий, фазы intro/guided/independent; версия генератора 1, seed uint32.
  Новый генератор пишет точные октавы, неполные такты implicit, парсит MusicXML один раз; solver
  рассчитывает аппликатуру за пределами пяти нот.
- ReadingSession получает явный targetCount по умолчанию 20. Мини-результат оборачивается и
  валидируется отдельно, не попадает в reading/bass историю.
- useBeginnerCourse владеет сохранённым выбором/результатами и даёт override общему
  useReadingCourse. Одна существующая useReadingTrainer выбирает результирующий policy; второй
  configureCourse отсутствует.
- beginner-course-v1 использует атомарный updateLibrarySetting с merge по ID; отдельные записи
  проверяются, неизвестная будущая схема защищена. Выбор восстанавливается, ответы не
  восстанавливаются.
- Новая компактная панель считает фактическое число ответов. Guided показывает имя/цвет после
  зарегистрированной помощи. Independent использует check, помощь отсутствует. Видимый диапазон
  ограничивается только для курса без записи предпочтений игрока.
- Маршрут добавляет новые команды перед старым массивом, старые IDs и журналы остаются доступны.

## Risks / Trade-offs

- Устаревшие события → identity сессии и selectionRevision проверяются до ответа/сохранения.
- Сбой IndexedDB → видимая локализованная ошибка, игра доступна, будущая схема не перезаписывается.
- Частый рендер staff → генератор/диапазон memo, только текущий prompt меняется; нет новых таймеров
  или кадровой геометрии.
- Одна законченная серия рекомендует продолжение, но не означает освоение.
