## Context

Нынешний repeat клонирует исходную половинную ми в два такта. Замена длительности под прежним ID
сделала бы старый proof двусмысленным. Startup выполняет только один переход supersededBy.

## Decisions

Новый узел hot-cross-buns/notes-e-quarter-v1 использует явный repeat.duration = quarter. Старый
notes-e-repeat-v1 остаётся доступным в legacyNodes с явным duration = half; отсутствие duration не
трактуется как четверть. Builder остаётся ограниченным четырьмя повторами исходной половинной ми:
для quarter переписывает только производные duration/type в одном такте 4/4, для half сохраняет два
такта. Высота, третья аппликатура и происхождение исходной ноты сохраняются.

Derived XML ID строится из нового node ID, поэтому MusicXML, Song, expected, demo и proof разделяют
одну новую идентичность, сохраняя исходный fingerprint. Никакой код grade/history не переносит
зачёт. Оба legacy-узла ссылаются напрямую на quarter-v1: восстановление selection не зависит от
цепочки. Их материал, proof и результаты остаются доступны по прежним ID.

Знакомства C/D не меняются; сборная мелодия и финал сохраняют настоящий исходный ритм. Половинные и
целые остаются отдельными занятиями. Восьмые и шестнадцатые требуют отдельной будущей реализации с
постепенным введением после четвертей и не добавляются в скрытый режим этого PR.

## Verification

Проверить один такт, четвертные атаки/длительности и палец 3; round-trip XML→Song→expected, demo,
четыре физические атаки, один длинный hold без полного зачёта. Оба legacy proof сохраняются, включая
сохранённый four-half proof; не завершают новый узел даже при подмене nodeId. Startup обоих ID ведёт
непосредственно в новый ready. Отдельно доказать неизменность sourceHash/revision/XML, финала и
четвертей C/D. Root выполняет видимую QA после PR, этот агент не запускает browser/server.
