# Проверка общей геометрии

Проверка ветки на существующем пользовательском Vite 5190 через отдельную игнорируемую
HTML-страницу, которая импортирует исходники worktree. Основная папка остаётся на dev; новый сервер
не запускался. Обычный профиль пользователя не менялся.

- Видимый Chrome: 1440×900, 320×568, 390×844, 667×375; короткая фраза и полное упражнение локального
  урока, обе панели и самостоятельные табы.
- На 240 движущихся кадрах: расхождение внутренней тактовой черты ≤0,159 px; курсоров ≤0,001 px;
  разница перемещения двух панелей за кадр — 0 px.
- Короткая фраза: тактовые черты, включая финальную, совпадают ≤0,027 px. Продолжение лиги не
  создаёт букву повторного нажатия.
- Проверены смена фразы, пауза и переход по ноте стана, порядок панелей, изменение размера,
  выключенное следование и строки. При самостоятельных табах снимок стана отсутствует.
- Русские названия: широкая строка без наложений; сжатая мобильная строка подстраивает размер,
  промежуток между соседними подписями ≥3,98 px.
- Ревью нашло и закрыло несовпадение начал viewport и лишнее горизонтальное следование в
  wrapped-режиме. Дополнительная проверка закрыла сдвиг центра при вертикальной полосе прокрутки.
- Тесты покрывают отдельные черты, дробные атаки, паузы, лиги, системы, сброс старого снимка,
  кадровое чтение, русские подписи и разные ширины viewport.

## Проверка после слияния

PR #143 влит; основная папка на dev обновлена fast-forward до e41b427. Обычная страница
http://localhost:5190/ отдаёт новую раскладку. Пользовательский сервер PID 129468 обслуживает
основную папку и сохранён работающим.

На 180 движущихся кадрах обычной dev-страницы: расхождение черт ≤0,019 px, курсоров ≤0,001 px,
разница перемещения панелей за кадр — 0 px. На 320×568 курсоры совпадают ≤0,001 px, страница не
имеет горизонтального переполнения. Ошибок консоли нет. Исполнение после проверки поставлено на
паузу; сохранённые настройки обычного профиля пользователя не изменялись.

Музыка и браузерные снимки в PR не входят. При сохранении старого состояния HMR страницу следует
перезагрузить.
