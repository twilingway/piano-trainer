# Нотный стан для MIDI

## Why

Песня из MIDI сейчас играется без нотного стана: стан рисуется только из MusicXML. Для
импортированных мелодий игрок видит одни падающие ноты, хотя большинство уроков опирается на стан:
аппликатура и названия нот на нотах, курсор, клик по такту.

## What Changes

- При открытии MIDI тренажёр записывает из его нот партитуру на двух нотоносцах (правая рука —
  скрипичный ключ, левая — басовый): начала и концы нот округляются до шестнадцатых, короткий зазор
  перед следующей нотой (до трети длины ноты) закрывается, на каждую руку один голос.
- Ключевые знаки — из файла; если файл их не называет — по тональности, в которой звучат ноты. Знаки
  альтерации — диезы в диезных и до-мажорной тональностях, бемоли в бемольных.
- Стан MIDI-песни работает как у MusicXML: аппликатура, названия нот, аккорды, переносы строк,
  курсор, клик по такту, транспонирование.
- Ноты песни (время, длительности, партии) остаются из MIDI; партитура их только показывает.
- Запись дубля в ноты использует ту же запись партитуры; смена размера посреди песни теперь
  отражается и там.
- Рабочее соглашение «MIDI не притворяется партитурой» в `AGENTS.md` и `openspec/config.yaml`
  заменяется на «стан MIDI — партитура, записанная из его нот; песня из неё не перечитывается».

## Goals

- У любой песни из MIDI есть читаемый стан, связанный с падающими нотами.

## Non-Goals

- Триоли и другие ритмы вне сетки шестнадцатых: они записываются округлёнными.
- Несколько голосов на нотоносце: нота, которую держат под следующей, обрывается на ней.
- Темповые обозначения и динамика на стане.
- Упрощённая версия (`midi-arrangement`).

## Capabilities

### New Capabilities

- `midi-score`: нотный стан, записанный из нот MIDI.

### Modified Capabilities

Нет: требования к стану MusicXML не меняются.

## Impact

Чтение MIDI, новый модуль записи партитуры (общий с записью дубля), транспонирование MIDI-песни,
рабочее соглашение в `AGENTS.md` и контекст `openspec/config.yaml`. Новых зависимостей нет. Большой
оркестровый MIDI (8 тыс. нот) записывается за ~0.1 с при открытии.
