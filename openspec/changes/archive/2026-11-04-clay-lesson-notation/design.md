# Design

## Context

Staff.relayout сначала перезаписывает XML-цвета через setStaffColors, затем красит SVG через
paintStaffNotes. Нужны явные режимы материала и разрешения палитры, иначе персональные цвета и
проверки получат неявную подсказку. См. proposal.md.

## Goals / Non-Goals

**Goals:** учебный пластилиновый материал без новой геометрии и без работы в rAF, независимые
персонажи и явная граница помощи. **Non-Goals:** новый шрифт, новый рендерер, лица в нотных
головках, изменение чтения или генераторов, клавиатура.

## Decisions

- Чистый XML-проход меняет только color написанных нот. Палитра C coral, D amber, E lime, F mint, G
  sky, A lilac, B rose; общий реестр для UI и XML. Невалидный XML возвращает исходник.
- По умолчанию учебный course-стан использует clay, обычный стан сохраняет classic; знакомства явно
  включают clay и палитру. В практике палитра разрешена только после уже зарегистрированной
  подсказки имени. Контроль остаётся одноцветным. Цветовая подсказка раньше имени не появляется.
- Сохранять NoteheadColorXml в разрешённом режиме. Аккорд красить по публичному vfnoteIndex, не
  целиком через noteheadShapes. Остальные режимы сохраняют нынешнюю покраску.
- Тонкий SVG-shell устанавливает материал после финального render/paint и до измерения/публикации
  геометрии. Небольшие локальные inner-highlight/shadow фильтры и округлённые линии сохраняют
  базовый цвет. Уникальные ID на SVG, идемпотентный повтор. Не фильтровать весь SVG, подписи, пальцы
  или курсор.
- NoteCharacter использует семь прозрачных сжатых картинок и текстовые имена; вверх/вниз — отдельные
  ассеты, лицо не переворачивается. Детерминированная нарезка и нормализация разрешены после
  генерации.

## Risks / Trade-offs

- Цвет выдаёт ответ → только знакомство/открытая именная подсказка, в контроле выключен.
- Тяжёлые фильтры → локальные малые области, один раз на relayout, проверить реальный мобильный
  viewport и исключить expensive blur/displacement.
- Полые ноты могут залиться → не менять контур глифа и проверить половинные/целые.
- Saved colors и обратная связь → базовый цвет материала наследуется из глифа, текущий/mark имеет
  приоритет.

## Migration Plan

Никакой миграции данных; источник MusicXML не перезаписывается. Откат убирает skin, прежние
настройки и история на месте.
