# Приёмка исправления native-клавиатуры

## Поведение

Сброс расположения использует естественную проекцию объёмных клавиш. Если доступная область слишком
мала, вся проекция уменьшается равномерно. Ручная высота остаётся отдельной регулировкой.

В ракурсе «Игрок» кадр учитывает переднюю стенку белых клавиш и полный ход нажатия 8 мм. Новый
пресет выбирается кнопкой «Игрок»; сохранённая пользовательская камера автоматически не заменяется.
Эталон DEFAULT_CAMERA, исходный GLB и принятые формы рук сохранены.

## Автоматическая проверка и review

Профильный набор проверяет реальный путь FallingNotesView → RoadLayer → native camera, диапазоны
25/49/88, resize, руки и ноты on/off, ручную высоту, CPU/GPU-проекцию и picking. Отдельный тест
проверяет реальные вершины исходного GLB в отпущенном и нажатом состоянии. Финальный профильный
прогон исполнителя: 154 теста. Независимое review закрыло найденный недостающий запас под ход
клавиши; повторный независимый набор — 91 тест.

Полный гейт: VITEST_MAX_WORKERS=2 pnpm check — PASS: 4234 теста и 23 теста с React Compiler;
форматирование, ESLint, TypeScript и production build — PASS. До архивации pnpm spec:validate — 79
passed, 0 failed. Ограничение workers применено только к запуску, конфигурация тестов не менялась.
Первый неограниченный прогон выявил устаревшее ожидание прежнего player pitch (исправлено) и два
таймаута тяжёлых тестов рук; повтор с двумя workers прошёл полностью.

## Границы

Аппаратная MIDI-приёмка и калибровка остаются отложенными по просьбе игрока. Чёрные углы 2D-нот,
интерфейс уроков, FPS, анимации, масштаб и курсор табов перечислены в docs/CURRENT_FIX_QUEUE.md и
этим изменением не объявляются исправленными.
