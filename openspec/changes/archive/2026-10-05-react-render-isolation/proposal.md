# Изоляция обновлений React

## Why

Публикация снимка игры каждые 150 мс обновляет весь App, включая закрытые окна. Сбор отладочных
стеков усиливает цену этой работы и мешает плавному падению нот.

## What Changes

- Перенести частые подписки к HUD, прогрессу, тексту и открытым панелям; оставить в оболочке редкие
  состояния управления.
- Разделить соединение данных с компонентами представления, исключить содержимое закрытых окон из
  работы.
- Подключить React Compiler для автоматической мемоизации без механического оборачивания всего кода
  в useMemo/useCallback.
- Сохранить часы сессии, MIDI/ПК/мышь, настройки, выбранную вкладку, уроки, запись и сравнение.

## Capabilities

### New Capabilities

Нет: это рефакторинг и настройка сборки, без нового поведения продукта. Используется skip_specs:
true.

### Modified Capabilities

Нет. Действующие player-settings, screen-layout, timing-engine и word-typing остаются контрактом.

## Impact

App, app-хуки и небольшие подключённые компоненты; окна и текст UI; Vite и документация архитектуры.
React Compiler, Babel и адаптер Rolldown добавляются только как devDependencies. React 19
предоставляет compiler-runtime; новых production dependencies, Context или глобального product store
нет. Автоматическая мемоизация явно входит в запрос пользователя. Чистое ядро, музыка и формат
сохранённых данных не меняются.
