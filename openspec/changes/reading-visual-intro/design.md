# Design

## Context

Памятка находится в `ReadingCourse.tsx`; библиотека открывает её через `ConnectedReading`. Staff уже
умеет показывать XML и выделять ноту по статическому beat. Профиль упражнений скрывает готовые
ответы и не должен зависеть от иллюстраций знакомства.

## Goals / Non-Goals

Цель — видимая связь названия, нотного стана, клавиши и пальца. Не добавляются MIDI-события, новая
сессия, звук, часы, зависимости и постоянные наклейки в основном тренажёре.

## Decisions

- Чистый `src/reading/introduction.ts` владеет пятью соответствиями и постоянным исходным MusicXML.
  Тесты проверяют реальные MIDI-высоты и позиции beat через существующий парсер.
- Отдельный `ReadingIntro.tsx` рисует HTML/SVG-клавиатуру и использует существующий Staff. Нотные
  головки не рисуются вручную: MusicXML остаётся источником. При выборе меняется только beat; XML не
  перезагружается, нет отдельного музыкального времени.
- Обзор C2–C6 — ориентир; увеличенная октава C4–B4 показывает чёрные группы 2+3, интерактивны только
  C4–G4. Подписи и текст проходят через RU/EN; finger 1 дополнен названием «большой палец».
- Staff изолирован от общих геометрических каналов (`shareGeometry=false`), ошибка выводится через
  presentation callback, повторная загрузка меняет ключ экземпляра. Размер области стана стабилен.
- «Начать читать ноты» передаёт callback в shell: закрыть intro, затем `reading.start('notes')`.
- Схема руки повторно использует `hands/five.webp` и координаты кончиков из `HAND_SPRITES`;
  отдельный UI-компонент накладывает номера и выделение, список подписей выбирает ту же ноту.
  SVG-контейнер размещает существующий растр и подписи; новое изображение не генерируется.

## Risks / Trade-offs

- Размер стана на телефоне → фиксированная область, собственные стили внутри диалога и проверка 320
  px.
- OSMD загружает XML асинхронно → актуальные presentation callbacks, локализованный retry и тест
  реального OSMD.
- Обозначения октав разных производителей различаются → текст явно относится к обозначениям
  приложения.
- Дублирование таймеров/часов → локальный выбор только меняет статический beat, не запускает сессию.
