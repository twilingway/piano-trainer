## Автоматические проверки

- `pnpm check`: форматирование, ESLint, TypeScript, 1624 теста и production-сборка прошли; один
  существующий тест пропущен. Запуск выполнен с разрешённым выходом из sandbox, поскольку дочерние
  процессы Vitest/Vite в ограниченной среде Windows получают `spawn EPERM`.
- `pnpm spec:validate`: 41/41.
- Независимые spec_architect и reviewer: блокирующих замечаний нет.
- Новые тесты проверяют MIDI-высоты и времена исходного XML, загрузку настоящим OSMD, локализованное
  преобразование подписей, связанный выбор ноты/клавиши/пальца, отсутствие перезагрузки XML при
  выборе, retry и устаревшие callbacks, отдельные действия закрытия и старта.
- Для руки использованы существующие `five.webp` и координаты кончиков пальцев из
  `handSpriteCatalog`; отдельная картинка и новые зависимости не добавлялись.

## Браузер

Проверены реальные компоненты ветки в видимом Chrome на существующем пользовательском
`localhost:5190`. Компонент временно смонтирован отдельно через Vite `@fs` из worktree с его CSS;
основная папка продолжает обслуживать `dev`, без подмены файлов и запуска другого сервера. После
проверки временный монтаж убран перезагрузкой страницы.

- Размеры: 1688×1000, 320×568, 390×844, 667×375.
- Настоящий Staff отрисовал все пять нот с русскими названиями, без ошибок и обрезания нот.
- Все пять выборов сохраняют один SVG и высоту Staff: 162 px с рамкой, на 320 px — 152 px. Связанные
  клавиша и палец выделяются правильно.
- Блок пояснения сохраняет высоту при всех пяти выборах: 198 px на 320 px, 160 px на 390 px;
  переполнения текста нет.
- Горизонтального переполнения модального окна нет. На узких экранах доступна вертикальная прокрутка
  к кнопкам пальцев, пояснению и началу упражнения.
- Схема существующей правой руки видна; номера стоят на кончиках пальцев, подписи читаются.
- Кнопка начала вызывает callback старта и закрывает знакомство в проверочном монтаже. Настоящий
  переход к серии через библиотеку требует слияния PR и обновления основной папки; задача 3.3
  остаётся открытой.
