# Design

## Context

Мотивация описана в proposal.md. Сессия владеет временем, GameScore повторно оценивает signed offset, а подсветка nextDue сейчас включается слишком рано. Visual Offset меняет только изображение нот.

## Goals / Non-Goals

Общий флаг learningWindow связывает подбор ноты, оценку и snapshot. Не меняем часы, offset ввода, PERFECT или правила рейтинга.

## Decisions

- Учебная атака получает существующее OK: отдельная шестая категория усложнила бы статистику. Реальная ошибка передаётся в текст обратной связи.
- Отдельные ранняя и поздняя границы в сессии; поздняя граница используется для expiry и аккорда, допуск timestamp добавляется независимо. Это предотвращает преждевременный MISS и расширение ранних атак.
- Флаг сохраняется в настройках, отключается для Ranked, snapshot запуска и дубля фиксирует его. Старые дубли совместимы благодаря optional-полю.
- Подсветка вычисляется чисто из начала ноты, времени сессии и скорости. Спрайты меняют прозрачность и tint; новые Graphics и покадровая генерация текстур не нужны.
- Подсказки учитывают все pending-атаки в ближайших 300 мс, а не только earliest chord, чтобы поздняя предыдущая нота не скрывала подготовку следующей.

## Risks / Trade-offs

- Пересекающиеся окна → ближайшая pending-нота и тест повторной высоты.
- Скорость и Visual Offset → тесты 50 % и отдельное время подсказок.
- Поздний callback и последний короткий звук → тесты expiry/finish и доставки timestamp.
- Визуальная оценка анимации → видимый Chrome на основном localhost:5190 после интеграции.

## Migration Plan

Расширить optional snapshot и сохраняемую настройку с default true. Зависимости не добавляются. Откат — выключение настройки либо возврат PR.
