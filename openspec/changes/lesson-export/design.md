# Design

## Context

Уровень урока — строка MusicXML (`ExerciseLevel.musicXml`). `lessonSong(choice)` читает её в `Song`
с заголовком «<урок> · <уровень>»; `withFingering(song, overrides)` расставляет пальцы, а правки
игрока лежат в localStorage под ключом `fingering:<title>:<число нот>` (`useSong.ts`).
`musicXmlWithFingering(xml, notes)` уже вписывает пальцы в XML для нотного стана. MIDI сейчас
пишется только для дубля (`takeToMidi`, `@tonejs/midi`).

## Goals / Non-Goals

**Goals:** чистые функции «песня → MIDI» и «урок → файл», которые проверяются тестами без DOM-клика;
UI только вызывает их и отдаёт файл браузеру.

**Non-Goals:** экспорт текущей (транспонированной) песни с экрана; общий механизм экспорта для любых
источников.

## Decisions

- **`songToMidi(song)` в `src/song/songMidi.ts` (чистый).** Темп берётся из сетки `song.beats`:
  между соседними долями bpm = 60 · Δposition / Δtime, событие темпа пишется там, где bpm меняется
  (с округлением до 0,01). Затем `header.update()`, и ноты добавляются в секундах (`time`,
  `duration`) — библиотека сама переводит их в тики по карте темпа, так что тики совпадают с долями
  партитуры. Размер такта — из `song.measures` (событие там, где он меняется). Дорожки «Right hand»
  (канал 0) и «Left hand» (канал 1); пустая дорожка не создаётся. Громкость нот без velocity —
  80/127. Альтернатива — одна дорожка в темпе 120: проще, но в DAW сетка тактов не совпадёт с
  нотами.
- **`lessonExportFile(choice, format)` в `src/app/lessonExport.ts`.** Возвращает `{ name, data }`:
  `lessonSong(choice)` → `withFingering(song, loadOverrides(song))`; для MusicXML —
  `musicXmlWithFingering(level.musicXml, fingered.notes)`, для MIDI — `songToMidi(fingered)`. Правки
  читаются той же функцией и с тем же ключом, что и на экране, поэтому экспорт совпадает с тем, что
  видит игрок в исходной тональности. Для этого `loadOverrides` в `useSong.ts` становится
  экспортируемым (перенос хранилища в отдельный модуль — отдельный рефакторинг, не здесь).
- **Имя файла.** `<exercise.title> · <level.title>` с заменой `\ / : * ? " < > |` и управляющих
  символов на `-`, расширение `.musicxml` / `.mid`.
- **Скачивание в UI.** `App.tsx` передаёт в `LibraryDialog` `onExportLesson`, который строит файл,
  делает Blob (`application/vnd.recordare.musicxml+xml` / `audio/midi`) и кликает временную ссылку —
  тот же приём, что `downloadTake` в `useTakeReview.ts`. Кнопки — компактные чипы рядом с чипом
  уровня; они не закрывают диалог.

## Risks / Trade-offs

- [Темп по сетке долей может дрожать из-за плавающей точки] → округление bpm и запись события только
  при реальном изменении; тест проверяет один tempo event у урока с постоянным темпом.
- [Правки, сделанные в другой тональности, в экспорт не попадают] → так и задумано: экспорт — урок в
  исходной тональности (non-goal в proposal).
- [Кадр и нотный стан] → экспорт выполняется по клику, вне игрового цикла; на кадр и OSMD не влияет.
