# Музыкальные символы искр

Из встроенных PNG в src/fx/piano-hit.json собирается статический SVG-атлас из пяти ячеек128×128.
Исходные PNG включены как data URI: внешние шрифты, сеть и новые зависимости не нужны. TextureLoader
растеризует атлас при создании двух существующих партий. Отдельный канал исходного seed выбирает
неизменный кадр для основного знака и свечения; остальные каналы движения не меняются. Два
фиксированных пула, depth test и освобождение ресурсов сохраняются.

Проверки: точное совпадение PNG с исходным каталогом, пять доступных кадров, неизменность формы при
паузе/seek, одинаковые UV у свечения и основного знака. Визуальную приёмку выполняет root на
существующем стенде.
