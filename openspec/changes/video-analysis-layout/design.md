# Устройство структуры анализа

## Context

Пайплайн уже связывает аудио с источником/интервалом и хранит исходники локально. Нужно группировать
много видео без переиспользования чужих результатов. Название песни не является названием урока.

## Goals / Non-Goals

**Goals:** сохранить источник и название; не менять старые CLI; разбирать полный вводный урок.
**Non-Goals:** публикация музыки, сброс прогресса, HTTP-сервисы, автоматическое снятие
reviewed-проверки.

## Decisions

- Чистый layout helper получает абсолютные courseRoot/video и id. Результат:
  `.analysis/<basename courseRoot>/<relative video including filename>/runs/<id>`.
- Корень курса — каталог над «1 ступень». Реальные пути canonical; видео вне корня отклоняется.
  `source.json` содержит path/size/mtime, courseRoot, courseTitle, lessonTitle и relativeVideo.
  lessonTitle — basename непосредственного родителя исходного видео. Изменение источника/корня при
  совпадающем названии не переиспользует результаты. Подготовка и кадры используют одну функцию.
- Без аргумента `--course-root` прежняя схема и метаданные остаются действующими.
- `local-lessons/course.json` допускает `lessonTitles: { "1": "Урок 1. Вводный" }`. Валидные строки
  для номеров 1–10 меняют только placeholder title; reviewed урок по-прежнему задаёт собственный
  title. Неверные значения игнорируются. Фразы/этапы/прогресс этим словарём не меняются.
- План первого урока находится рядом с transcript/frames и называется по каталогу. Произведения
  перечисляются отдельно; теория и музыкальные задания разделяются по фактам видео. Неизвестные
  темп, доля, октава, повторы или пальцы не заменяются догадкой. Материалы PDF/табов используются
  как дополнительное подтверждение и остаются локальными.

## Risks / Trade-offs

- Одинаковые имена в разных исходных корнях: provenance проверяется, вместо смешивания — отказ.
- Речь поверх музыки: ASR — оценка тайминга, адресные кадры и исходные табы подтверждают задания.
- HMR при локальном подключении данных: перед проверкой обновить страницу; не менять saved prefs.

## Migration Plan

Плоские smoke-запуски сохраняются. Новый полный урок анализируется в иерархии. MusicXML подключается
отдельно после сверки; основная папка остаётся dev, код поставляется через PR в dev.
