## ADDED Requirements

### Requirement: Иерархия источника

Prepare и frames SHALL с необязательным корнем курса хранить результаты по структуре курс →
относительные каталоги → имя видео → runs → ID. Название урока SHALL быть названием
непосредственного каталога видео. Без корня курса SHALL сохраняться прежний плоский режим.

#### Scenario: Первый вводный урок

- **WHEN** корень — каталог курса, файл — `1 ступень/Урок 1. Вводный/Урок 1. Вводный.mp4`
- **THEN** результаты находятся под теми же именами в analysis, название — «Урок 1. Вводный»

#### Scenario: Несколько видео и одинаковые ID

- **WHEN** основной и бонусный файлы одного урока либо видео разных уроков имеют одинаковый ID
  запуска
- **THEN** каждый файл имеет отдельную папку, результаты не смешиваются

### Requirement: Проверка происхождения

CLI SHALL проверять канонические пути корня/видео и записывать корень, относительный файл, названия
и прежнюю идентичность источника. Видео вне корня и перенаправление выходов наружу SHALL
отклоняться. Другой корень с совпадающими именами SHALL NOT переиспользовать прежние результаты.

#### Scenario: Безопасный повтор

- **WHEN** prepare и frames используют один источник, корень и ID
- **THEN** они работают в одной папке с прежними проверками интервала и модели

#### Scenario: Внешний файл

- **WHEN** файл или его каноническая junction-цель находится вне указанного корня
- **THEN** команда отказывает без изменения существующих материалов
