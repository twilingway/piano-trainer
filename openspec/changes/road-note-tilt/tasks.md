# Tasks

## 1. Формула выпрямления

- [ ] 1.1 `straightDockedClip`, `anchorRelativeDockedClip`, `dockedScreenPoint` и GLSL
      `anchorRelativeRoadClip` принимают долю наклона: смещение к контакту `anchor.w·(1 − tilt·p)`;
      тесты: 0 — постоянный сдвиг в однородных координатах (параллельно мировой дорожке), 1 —
      прежний результат, 0.5 — точка прямой; контакт при p = 0 не зависит от доли.
- [ ] 1.2 Униформа `roadDockTilt` для нот, ореола, следов и направляющих; `configureDockedRoad`
      ставит её из снимка выпрямления; тест униформы.
