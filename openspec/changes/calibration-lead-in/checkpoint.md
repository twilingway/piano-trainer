# Контрольная точка: аппаратный MIDI и вступление к калибровке

Дата: 2026-10-26. Ветка feat/calibration-lead-in от origin/dev f06b19f (PR #220 уже влит). Стенд
задачи: localhost:5192, отдельное хранилище; основная папка и стенд 5190 не обновлялись.

## Реальное пианино

Проверки выполнены с физическим USB MIDI, исходными note-on/off и CC64, без подстановки событий:

- Одиночная C4: нажатие и отпускание приняты.
- C–E–G вместе: 22 мс между атаками; результат P6 1/1 без ошибок.
- Медленный набор C–E–G: 4734 мс; не засчитан, ошибка синхронности.
- Правая педаль: реальные CC64 press/release; несколько каналов устройства.
- Раздельные C, E, G и повторения C под педалью: одновременно удерживалась максимум одна клавиша;
  ложного аккорда нет, залипания после отпускания нет.
- Переход C–E–G → C–F–A с удержанным C: результат 2/2, ошибок нет, движение голосов минимальное.
- P5 WAIT: продиктованная проверочная фраза 16/16, ошибок высоты, пропусков и лишних нот нет.
  Ритмические оценки отсутствуют по правилам WAIT; это не проверка самостоятельного чтения с листа.

Сырые пользовательские MIDI-события сохранены только в игнорируемом локальном browser artifact, в
Git не включены.

## Незавершённая калибровка

Старая процедура: разминка 3/4, измерения 24/24; профиль не сохранён. Пользователь попросил 2–3
начальных щелчка для подстройки. Принято 3.

Новая процедура: 3–2–1 подготовки, 3 вступительных щелчка без учёта нажатий, 4 разминочных, 24
измерительных. Период 600 мс (100 BPM); вся процедура около 22 секунд. Раннее нажатие в допустимом
окне первого warmup учитывается. Пропуск warmup по-прежнему делает результат неполным.

## Остаток аппаратной приёмки P5–P8

Новая калибровка ещё не проверена человеком. Остаются TEMPO, сопровождение по часам, слуховой эталон
и быстрый ответ с профилем, отмена/смена устройства и интегрированный P8. Автоматические проверки не
заменяют эту приёмку.

Наблюдение вне текущего изменения: подпись устройства в шапке показывает первое MIDI-устройство
вместо выбранного. Маршрутизация выбранного физического пианино подтверждена; исправление подписи
отдельно.
