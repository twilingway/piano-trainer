# Проверка меток октав

## Реализация

Предпочтение `octaveLabels` по умолчанию включено; явное выключение сохраняется. Полные наклейки не
сбрасываются. В действительном диапазоне 21–108 создаются только C1–C8. Текст запекается заранее для
RU/EN; плоский и native экранный слой используют текстуры одного владельца.

Native-слой использует фактическую камеру клавиатуры ThreeStage, matrixWorld и текущий dip.
Отсутствующий UV, скрытая клавиша, anchor за камерой или вне viewport не получают подпись. Ячейка
видимой метки остаётся 18 px; на краю C8 её границы ограничиваются canvas. В предельно боковом
ракурсе пересекающиеся метки не накладываются друг на друга.

Обычная цифра C ограничивается оставшимся местом под меткой; узкие C и другие клавиши сохраняются.
Разрешённый уроком finger badge временно скрывает только совпавшую C-метку, без изменения
предпочтения или самого badge; после исчезновения badge метка восстанавливается.

## Автоматические проверки

- Регрессии старых настроек сначала воспроизвели 6 ошибок missing/default/persistence.
- Регрессия обычной цифры C сначала воспроизвела пересечение с полосой 18 px.
- Тесты покрывают фактическую октаву, отсутствие ложных C, layout, видимость, уничтожение owned
  текстур, независимые переключатели, оба вида сравнения и RU/EN.
- Native-проверки покрывают actual top без двойной высоты, current docked/free/performance camera,
  matrix/dip, viewport/behind-camera, C8 clamp, авторизованные cues и повторное использование bake.
- `pnpm spec:validate`: 86 passed / 0 failed.
- Полный `pnpm check`: все этапы прошли, 4423 passed / 10 skipped, compiler 23/23, 229.7 s. Лог:
  `~/.claude/status/logs/octave-key-labels-clean-check.log`.
- Изолированный неизменённый `handSolver/chunks.test.ts`: 6/6, 4057 ms на 280 strikes. Тесты
  решателя, тайм-ауты и конфигурация не менялись.

## Браузерная проверка ведущим агентом

Ведущий проверил desktop и mobile: classic 320, arcade 667×375/320×568, reading, native 25 в косом
ракурсе, native 88 и free-camera mobile. Проверены toggle false + reload, полные наклейки,
отсутствие горизонтального переполнения. Разрешённый C4 lesson badge и восстановление метки
подтверждены отдельным component probe; это не новый сквозной MIDI-прогон курса.

Локальные снимки основной папки: `.browser-artifacts/octaves-native-overlay-390.png`,
`octaves-native-25-oblique.png`, `octaves-native-free-mobile.png`, `octaves-classic-final-320.png`,
`octaves-arcade-final-landscape.png`, `octaves-cue-suppression-320.png`,
`octaves-cue-restored-320.png`. Снимок `octaves-native-final-390.png` фактически показывает
effective classic в уроке и не является доказательством native-вида.

Временный сервер ведущего на 5191 остановлен; пользовательский 5190 не менялся.
