# Постоянные метки октав

## Context

`KeyboardLayer` уже рисует наклейки в общей текстуре клавиатуры; она переносится на native top.
Существующие полные наклейки показывают имена и октавы на всех клавишах. Их переключатель нельзя
переиспользовать: начальные уроки специально выключают полные наклейки.

## Goals / Non-Goals

Цель — отдельные номера на C без изменения геометрии. Не вводить новый world-space renderer, новые
масштабы, подсветку, изменения MIDI или обновления React на каждый кадр.

## Decisions

- Чистый расчёт `pitch % 12 === 0` и `floor(pitch / 12) - 1` определяет наличие и номер. Фактический
  88-клавишный диапазон 21–108 содержит C1–C8; C0 не добавляется искусственно.
- Небольшой отдельный владелец меток рядом с `keyStickers`: запечь постоянный текст в текстуру,
  разместить спрайты при layout и уничтожить owned textures при destroy. Не раздувать
  `KeyboardLayer` за ESLint 500 строк.
- Прокинуть отдельный boolean через StaffPrefs и существующий applyLaneLook для основного и
  сравнительного видов. Использовать прежний persisted staff объект; нормализация missing→true,
  explicit false→false. Профили уроков сохраняют выбранное значение.
- Когда полные наклейки видны, отдельный слой скрыт: буква с октавой уже есть на полной наклейке.
  Это устраняет дубль, не меняя старый переключатель.
- Настройка и доступное имя идут через t() и каталог RU/EN. Обозначение C4 — международная
  музыкальная нотация; формат новой подписи тоже оформить через локализованный шаблон.

## Risks / Trade-offs

- 88 клавиш на узком экране → проверить реальные снимки и выбрать размер/место без наложения
  соседних C и цифр пальцев; не расширять физические клавиши ради текста.
- Смена layout/style → новый слой обновляет позиции и не оставляет старых подписей.
- Native texture path → проверить фактические 3D-ракурсы, а не только плоский слой.
- Кадровый цикл → никаких Text/Graphics или новых textures в update; OSMD не затрагивается.

## Migration Plan

Миграция хранения не нужна. Новый boolean нормализуется поверх существующих предпочтений.
