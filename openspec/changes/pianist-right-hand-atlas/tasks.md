# Задачи локального атласа

## 1. Сохранение основы и индекс

- [x] 1.1 Зафиксировать SHA256 исходных .blend, JSON и SMPL+H, эталонные параметры и evaluated
      кожу/30 ногтей кадров 1–6; проверить неизменность файлов и записать локальный baseline-отчёт.
- [x] 1.2 Создать отдельный набор атласа с 32 масками и соответствием кадрам; проверить уникальность
      0–31, распределение 1/5/10/10/5/1 и повторное использование кадров 1–6.

## 2. Совместный подбор новых сочетаний

- [x] 2.1 Подбирать все суставы пяти пальцев совместно для 26 новых масок с фиксированными первыми
      111 компонентами full_pose156 и масштабом; проверить инварианты и сохранение воспроизводимых
      настроек, попыток, причин и результатов в локальном JSON.
- [x] 2.2 Проверить независимым вычислителем исходную деформацию и коррекции каждого кандидата;
      сопоставить FK/LBS и конечную поверхность с Blender, указать численные допуски в отчёте.

## 3. Сцена и геометрическая проверка

- [x] 3.1 Запечь в отдельном .blend коррекции, состояния ровно назначенных клавиш и пять замкнутых
      объёмных ногтей на кадр; проверить CONSTANT, ход 8 мм, кадры после 6 и совпадение конечной
      кожи/ногтей исходных шести поз с baseline.
- [x] 3.2 Проверить evaluated кожу, подушечки, ногти и треугольники белых/чёрных клавиш: контакт
      −0,5…+1 мм только своей подушечкой, остальные зазоры от 0,5 мм; получить отчёт всех 32 масок
      со статусами PASS_GEOMETRY_ONLY/REJECTED_VALIDATION/UNRESOLVED и причинами. Новые нарушения
      старых поз записать отдельно, сохранив их исходные параметры и геометрию.
- [x] 3.3 Запустить негативные контроли: отсутствующий контакт одного пальца аккорда, лишняя
      клавиша, отсутствующий ноготь, отсутствующие данные подушечки и контакт вне подушечки; каждый
      контроль должен дать явный отказ, свидетельства записать локально.

## 4. Воспроизведение и просмотр

- [x] 4.1 Независимо открыть сохранённый .blend и повторить проверку без перестроения; сравнить
      параметры, конечную кожу, все ногти, клавиши и метрики, сохранить replay-отчёт.
- [x] 4.2 Получить и просмотреть изображения сверху/сбоку всех новых кандидатов; проверить наличие
      обоих видов и восстановление пользовательского кадра/ракурса.
- [ ] 4.3 Получить визуальное подтверждение пользователя для новых кандидатов и отдельно для пяти
      исходных нажатий; без подтверждения оставить этот пункт открытым и не объявлять геометрический
      PASS визуальной приёмкой.

## 5. Итоговая интеграционная проверка

- [x] 5.1 Выпустить общий отчёт с точными количествами по статусам, ограничениями методов,
      локальными путями и командами воспроизведения; сверить все 32 записи и исходные SHA256.
- [x] 5.2 Проверить публичный diff: только документация, без локальных моделей, параметров,
      адаптеров, сцен и изображений; получить независимый review соответствия спецификации.
- [x] 5.3 Выполнить `pnpm check` и `pnpm spec:validate`, записать результаты и точные причины
      недоступных проверок; визуальную приёмку не закрывать по итогам автоматических команд.
