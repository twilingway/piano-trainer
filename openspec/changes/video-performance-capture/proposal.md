# Локальное извлечение музыкального исполнения и наблюдений рук

## Why

Существующий pipeline извлекает речь и отдельные кадры, но не даёт проверяемую транскрипцию
фортепиано и покадровые наблюдения рук. Нужен локальный пакет исходных данных, который Claude Code
сможет использовать при последующем ретаргетинге на собственный риг.

## What Changes

- Добавляются команды подготовки отдельной среды, получения YouTube/локального видео, музыкальной
  транскрипции, извлечения рук и экспорта пакета.
- Сохраняются исходные PTS кадров, ноты, 21 landmark каждой найденной руки, калибровка клавиатуры,
  доказательства, пропуски и отдельные исправления проверяющего.
- Музыкальные события и наблюдения пальцев сохраняют независимое происхождение и проверенность;
  результат модели не становится подтверждённым исполнением.
- Цель: воспроизводимый локальный JSON/MIDI-пакет для дальнейшего анализа. Не входят: Blender,
  изменение рига, анимация костей, runtime игры, автоматическое подключение урока и автоматическая
  проверенная партитура.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `video-lesson-pipeline`: получение видео, музыкальные события и нейтральные наблюдения рук с
  независимой проверкой и экспортом.

## Impact

Новый изолированный раздел `src/lessonVideoTools/capture/`, маршрутизация новых команд через
существующий CLI и документация pipeline. Старые команды ASR сохраняются. Node запускает yt-dlp,
FFmpeg/ffprobe, Transkun на GPU и MediaPipe локально; Python-среда и модели находятся в git-ignored
`.browser-artifacts/video-capture/`. Новые production-зависимости приложения не нужны. Сеть
используется для исходного видео, инструментов и моделей, но не для отправки записей сервисам
распознавания. Скачанная музыка, кадры, модели и результаты остаются локальными; сторонние материалы
и права на них не публикуются вместе с инструментами.
