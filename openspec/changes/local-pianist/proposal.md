# Личный пианист в виде «3D» (локально)

## Why

В отдельной лаборатории Blender (`BlenderLabs/pianist-full-008/pianist-full.blend`) собран персонаж
пользователя: его лицо (голова `PersonalHead_UV` с запечённой текстурой), очки, цилиндр, пальто с
меховым воротником, брюки, белая рубашка, закрытые белые перчатки, готовые туфли Mindfront Oxford
(CC BY 4.0) на скелете `PianistRig` с весами. Пользователь хочет увидеть этого персонажа в игре, за
клавиатурой вида «3D». Лицо и текстура личные: в публичный репозиторий они не попадают, подключение
сначала только локальное.

## Goals

- Экспортная копия персонажа в GLB: без синтезатора, банкетки, пола, камер и света лаборатории, без
  скрытых дублей анатомии под головой и одеждой; видимая геометрия, скелет, веса, UV головы, очки
  отдельной геометрией и личные формы головы сохраняются. Исходный `.blend` не меняется.
- В виде «3D» персонаж сидит за клавиатурой на месте игрока; C4 лаборатории (`Key_60`) совмещено с
  C4 приложения. Время позы берётся только из `PracticeSession`.
- Файл модели лежит в git-игнорируемой папке `local-models/` и подхватывается только локальным
  dev-сервером; без файла приложение работает как раньше и не показывает новый выбор.

## Non-Goals

- Игра всех пальцев, октавы, произвольные ноты, педаль. В сцене есть только пробная 8-секундная
  анимация двух указательных пальцев; она показывается как проба, а не как механика игры.
- Связь тела с решателем живых рук (`handSolver`), IK рук по нотам песни.
- Камера, которая смотрит на пианиста спереди (орбитальная камера — отдельное изменение
  `orbit-camera`); банкетка и пол в игре.
- Публикация модели, текстуры или фотографий; сборка для продакшена с пианистом.

## What Changes

- Скрипт экспорта для лаборатории (`export-glb/export_pianist.py`, рядом с копией сцены, вне
  репозитория): удаляет лабораторные объекты, прозрачные «Hidden_Source_*» грани тела и пальто и
  грани тела, закрытые отдельными мешами во всех пробных кадрах анимации; сдвигает начало координат
  в переднюю верхнюю кромку C4; пишет `pianist.glb` с клипом `IndexFingerTest_8s`.
- `.gitignore`: новая папка `local-models/` (модель и файл авторства обуви рядом с ней).
- Новый модуль `src/render/three/pianist.ts`: поиск локальной модели (только в dev), загрузка,
  посадка на клавиатуру, поза по времени песни.
- Настройка «Мой пианист (проба)» в разделе «Вид», видна только в виде «3D» и только при найденной
  модели; сохраняется. Когда она включена и модель загружена, пианист заменяет живые 3D-руки.

## Material decisions

- **Приватность.** Модель с лицом не коммитится и не попадает в продакшен-сборку: поиск через
  `import.meta.glob` выполняется только при `import.meta.env.DEV`.
- **Лицензия обуви.** Mindfront Shoes Oxford Male, CC BY 4.0: файл `ATTRIBUTION.txt` лежит рядом с
  GLB в `local-models/`; при будущей публикации модели авторство обязательно.
- **Проба вместо механики.** Пока нет игры по нотам, поза — 8-секундный тест лаборатории в первые 8
  секунд песни, дальше последний кадр. Это решение временное и подлежит замене.
- Новых зависимостей нет: `GLTFLoader` и `AnimationMixer` уже в `three`.
