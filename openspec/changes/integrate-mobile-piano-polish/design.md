# Design

## Context

Пять источников начинаются от dev 9e95e937 и опубликованы отдельно; компактный результат добавляется
после своей проверки. Главная папка и стенд 5190 остаются пользовательскими. Объединение выполняется
в новой ветке и внешнем worktree.

## Goals / Non-Goals

Единая проверяемая сборка сохраняет принятые функции. Не добавляем настройки, зависимости и новые
часы. Слияние в dev/main и развёртывание не входят в эту задачу.

## Decisions

- Последовательные merge исходных веток сохраняют происхождение кода. Конфликт разрешается с
  сохранением обоих поведений, без выбора целиком ours/theirs для изменённого модуля.
- Особое пересечение: начальная готовность сцены и подтверждение полного runtime-кадра; размеры
  клавиш/дороги и переключатель линий; владение материалами и композиция native 3D; два Vite-plugin.
- Полный свет ручного 3D и приоритет сохранённого стиля остаются. Мобильная классика действует
  только при отсутствии допустимого выбора. Начальный и поздний лоадеры не блокируют друг друга.
- Механическое выделение небольших функций оболочки допустимо для соблюдения лимита 500 строк.
  PracticeSession остаётся единственными часами; pure-core не получает DOM/таймеры/React.
- Финальный PR содержит все правки; промежуточные PR после этого отмечаются заменёнными, их ветки с
  неопубликованной/невлитой работой не удаляются. Данные и код сохраняются в общем PR.

## Risks / Trade-offs

Независимый зелёный gate не доказывает совместимость. Нужны проверки точного общего SHA, реальные
видимые кадры Chrome и холодный старт. Физические устройства выключены игроком, Safari не
объявляется проверенным. Временные серверы только управляемые, на 5191–5199, с последующей очисткой.

## Validation

Целевые тесты native compositor/готовности/материалов/геометрии/прогресса; `pnpm check` и
`pnpm spec:validate`. Видимый Chrome: начальный loader без скрытой modal, выбранный Classic/3D,
компактные RU/EN окна, переходы панелей, FPS/ручки/меню, звук/партия и доступный footer результата.
Завершающее независимое ревью интеграции и проверка чистоты основной папки dev.
