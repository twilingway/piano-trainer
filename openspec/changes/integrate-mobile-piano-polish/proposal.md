# Proposal

## Why

Проверенные правки загрузки и мобильного экрана находятся в отдельных ветках с пересечением
renderer, CSS и Vite. Перед передачей игроку нужна одна совместимая сборка и один PR для проверки.

## What Changes

- Объединить ветки начального HTML-лоадера, мобильного профиля, устойчивой компоновки, вертикальных
  линий, поздней подготовки звука/партии и компактного результата.
- Разрешить пересечения, сохраняя обе стороны уже проверенного поведения, и выполнить общий gate.
- При необходимости механически вынести код оболочки ради лимита 500 строк без изменения поведения.
- Сохранить источники, результаты проверок и ограничения в одной очереди и отчёте приёмки.

Цели: совместимость и единый путь просмотра. Не-цели: новые функции, изменение качества света,
дополнительные зависимости, музыкальные правила, merge/deploy в dev/main. Новых существенных
продуктовых, лицензионных и privacy-решений нет.

## Capabilities

### New Capabilities

Нет. `skip_specs: true`: интеграция реализует контракты исходных изменений без новой семантики.

### Modified Capabilities

Нет новых дельт; исходные OpenSpec входят вместе со своими ветками.

## Impact

Пересекающиеся renderer/Workspace/Vite/CSS, общий набор тестов и документация. Источники: PR #277,
#278, #279, #280, #281 и ветка `fix/compact-practice-result` после её проверки.
