## 5. Механическая кисть и форма из видео

- [x] 5.1 `tools/hand-rig/hand_mech.py`: фаланги рига как звенья, суставы с пределами-стенами;
      обхват шара (перенос прототипа `mech/grasp.py` на кисть рига) — проверка стен, а не модель
      формы. Проверка в фоновом Blender: обхват шаров 400…18 мм без выхода суставов за пределы,
      сжатый до предела палец помечен; скелет-рендер показан пользователю.
- [x] 5.2 `tools/hand-rig/hand_shape.py`: форма из видео сверху — сгиб и разведение пальцев 2–5 и
      углы большого, подогнанные в стенах по точкам кадра и касанию кончика; в библиотеку —
      разведение, относительный сгиб и углы большого. Проверка: наложение скелета рига на кадры
      вступления, медиана ошибки суставов в пикселях; удары за порогом без формы перечислены;
      распределение углов против пределов; относительный сгиб при наклоне −20° и 0° — медиана
      разницы ≤ 0,05.
- [x] 5.3 Раскладка сгиба по суставам из вида сбоку (Hn6tFiyNMBQ, ближняя правая рука): `BEND_SPLIT`
      в `hand_mech.py`. Проверка: медианы MCP/PIP/DIP по 4267 кадрам на палец.
