# Spec Delta

## Purpose

Определяет доступность Piano Trainer по публичному HTTPS-адресу и условия, при которых новая версия
может заменить работающую.

## ADDED Requirements

### Requirement: Публичный сайт доступен по защищённому адресу

Система SHALL открывать Piano Trainer по `https://piano.twiling.ru/` и отдавать ресурсы приложения
по тому же адресу.

#### Scenario: Страница и ресурсы доступны

- **WHEN** пользователь открывает `https://piano.twiling.ru/`
- **THEN** страница и ресурсы текущего релиза загружаются без ошибок сервера и браузер видит
  защищённый контекст

#### Scenario: HTTP перенаправляется на HTTPS

- **WHEN** пользователь открывает `http://piano.twiling.ru/`
- **THEN** браузер переходит на защищённый адрес

### Requirement: Публикуется только проверенный релиз

Система MUST выпускать в продакшен только коммит основной ветки с успешной обязательной проверкой
качества.

#### Scenario: Проверка прошла

- **WHEN** в основной ветке появился новый коммит и его обязательная проверка завершилась успешно
- **THEN** этот коммит становится кандидатом на публикацию

#### Scenario: Проверка не прошла или ещё идёт

- **WHEN** проверка нового коммита завершилась ошибкой, ещё идёт или её результат недоступен
- **THEN** работающий релиз остаётся на сайте

### Requirement: Неудачный выпуск сохраняет доступную версию

Система MUST проверять новый релиз после переключения и возвращать предыдущий, если новый релиз не
отдаёт ожидаемую версию через публичный адрес.

#### Scenario: Проверка нового релиза прошла

- **WHEN** публичный адрес отдаёт ожидаемую версию и стартовую страницу нового релиза
- **THEN** новый релиз отмечается как опубликованный

#### Scenario: Проверка нового релиза не прошла

- **WHEN** новый релиз не запустился или публичный адрес не отдаёт ожидаемую версию
- **THEN** система возвращает предыдущий релиз и не отмечает новый как опубликованный

### Requirement: Обновление не удаляет локальные данные игрока

Система MUST сохранять адрес сайта и не выполнять при релизе действий, очищающих песни, настройки и
дубли, хранящиеся в браузере.

#### Scenario: Данные после обновления

- **WHEN** игрок открывает сайт по прежнему адресу после выпуска новой версии в том же браузере
- **THEN** его сохранённые песни, настройки и дубли остаются доступны
