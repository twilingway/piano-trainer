# Design

## Context

ThreeStage каждый кадр задаёт отдельные проекции дороги и клавиатуры. Pixi рисует перспективные
декорации и экранный HUD. ЛКМ уже отделена от СКМ.

## Goals / Non-Goals

Одна временная камера всех объёмных объектов и сохранённый флаг режима. Автоматический облёт, новые
движения пианиста и перенос всего Pixi в Three не входят.

## Decisions

- FreeSceneCamera владеет PerspectiveCamera и существующим OrbitControls. LEFT/RIGHT и touch
  отключены, MIDDLE=ROTATE; штатный Shift переключает pan. Слушатели подключены только в активном
  3D-режиме и удаляются при выходе/ошибке/destroy.
- ThreeStage использует единственный проход свободной камеры, без прежних матриц и split-view. Сцена
  фиксируется без автоматического pan; все три группы получают одинаковый transform.
- Сброс кадрирует bounds клавиатуры с загруженным пианистом; дорожка не растягивает кадр до
  горизонта. Появление модели и изменение геометрии обновляют исходный общий кадр. Ручной pose живёт
  только до пересоздания сцены.
- Raycast по физическим key mesh возвращает pitch, который преобразуется в существующий плоский key
  hit input. Песня и PracticeSession не затрагиваются.
- По прямому уточнению пользователя Pixi декорации/искры/спрайтовое пламя/дым исключены из всего
  native 3D; энергия продолжает обновляться. Спрайтовые руки скрыты только во время свободного
  осмотра; native notes/trails/aura остаются, экранный HUD сохраняется.
- Флаг хранится в staff-prefs с boolean normalization; DOM-легенда обновляется только при
  locale/активности, без React подписок на кадры.

- По уточнению пользователя halo проверяет глубину, как aura/trails. В запасной перспективе FxLayer
  и PlasmaLayer находятся ниже HandsLayer; Three point lights не меняются.

## Risks / Trade-offs

Bounds вычисляются при reset/изменении геометрии, не на каждом кадре. Шейдеры нот продолжают
использовать реальную камеру рендера. Нужна визуальная проверка v5 playback.mid с частным GLB;
артефакты остаются локальными.

## Open Questions

Нет: ручное управление и легенда прямо запрошены пользователем, новых зависимостей и решений о
публикации нет.
